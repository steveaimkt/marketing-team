# 실습 입력 · 079 리뷰·후기 요청 자동화

```
리뷰 요청 자동화 만들어줘
```

## 인센티브를 주면 대가성 표기 의무가 생긴다

적립금 1,000원도 대가다.
**표기 없이 모은 리뷰는 나중에 통째로 지워야 할 수 있다.**

| 인센티브 | 표기 |
|---|---|
| 없음 | 불필요 |
| 적립·쿠폰·증정 | **"○○ 제공받아 작성"** 을 리뷰에 넣도록 안내 |

## 시점 플로우

| 시점 | 메시지 | 중단 조건 |
|---|---|---|
| D+3 | 도착 확인·사용 안내 | **CS 접수 시 보류** |
| D+10 | 리뷰 요청 (+인센티브) | 작성 확인 시 종료 |
| D+17 | 마지막 리마인드 | 이후 안 보냄 |

**D+3 이 있는 이유**: 불만을 먼저 접수해서 **나쁜 리뷰가 되기 전에** 처리한다.

## ⏸ 발송 전에 멈춘다 (`mutating: true`)

## 바꿔서 해 보기

- 「인센티브 없이」로 해 본다 → 표기 문구가 사라지고 **응답률이 낮아진다는 안내**가 붙는다
- 구매 데이터를 빼고 돌려 본다 → **`[발송 대기]`** 로 설계만 나온다
