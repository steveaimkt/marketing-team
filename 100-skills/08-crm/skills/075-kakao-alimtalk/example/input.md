# 실습 입력 · 075 카카오 알림톡·친구톡 설계

```
알림톡 템플릿 만들어줘
```

## 애매하면 친구톡(광고성)으로 본다

| | 알림톡 (정보성) | 친구톡 (광고성) |
|---|---|---|
| 요건 | **거래·계약 이행에 필요한 정보** | 판촉·프로모션 |
| 예 | 주문·배송·예약 확인, 만료 안내 | 신상품·할인·이벤트·쿠폰 |
| 동의 | 불필요 | **채널 친구 + 광고 수신 동의** |

정보성으로 잘못 분류해 보내면 **동의 없이 광고를 보낸 것**이 된다.
그래서 애매할 때는 광고성으로 본다. 잘못 기울였을 때 손해가 작은 쪽이다.

## 변수 필드가 없으면 멈춘다

`#{고객명}` · `#{주문번호}` 같은 변수가 없는 알림톡은 **심사에서 반려**된다.
정보성이라는 근거가 변수에 있기 때문이다.

## 바꿔서 해 보기

- 「할인 쿠폰 안내」로 해 본다 → **친구톡**으로 판정되고 광고 표기·수신거부가 붙는다
- 변수를 빼고 돌려 본다 → 어떤 값이 들어가는지 되묻는다
