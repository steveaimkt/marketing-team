## 모르면 지어내지 않는다

챗봇 사고의 대부분은 「모르는데 그럴듯하게 답한 것」에서 난다.
그래서 확신도를 3단으로 나눈다.

| 확신도 | 근거 | 행동 |
|---|---|---|
| HIGH | 정확한 근거 문서 있음 | 답변 + 출처 |
| MEDIUM | 부분 근거 | 답변 + **고객센터 권유** |
| **LOW** | 근거 없음 | **답변하지 않고 에스컬레이션** |
