# 실습 입력 · 083 보도자료 작성

```
보도자료 써줘
```

## ⏸ 앵글을 고르기 전에는 본문을 안 쓴다

같은 소식도 어느 앵글로 쓰느냐에 따라 **실리는 매체가 달라진다.**

| 렌즈 | 질문 |
|---|---|
| 시의성 | 지금 왜 이 소식인가 |
| 최초성 | 업계 처음인가 |
| **데이터** | 숫자가 이야기인가 |
| 사회적 맥락 | 트렌드·정책과 연결되나 |
| 영향 범위 | 누구의 문제를 푸나 |

## 인용 없는 보도자료는 안 실린다

**근거 수치**와 **인용 가능한 담당자**가 없으면 묻고 멈춘다.
기자가 그대로 쓸 수 있는 문장이 있어야 기사가 된다.

## 바꿔서 해 보기

- 수치를 빼 본다 → 데이터 앵글이 후보에서 사라진다
- 「업계 최초」라고 주장해 본다 → **근거를 요구**하고, 없으면 그 앵글을 뺀다
