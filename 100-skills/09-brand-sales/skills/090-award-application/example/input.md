# 실습 입력 · 090 수상·인증 지원서 빌더

```
이 공고로 지원서 써줘
```

## 배점표를 역산한다

공고문에 배점이 있으면 **배점 높은 항목에 분량을 몰아준다.**
배점을 모르면 역산이 안 되므로 **묻고 멈춘다.**

## 증빙 없는 성과는 본문에서 뺀다

감점이 아니라 **실격 사유**가 되는 경우가 있다.
`[증빙 미확보]` 로 표기하고 본문에 안 쓴다.

## 분량 제약을 지킨다

"1,000자 이내"를 넘기면 자동 탈락하는 심사가 흔하다.
초안 단계에서 글자 수를 세어 표에 적는다.

## 바꿔서 해 보기

- 배점표를 빼 본다 → **묻고 멈춘다**
- 증빙 목록을 다 채워 본다 → 본문에 쓸 수 있는 성과가 늘어난다
