# 실습 입력 · 082 브랜드 가이드라인 문서화

```
브랜드 가이드라인 문서 만들어줘
```

## 없는 자산은 `[미확보]` 로 남긴다

컬러가 없다고 임의로 정하면 **외주가 그 색으로 작업**하고,
나중에 진짜 색이 정해지면 전부 다시 해야 한다.

## 정본은 `tone.md` 하나다

원페이지는 **배포용 요약**이고, 단일 진실 소스는 `brand/tone.md` 다.
둘이 어긋나면 tone.md 를 따른다. 교차 검증을 마지막에 한다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 서사·보이스 | 081 산출물 | ⏸ **081 을 먼저 권한다** |
| 로고·컬러·폰트 | 파일 · HEX | `[미확보]` |
| 금기 표현 | `brand/profile.md` §6 | 업종 규제어 |

## 바꿔서 해 보기

- 081 없이 돌려 본다 → **"서사 없이 규정만 만들까요"** 를 먼저 묻는다
- 로고 파일만 주고 컬러를 빼 본다 → 컬러 칸이 `[미확보]` 로 남고 **외주 체크리스트에서 빠진다**
