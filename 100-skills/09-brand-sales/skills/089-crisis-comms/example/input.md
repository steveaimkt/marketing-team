# 실습 입력 · 089 위기 커뮤니케이션 플랜

```
이 이슈 어떻게 대응할지 정리해줘
```

## 세 가지를 먼저 나눈다

| 구분 | 무엇 |
|---|---|
| ✅ **확인된 사실** | 우리가 증명할 수 있는 것 |
| ❓ **미확인 주장** | 상대가 말했지만 확인 안 된 것 |
| 🗣 **여론 반응** | 사실과 무관하게 퍼지는 것 |

**이 구분이 모든 문구의 수위를 정한다.** 안 나뉘면 문구를 쓰지 않는다.

## ⏸ 대응 수위는 사람이 확정한다

| 분기 | 판단 |
|---|---|
| 사실인가 | 사실 → 인정+조치 / 허위 → 정정 / 미확인 → **홀딩** |
| 확산 중인가 | 자연 소멸 추세면 **무대응 + 모니터링** |
| L3·법적인가 | → **에스컬레이션** (대표 승인 · 변호사 검토) |

## 사과문 4단 (고정)

인정 (구체적으로 무엇을) → **사과 (조건 없이)** → 조치 (한 것 + 할 것, 날짜) → 재발 방지 (구조)

> ❌ **"불편하셨다면"** 금지. 조건부 사과는 사과가 아니다.

## 바꿔서 해 보기

- 「미확인 주장」만 있는 상황으로 해 본다 → **홀딩 스테이트먼트**만 나오고 사과문은 안 나온다
- L3(언론 보도)로 올려 본다 → `[변호사 검토 필수]` 플래그가 붙고 **전달이 막힌다**
