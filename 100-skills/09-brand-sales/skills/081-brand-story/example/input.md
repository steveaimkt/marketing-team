# 실습 입력 · 081 브랜드 스토리·미션 빌더

```
브랜드 스토리 만들어줘
```

## ⏸ 7문항을 답해야 시작된다

창업 스토리는 **지어낼 수 없는 유일한 자산**이다.
답이 없으면 만들지 않는다 (059 펀딩 2막을 비운 것과 같은 이유).

| # | 질문 |
|---|---|
| ① | 이 일을 시작하게 만든 **구체적 사건**은? |
| ② | 그때 무엇이 가장 불만·부당했나? |
| ③ | 그만둘 뻔한 순간과 그래도 계속한 이유는? |
| ④ | 첫 고객(또는 첫 성공)의 장면은? |
| ⑤ | **절대 타협하지 않는 것** 하나는? |
| ⑥ | 고객이 우리를 쓰고 나서 달라져야 하는 것은? |
| ⑦ | 10년 뒤에도 변하지 않을 것은? |

**한 번에 다 묻지 않는다.** 2~3개씩 나눠 묻는다.

- ⑤만 답하고 나머지를 비워 본다 → 신념 막만 채워지고 **계기·약속 막이 비었다고 표시**된다
