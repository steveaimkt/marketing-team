# 실습 입력 · 084 제안서 자동 생성

```
이 RFP 로 제안서 만들어줘
```

## ⏸ Win Theme 승인 전에는 목차도 안 쓴다

Win Theme 3개가 제안서의 뼈대다. 여기가 뒤집히면 **전부 다시 쓴다.**
순서를 지키는 게 가장 빠르다.

```
Win Theme = "고객의 {문제}에 우리는 {차별 근거}로 답한다" + 지지 증거 1개
```

## RFP 에서 뽑는 4가지

1. 요구 과업 목록
2. **평가 기준 (배점 있으면 배점순)**
3. 예산·일정 제약
4. **행간의 Pain Point 3개 이상**

배점이 있으면 **배점 높은 항목에 분량을 비례 배분**한다.

## 바꿔서 해 보기

- 배점표를 빼 본다 → 분량 배분이 균등해지고 **어디에 힘을 줄지 못 정한다**
- 086 미팅 노트를 같이 줘 본다 → **영업 신호 메모**가 Pain Point 입력이 된다
