# 실습 입력 · 088 스폰서십 콘텐츠 기획

```
이 광고주 브리프로 콘텐츠 기획해줘
```

## 시청자 가치와 안 겹치는 요구는 본편에 안 넣는다

```
광고주가 말하고 싶은 것  ∩  내 시청자가 얻고 싶은 것
```

이 교집합을 **한 문장**으로 정의한다.
안 나오는 요구는 **광고주 협의 항목으로 분리**한다.
억지로 넣은 멘트 하나가 그 영상 전체의 신뢰를 깎는다.

## ① 앞광고 고지가 1단이다

**회피 화법을 쓰지 않는다.**

| ❌ | ✅ |
|---|---|
| "협찬 비슷한 건데요" | "이 영상은 ○○의 유료 광고입니다" |
| 영상 끝 자막 한 줄 | **도입부 + 자막 + 더보기** |

- 「할인 코드」를 추가해 본다 → 8단 중 CTA 단의 구조가 바뀐다
