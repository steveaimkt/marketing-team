# 실습 입력 · 087 파트너십·제휴 제안 팩

```
이 브랜드랑 제휴 제안하고 싶어
```

## 기울기를 숨기지 않는다

교환이 한쪽으로 기울면 **기울기를 명시**하고 보정 수단을 딜 구조로 넘긴다.
숨기고 제안하면 상대가 먼저 알아채고 **협상력이 통째로 넘어간다.**

## 딜 구조 3형

| 안 | 언제 |
|---|---|
| **A 고정비형** | 첫 거래 · 신뢰 낮을 때 · 상대 리스크 최소 |
| **B 성과 셰어형** | 상호 신뢰 + **측정 인프라**가 있을 때 |
| **C 혼합형** | **대부분의 첫 제휴에서 권장** (최소 보장 + 초과 셰어) |

## 상대의 KPI 를 추정한다

우리가 주고 싶은 것이 아니라 **상대가 지금 키우려는 지표**에서 출발한다.
공개 정보 기반은 `[추정]` 표기.

## 바꿔서 해 보기

- 우리 목표를 2개 잡아 본다 → **1순위 1개로 좁히라**고 되묻는다
- 성과 추적 수단이 없다고 해 본다 → **B 성과 셰어형이 후보에서 빠진다**
