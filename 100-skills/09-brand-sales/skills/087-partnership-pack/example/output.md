## 딜 구조 3안

### A 고정비형
| 항목 | 내용 |
|---|---|
| 구조 | 뉴스레터 2회 노출 · 정액 **150만원** |
| 상대 | 리스크 0 · 예측 가능 |
| 우리 | **성과 무관하게 150만원 확정 지출** |
| 적합 | 첫 거래 · 상대가 성과 셰어를 꺼릴 때 |

### B 성과 셰어형
| 항목 | 내용 |
|---|---|
| 구조 | 전용 코드 매출의 **20%** |
| 추적 | 전용 할인 코드 `SOONHAN10` · 전용 랜딩 |
| 상대 | 리스크 공유 · 상한 없음 |
| 적합 | 상호 신뢰 · **측정 인프라 있음** ✅ (코드 추적 가능) |

### C 혼합형 · **권장**
| 항목 | 내용 |
|---|---|
| 구조 | **최소 보장 60만원 + 코드 매출 15%** |
| 상대 | 최소 수익 보장 · 잘되면 더 |
| 우리 | 고정 지출을 60만으로 낮추고 성과에 연동 |
| 손익분기 | 코드 매출 **400만원**에서 A안과 동일 비용 |

```
C안 검증: 코드 매출 400만원 가정
비용 = 600,000 + 4,000,000 × 0.15 = 1,200,000
매출 총이익 = 4,000,000 × 52% = 2,080,000
순기여 = +880,000  ✅
```

> **코드 매출 190만원 아래면 C안이 A안보다 싸다.** 첫 제휴는 대개 그 아래다.

## 어디를 봐야 하나

**기울기를 먼저 적었다.** "상대는 우리 없이도 되고 우리는 아쉽다."
제안서에는 안 쓰지만 **우리 문서에는 쓴다.** 이걸 모르고 협상에 들어가면
상대가 셰어율을 낮출 때 근거 없이 버티게 된다.

**C안 손익분기가 190만원이다.** 코드 매출이 그보다 크면 A안(정액 150만)이 싸다.
첫 제휴는 대개 그 아래라 C안이 유리하다.
**"혼합형이 무난하다"가 아니라 숫자로 그 구간을 아는 것**이 다르다.

**협상 카드에서 지킬 것 1번이 검수권이다.** 셰어율은 양보해도 되지만
상대가 우리 제품을 "피부가 재생됩니다"라고 쓰면 **책임은 우리에게 온다** (034 와 같다).
돈보다 먼저 지킬 것이 문서에 적혀 있어야 협상 중에 안 흔들린다.
