# 🎯 구글 광고 세팅: A 브랜드 (월 200만원)

## 캠페인 구조

| # | 캠페인 | 유형 | 월 예산 | 목적 |
|---|---|---|---|---|
| 1 | A브랜드_브랜드방어 | 검색 | **200,000** (10%) | 경쟁사 입찰 방어 · 저CPC |
| 2 | A브랜드_일반검색 | 검색 | **1,000,000** (50%) | 전환 데이터 축적 |
| 3 | A브랜드_PMax | Performance Max | **800,000** (40%) | 2번 전환 30건 확보 **후 시작** |

> ⚠️ 3번은 **1개월 뒤에 켠다.** 첫 달은 1·2번에 200만원을 넣어 전환 신호를 만든다.
> 전환 데이터 없이 PMax 를 켜면 학습이 안 되고 예산만 소진된다.

|---|---|---|---|
| 민감성_세럼 | 구문 | "민감성 피부 세럼" | 700 |
| 무향_세럼 | 구문 | "향료 무첨가 세럼" | 700 |

- **확장검색은 첫 달에 쓰지 않는다.** 검색어 보고서가 쌓인 뒤에 연다
- 제외 키워드 초기 세트: 무료 / 샘플 / 부작용 / 후기만 / 알바

## 전환 추적 체크리스트

- [ ] GA4 전환 이벤트 → 구글 광고 가져오기 연결
- [ ] **구매 전환에 값(value) 전달** (없으면 ROAS 입찰 불가)
- [ ] 향상된 전환(Enhanced Conversions) 설정
- [ ] 전환 기간 설정 확인 (클릭 후 30일 기본 · 화장품은 고려 기간이 짧아 7~14일 검토)
- [ ] **테스트 구매 1건**으로 전환 실제 기록 확인 ← 이게 없으면 나머지가 무의미

| 시기 | 전략 | 조건 |
|---|---|---|

## 어디를 봐야 하나

**3번 캠페인 예산이 잡혀 있는데 "1개월 뒤에 켠다"고 적혀 있다.** 구조 설계와 실행 순서가 다르다.
계정에 세 개를 다 만들어 놓고 동시에 켜면 **1·2번에 갈 데이터가 3번으로 새서**
셋 다 학습이 안 된다.

**「테스트 구매 1건」에 화살표가 붙어 있다.** 체크리스트에서 가장 많이 건너뛰는 항목이고,
안 하면 나머지 네 개를 다 해도 소용없다. **전환이 안 잡히는 계정은 그걸 한 달 뒤에 안다.**

**입찰 전략이 단계로 되어 있다.** 처음부터 타겟 ROAS 를 걸고 싶어지는데,
전환 50건이 없으면 구글이 목표를 못 맞춰서 노출 자체를 줄인다.
**자동 입찰은 데이터를 먹고 돈다.** 순서가 있는 이유다.
