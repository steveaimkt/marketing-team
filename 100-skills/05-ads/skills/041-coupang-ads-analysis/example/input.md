# 실습 입력 · 041 쿠팡 광고 성과 분석

```
쿠팡 광고 키워드 리포트 분석해줘
```

## ⚠️ 리포트 종류가 정해져 있다

쿠팡은 공식 MCP 가 없어 **파일 업로드가 기본 경로**다.
그런데 아무 리포트나 되는 게 아니다.

```
광고센터 → 리포트 → 키워드 리포트 → 기간 설정 → 다운로드
```

**캠페인 리포트·광고그룹 리포트는 컬럼 구조가 달라 못 읽는다.**
키워드 단위가 있어야 효자·낭비 분류가 되기 때문이다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 키워드 리포트 | 광고센터 다운로드 | **묻고 멈춘다** |
| 손익분기 ROAS | `brand/profile.md` §4 | **2.0** 폴백 + 그 사실 명시 |
| 목표 ROAS | 같은 곳 | 3.0 |

## 바꿔서 해 보기

- BEP 를 3.0 으로 올려 본다 → **효자였던 키워드가 낭비로 내려간다.** 분류는 절대값이 아니라 BEP 상대값이다
- 기간을 7일로 줄여 본다 → 전환 0건 키워드가 늘어 「잠재」 판정이 많아진다 (표본 부족)
