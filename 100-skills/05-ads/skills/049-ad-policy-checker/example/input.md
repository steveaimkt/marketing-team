# 실습 입력 · 049 광고 정책·심의 체커

```
이 광고 카피 심의 걸리는지 봐줘. 메타랑 네이버에 올릴 거야
```

## 매체를 반드시 말한다

기준이 다르기 때문이다.

| | 메타 | 네이버 | 쿠팡 | 구글 |
|---|---|---|---|---|
| 심의 | **사후** 자동+수동 | **사전 검수** (1~2 영업일) | 사전 검수 | 사후 자동 |
| 걸리면 | 계정 품질 하락 | **일정이 밀린다** | 소재 반려 | 반복 시 계정 정지 |
| 특히 | 개인 특정 · Before/After | 최상급·보장 · **서류 미비** | 타 플랫폼 언급 · 최저가 | 랜딩 정책 위반 |

**네이버는 미리 걸러야 손해가 적다.** 반려되면 1~2일이 날아간다.
메타는 통과됐다가 나중에 계정 품질이 깎이는 쪽이라, 통과가 안전을 뜻하지 않는다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 업종 | `brand/profile.md` §1 | **묻고 멈춘다** (업종을 모르면 규제를 못 고른다) |
| 금기·필수 고지 | `brand/profile.md` §6 + `100-skills/compliance.md` | 업종 일반 규정 |

- 업종을 「건강기능식품」으로 바꿔 본다 → 사전심의필 항목이 추가된다
