# 실습 입력 · 047 광고 소재 A/B 판독기

```
A/B 결과 판정해줘
```

## ⚠️ 두 군데 이상 다르면 판독을 거부한다

A 와 B 가 헤드라인도 다르고 이미지도 다르면, B 가 이겨도 **왜 이겼는지 모른다.**
그 결과로 다음 소재를 만들 수 없으니 테스트한 의미가 없다.

이때는 판정하지 않고 **019 A/B 설계**로 되돌려 보낸다.

## 019 와의 경계

| | 019 | **047** |
|---|---|---|
| 언제 | 데이터 생기기 **전** | 데이터 나온 **후** |
| 무엇 | 표본수·기준 설계 | 통계 판정 |

019 설계서를 만들어 뒀으면 그 값(지표·표본·임계)을 그대로 쓴다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 안별 노출·클릭·전환·광고비 | 광고 관리자 · CSV | `sample-data/A브랜드-메타광고-30일.csv` |
| 판정 기준 | 019 설계서 | CVR · 전환 50건 · 95% |

## 바꿔서 해 보기

- 전환을 20건으로 줄여 본다 → **「표본 부족」 판정**이 나오고 승자를 뽑지 않는다
- 임계를 90%로 낮춰 본다 → 박빙이 확정승으로 바뀐다. **기준을 낮추면 승자가 생긴다**는 걸 눈으로 본다
