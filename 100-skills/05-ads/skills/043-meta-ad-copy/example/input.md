# 실습 입력 · 043 메타 광고 소재 카피 팩

```
메타 광고 카피 뽑아줘. 메시지는 〈향을 뺐더니 따가움이 줄었다〉
```

## ⏸ 메시지가 2개면 멈춘다

「순하고 촉촉하고 가성비도 좋은 세럼」은 메시지가 셋이다.
이걸로 10종을 만들면 **10종 전부가 흐릿해진다.**

메타 광고에서 한 소재가 전달할 수 있는 건 하나다.
그래서 이 스킬의 첫 게이트가 "하나로 좁혀 주세요"다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 핵심 메시지 1개 | 발화 | **묻고 멈춘다** |
| 톤·금기어 | `brand/tone.md` | A 브랜드 기본 |
| 근거 | 006·015 산출물 | 근거 없는 주장은 카피에 안 넣는다 |

## 바꿔서 해 보기

- 메시지를 「가성비」로 바꿔 본다 → 10종이 전부 다른 결로 나온다. **메시지가 카피를 정한다**
- 「글자 수 60자 제한」을 붙여 본다 → 패턴 중 서사형 2~3개가 자동으로 빠진다
