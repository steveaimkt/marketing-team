# 컴플라이언스 게이트 (전역 필수 게이트)
> SKILL.md 헤더의 `gate: true` 인 스킬이 산출물을 완성하면, 사용자에게 전달하기 **전에** 이 게이트를 반드시 통과한다.
> 게이트를 건너뛴 대외 발행물은 규격 위반 — 오케스트레이터가 차단한다.

## 대상
대외 발행물 전부: 광고 카피, 상세페이지, SNS 게시물, 블로그, 뉴스레터, 보도자료, 랜딩페이지, 영상 스크립트, 리뷰 답변.
(내부 리포트·분석 산출물은 대상 아님 → `gate: false`)

## 절차 (3 STEP)
1. **룰 로드** — [brand/profile.md](../../brand/profile.md)의 업종 값 확인 → [brand/compliance.md](../compliance.md)에서 해당 업종 섹션 + 공통(표시광고법) 섹션 로드. profile.md 미작성 시 [data/samples/profile-sample.md](../../sample-data/profile-sample.md)의 업종 값 사용
2. **전수 스캔** — 산출물 전문을 문장 단위로 검사:
   - 금지 표현 검출 → 치환 사전이 있으면 자동 치환, 없으면 대안 문구 제안
   - 필수 고지 누락 검사 (건기식 마크, 대가성 표기 등)
   - 최상급·보장성 표현의 근거 유무 확인
3. **판정 리포트** — 산출물 하단에 게이트 결과 블록 부착:

```
─── 🛡 컴플라이언스 게이트 ───
판정: ✅ 통과 | ⚠️ 수정 후 통과 (n건 치환) | ⛔ 차단 (사유)
검출·치환 내역:
  - "피부 재생" → "피부 활력" (화장품법 §13)
근거 필요 항목:
  - "판매 1위" — 근거 자료 확보 전 사용 보류
──────────────────────────
```

## 판정 기준
| 판정 | 조건 | 후속 |
|---|---|---|
| ✅ 통과 | 검출 0건 | 즉시 전달 |
| ⚠️ 수정 후 통과 | 치환 가능한 위반만 존재 | 치환본 전달 + 내역 고지 |
| ⛔ 차단 | 치환 불가한 핵심 주장 위반 (효능 주장 등) | 전달 금지, 수정 방향 제시 |

**⛔ 재시도 루프**: ⛔ 시 수정본을 자동 생성해 재스캔한다. 2회 연속 ⛔면 사용자 에스컬레이션 — 수정 방향 + 선택지를 제시하고 판단을 받는다.

## 로그
게이트 실행 결과는 [logs/build-log.md](../../logs/build-log.md)의 해당 행 `게이트` 열에 기록 (✅/⚠️/⛔).
⛔ 차단도 build-log 에 기록한다 — 산출물 열 "차단됨", 게이트 열 ⛔ (단 누적 카운터에는 미산입 — build-log 기록 규칙 참조).
