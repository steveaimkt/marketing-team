# 실습 입력 · 008 타깃 페르소나 빌더

```
sample-data/A브랜드-리뷰-200건.csv 로 페르소나 만들어줘
```

006 리뷰 마이닝을 먼저 돌렸다면 **그 산출물을 넣는 것이 가장 좋다.**
이미 5분류·클러스터가 되어 있어 바로 패턴으로 간다.

## ⚠️ 데이터가 없으면 안 돈다

이 스킬은 **최소 리뷰 50건 또는 인터뷰 3건**이 있어야 시작한다.
없으면 멈추고 요청한다. 상상으로 만들지 않는다.

```
❌ "30대 직장인 김지영 · 워라밸 중시 · 인스타 자주 봄"
     → 교과서 페르소나. 어느 브랜드에나 붙고 아무 데도 못 쓴다
✅ "성분 확인 후 구매 — 리뷰 23건에서 관찰된 패턴"
     → 근거가 붙어 있어 검증할 수 있다
```

## 나이만 다른 페르소나는 만들지 않는다

3~5종은 **서로 다른 니즈·행동 축**이어야 한다.
「30대 김지영 / 40대 박서연」처럼 나이만 바뀐 건 하나의 페르소나다.
