# 실습 입력 · 012 USP·가치제안 정의

아래 한 줄을 클로드에게 그대로 말하면 된다.

```
sample-data/경쟁사-3곳.md 로 우리 제품 가치제안 만들어줘
```

## 이 실습이 쓰는 것

| 무엇 | 어디서 |
|---|---|
| 브랜드 정보 | `brand/profile.md` · 비어 있으면 아래 A 브랜드로 돈다 |
| 경쟁 대조 | `sample-data/경쟁사-3곳.md` · **차별점을 걸러 내는 체** |
| 현재 문구 | `sample-data/A브랜드-상세페이지.md` (있으면 증거 검사 대상이 된다) |

## A 브랜드 (샘플)

- 수분 세럼 30ml 39,000원 · 타깃 27~38세 민감성 피부
- 포지셔닝 "민감 피부의 데일리 루틴을 가장 단순하게" (3스텝)
- 상세페이지 문구: "피부 장벽을 재생시켜 근본부터 개선합니다" · "3일 만에 달라지는 피부" · "고객 만족도 1위"

## 바꿔서 해 보기

이 스킬의 본체는 문장 생성이 아니라 **경쟁 대조 필터**다.

- 경쟁 자료를 빼고 돌려 본다 → 강점 7개가 전부 "차별점"이 되어 돌아온다
- 경쟁 자료를 넣고 돌린다 → 그중 4개가 **기본기**로 내려간다
- 상세페이지를 같이 준다 → 지금 쓰고 있는 문구 중 무엇이 `[증거 필요]` 인지 나온다

두 번을 비교해 보면 이 스킬이 왜 필요한지가 한눈에 보인다.
