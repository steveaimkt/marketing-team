# 실습 입력 · 013 제품명·네이밍

아래 한 줄을 클로드에게 그대로 말하면 된다.

```
수분 세럼 신규 라인 이름 지어줘
```

## 이 실습이 쓰는 것

| 무엇 | 어디서 |
|---|---|
| 이름이 실어야 할 연상 | 012 산출물의 원라이너 · 없으면 한 줄 물어본다 |
| 톤·금기어 | `brand/tone.md` · 없으면 `brand/profile.md` 의 톤 |
| 기존 계열 | `brand/profile.md` 의 제품 라인업 |

## A 브랜드 (샘플)

- 수분 세럼 30ml 39,000원 · 27~38세 민감성 피부 · 3스텝 루틴
- 012 원라이너: "더 넣지 않아서 순한 세럼. 민감 피부의 3스텝 루틴."
- 이번에 이름을 지을 것: **입문용 2주 어댑팅 세럼 15ml** (011 B안)

## 바꿔서 해 보기

- 「기존 계열 확장이야」라고 말해 본다 → 접두·접미 패턴을 맞춘 후보만 나온다
- 「금기어: 닥터, 더마」라고 붙여 본다 → 그 계열 후보가 생성 단계에서 빠진다
- 이름만 주고 「검색 오염도만 봐줘」라고 해 본다 → 기존 제품명 진단으로 쓸 수 있다

## ⚠️ 이 스킬이 하지 않는 것

**상표를 검색해 주지 않는다.** 등록 가능 여부도 말하지 않는다.
어디서(키프리스) 무엇을(동일·유사 호칭, 니스 분류) 확인하는지까지만 붙여 준다.
출원 전 변리사 검토는 대체되지 않는다.
