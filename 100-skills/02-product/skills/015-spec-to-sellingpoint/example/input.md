# 실습 입력 · 015 제품 스펙시트 → 셀링포인트

아래 한 줄을 클로드에게 그대로 말하면 된다.

```
sample-data/A브랜드-상세페이지.md 로 셀링포인트 뽑아줘
```

리뷰까지 같이 주면 결과가 달라진다. **이 실습의 핵심이 그 차이다.**

```
sample-data/A브랜드-상세페이지.md 와 sample-data/A브랜드-리뷰-200건.csv 로 셀링포인트 뽑아줘
```

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 스펙 | `sample-data/A브랜드-상세페이지.md` | 묻고 멈춘다 |
| 고객 언어 | `sample-data/A브랜드-리뷰-200건.csv` | `[작성]` 태그를 달고 창작한다 |
| 타깃 | `brand/profile.md` | A 브랜드 기본 타깃 (27~38세 민감성) |

## 두 번 돌려서 비교하기

| 리뷰 없이 | 리뷰와 함께 |
|---|---|
| `[작성]` "속당김이 안 와요" | 리뷰 #41 "환절기에 뒤집어지는 게 줄었어요" |
| 그럴듯하지만 **내가 지은 말** | 고객이 실제로 쓴 말 · 출처가 있음 |

상세페이지에 쓸 수 있는 건 오른쪽이다. 왼쪽은 시안이고, 오른쪽은 근거다.

## 바꿔서 해 보기

경쟁품 리뷰를 넣어 본다. 4단계가 **경쟁품 불만을 자사 장점 카피로 뒤집는다.**
`sample-data/경쟁사-3곳.md` 의 B사 약점("사용감이 무겁다")을 넣으면
그게 A 브랜드의 소구점이 되어 돌아온다.
