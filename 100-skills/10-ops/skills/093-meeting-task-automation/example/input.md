# 실습 입력 · 093 회의록·업무 위임 자동화

```
이 회의 정리해줘
```

## 담당이 불명확하면 「미정」이다

아무에게나 귀속시키면 **그 사람은 자기가 맡은 줄 모르고**,
회의록만 완성돼 보인다. 회의록의 실패는 이 한 칸에서 난다.

## 086 과의 경계

| | **093** | 086 |
|---|---|---|
| 대상 | **내부 회의** | 고객·파트너 미팅 |
| 산출 | 태스크 배분표 | 팔로업 메일 |

대외 미팅으로 판별되면 **086 으로 핸드오프**한다.

## 2회 이상 이월은 ⚠️

이전 회의록을 같이 주면 미결 추적이 켜진다.
2회 이상 이월된 항목은 **다음 회의 첫 안건**으로 올린다.

## 바꿔서 해 보기

- 이전 회의록을 같이 줘 본다 → **미결 추적표**가 생기고 이월 횟수가 세어진다
- 고객 미팅 메모를 넣어 본다 → 086 으로 안내하고 끝난다
