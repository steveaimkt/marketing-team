# 실습 입력 · 096 경쟁 입찰·견적 비교기

```
이 견적서들 비교해줘
```

## 「일식(一式)」을 찾는다

계약 후 추가 청구가 대부분 그 줄에서 나온다.

| 뭉뚱그림 신호 | 대응 |
|---|---|
| 일식(一式) | **항목 분해 요구** |
| 기타 제반 비용 | 분해 요구 |
| 협의 후 결정 | 상한선 요구 |

## VAT 부터 통일한다

업체마다 포함·별도가 다르면 **10% 차이가 실력 차이로 보인다.**
공급가액 기준으로 맞추고 시작한다.

## 3종 스캔

| 종류 | 무엇 |
|---|---|
| **누락** | 한 업체에만 없는 항목 (**계약 후 추가 청구 1순위**) |
| **과다** | 동일 항목 단가가 타사 대비 +50% 이상 |
| **뭉뚱그림** | 일식 · 기타 |

## 바꿔서 해 보기

- 견적서를 1개만 줘 본다 → **비교가 아니라 항목 검증 모드**로 바뀐다
- 094 브리프를 같이 줘 본다 → 브리프의 산출물 명세가 **정렬 기준 축**이 된다
