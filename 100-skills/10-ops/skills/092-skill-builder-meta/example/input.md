# 실습 입력 · 092 나만의 스킬 만들기

```
이 업무로 스킬 만들어줘
```

## 전 과정을 스킬로 만들지 않는다

「콘텐츠 기획부터 발행까지」는 스킬이 아니라 **여러 스킬의 체인**이다.
**가장 자주 하고 가장 아픈 한 스텝**으로 좁힌다. 작게 끝내야 성공 경험이 생긴다.

## 그릇 판정

| 성격 | 그릇 |
|---|---|
| 절차 고정 | **스킬** |
| 판단·다단계 | 에이전트 체인 |
| 상시 감시 | 스케줄 결합 |

스킬 그릇이 아니면 **그 사실과 대안을 알려준다.**

## 사람 게이트가 0개면 넣는다

발행·발송·확정 직전에 최소 1개.
**게이트 없는 스킬은 사고를 자동화한다.**

## 바꿔서 해 보기

- 「전 과정」이라고 말해 본다 → 한 스텝으로 좁히자고 되묻는다
- 잘된 결과물 예시를 3개 줘 본다 → **공통 구조**가 추출되어 Output Format 이 정확해진다
