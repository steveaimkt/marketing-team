# 실습 입력 · 095 마케팅 예산 플래너

```
다음 분기 예산 짜줘
```

## 실험 예산을 따로 뗀다

성과 데이터가 없는 채널을 기존 채널과 같은 잣대로 배분하면
**영원히 안 써 보게 된다.** 총 예산의 **10~20%** 를 실험으로 분리한다.

## 손익분기 ROAS 는 계산된다

```
손익분기 ROAS = 1 ÷ 마진율
```

마진율만 알면 나온다. `brand/profile.md` §4 에 기록해 두면
041~046 전 스킬이 재사용한다.

## 조정은 산식으로만

배분표를 사용자가 고칠 때 **수치를 임의로 바꾸지 않는다.**
가중치나 목표값을 바꿔서 산식이 다시 계산되게 한다.
그래야 왜 그 숫자인지가 남는다.

## 바꿔서 해 보기

- 마진율 52%를 넣어 본다 → 손익분기 ROAS 1.92 가 자동 계산된다
- 성수기 가중치를 빼 본다 → 월별 캐시플로가 평평해지고 **마이너스 월이 사라진다** (그게 함정이다)
