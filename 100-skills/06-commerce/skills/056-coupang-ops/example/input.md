# 실습 입력 · 056 쿠팡 로켓·마켓플레이스 운영

```
쿠팡 운영 점검해줘
```

## Wing 에서 받아야 할 파일

| 파일 | 필수 | 쓰는 곳 |
|---|---|---|
| `*DAILY*SUMMARY*METRICS*` | ✅ | 일별 판매·소진 예상 |
| `*VENDOR*ITEM*METRICS*` | ✅ | 상품별 아이템위너·전환 |
| 재고 파일 | 권장 | ROP·발주일 역산 |
| 광고 리포트 CSV | 선택 | 041 로 넘긴다 |

두 필수 파일이 없으면 체크리스트 정성 모드(`[추정]`)로 간다.

## ⚠️ 마진 하한선을 깨야 위너를 되찾는 상황이면

**가격 인하를 제안하지 않는다.** 그 위너는 되찾아도 남는 게 없다.
배송(로켓 전환)·재고(품절 이력)·리뷰 쪽으로 방향을 돌린다.

아이템위너는 가격만으로 정해지지 않는다. 그래서 가격이 유일한 답인 경우가 드물다.

## 바꿔서 해 보기

- 재고를 아주 적게 줘 본다 → ROP 도달 상품이 늘고 **발주가 액션 1순위**로 올라온다
- 취소율을 6%로 올려 본다 → 위험 신호가 잡히고 **가격보다 배송이 먼저** 나온다
