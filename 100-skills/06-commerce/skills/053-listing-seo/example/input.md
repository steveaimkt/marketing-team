# 실습 입력 · 053 상품명·검색 최적화

```
상품명 최적화해줘. 쿠팡이랑 스마트스토어
```

## 플랫폼마다 규칙이 다르다

| 플랫폼 | 조합 공식 | 싫어하는 것 |
|---|---|---|
| 쿠팡 | 브랜드 + 제품명(모델) + 유형 + 속성 | **수식어 · 중복 키워드** |
| 스마트스토어 | 브랜드 + 제품명 + 핵심 키워드 + 속성 | **키워드 반복 페널티** |

같은 이름을 양쪽에 쓰면 한쪽이 손해를 본다. 그래서 이 스킬은 **플랫폼별로 3안씩** 낸다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 유입 검색어 | 쿠팡 키워드 리포트 · 스토어 통계 | 카테고리 연관어 `[추정]` |
| 상품 속성 | 발화 · `brand/profile.md` | 묻는다 |

## ⚠️ 상품명을 바꾸면 순위가 초기화될 수 있다

기존 상품이 이미 상위에 있으면, 이름을 바꾼 뒤 며칠~몇 주간 순위가 흔들린다.
**신규 등록이면 자유롭게, 기존 상품이면 성수기를 피해서.** 산출물에 함께 안내한다.

## 바꿔서 해 보기

- 유입 검색어 데이터를 줘 본다 → 우선순위표가 `[추정]` 에서 실측으로 바뀐다
- 「자사몰만」으로 해 본다 → 플랫폼 규칙이 아니라 **구글 SEO** 기준으로 바뀐다
