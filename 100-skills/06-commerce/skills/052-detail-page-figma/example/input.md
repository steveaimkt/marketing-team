# 실습 입력 · 052 상세페이지 → Figma 자동화

```
이 기획서로 피그마 시안 만들어줘
```

## ⚠️ 051 기획서가 없으면 멈춘다

여기서 카피를 즉석으로 만들면 디자인은 나온다. 그런데
**그 카피가 어디서 왔는지 아무도 모른다.** 규제 검사도 안 거쳤다.

051 → 052 순서를 지키는 이유다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 24섹션 기획서 | 051 산출물 | **묻고 멈춘다** |
| 브랜드 컬러 | `brand/profile.md` | 제품 이미지에서 추출 · 칩으로 확인받는다 |
| 제품 이미지 | 발화 | 플레이스홀더로 두고 표시 |
| 피그마 연결 | MCP | **HTML 폴백 시안** + 그 사실 명시 |

## ⏸ 승인 전에 피그마에 쓰지 않는다

`mutating: true` 스킬이다. 프레임 목록·컬러·타이포를 먼저 요약해 보여 주고
승인을 받은 뒤에만 실제로 만든다. 24개 프레임을 잘못 만들면 지우는 게 더 오래 걸린다.

## 바꿔서 해 보기

- 제품 이미지를 줘 본다 → 컬러가 이미지에서 추출되고 팔레트가 바뀐다
- 「HTML 로 줘」라고 해 본다 → 피그마를 건너뛰고 바로 시안 파일이 나온다
