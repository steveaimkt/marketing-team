# 실습 입력 · 051 상세페이지 24섹션 빌더

```
상세페이지 만들어줘. 제품은 A 브랜드 수분 세럼
```

앞 스킬 산출물이 있으면 훨씬 좋다.

```
015 셀링포인트랑 012 가치제안으로 상세페이지 만들어줘
```

## 24섹션은 순서가 고정이다

검증된 구조라 바꾸지 않는다. 재료가 부족하면 **섹션을 비우고 비었다고 적는다.**
순서를 흐트러뜨리는 대신 결손을 드러내는 쪽을 택한다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 셀링포인트 | 015 산출물 | 스펙에서 직접 뽑고 근거 표기 |
| 가치제안 | 012 산출물 | 01·02 섹션이 약해진다 |
| VoC | `sample-data/A브랜드-리뷰-200건.csv` | 20 후기 섹션이 `[작성]` 이 된다 |
| **업종** | `brand/profile.md` | **묻고 멈춘다** · 규제 사전을 못 고른다 |
