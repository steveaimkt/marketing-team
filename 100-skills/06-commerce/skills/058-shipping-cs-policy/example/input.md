# 실습 입력 · 058 배송·CS 정책 설계

```
반품 교환 정책 만들어줘
```

## 먼저 묻는 두 가지

1. **소모품인가**
2. **개봉하면 재판매가 안 되나**

이 답이 반품 정책 전체를 정한다. 화장품처럼 개봉 시 재판매가 불가능한 상품은
법정 청약철회 예외에 해당할 수 있는데, **예외를 쓰려면 사전 고지**가 있어야 한다.

## ⛔ 쓸 수 없는 말

| 표현 | 왜 |
|---|---|
| "환불 절대 불가" | 전자상거래법상 청약철회권을 배제할 수 없다 |
| "단순 변심 반품 불가" (고지 없이) | 예외를 쓰려면 **사전 고지 + 개별 확인**이 필요 |
| "교환만 가능" | 요건 충족 시 환불을 막을 수 없다 |

이런 표현이 있으면 **전달 전에 멈춘다.**

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 상품 특성 | 발화 | **묻고 멈춘다** |
| 물류 조건 | 발화 | 왕복 배송비 칸을 비운다 |
| 플랫폼 | 발화 | 자사몰 기준 + **플랫폼 우선 항목 표시** |

## 바꿔서 해 보기

- 「설치형 상품」이라고 해 본다 → 설치 후 반품 조항이 추가된다
- 「쿠팡에도 판다」고 해 본다 → **플랫폼 정책이 자체 정책보다 우선하는 항목**이 표시된다
