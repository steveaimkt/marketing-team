# 실습 입력 · 059 크라우드펀딩 페이지 빌더

```
와디즈 펀딩 페이지 써줘
```

## 5막 중 2막이 심장이다

| 막 | 목적 | 분량 |
|---|---|---|
| 1 문제 | 공감 후킹 | ~15% |
| **2 여정** | **메이커 신뢰** | ~20% |
| 3 해결 | 제품 설명 | ~30% |
| 4 증거 | 검증·시연 | ~20% |
| 5 리워드·약속 | 전환 | ~15% |

펀딩은 **완성품이 아니라 만드는 사람에게 돈을 거는 것**이다.
그래서 2막(개발 계기·실패담·제작 과정)이 없으면 페이지가 그냥 상세페이지가 된다.

**소재가 없으면 지어내지 않고 비운다.** 지어낸 창업 스토리는 댓글에서 걸린다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 목표 금액·원가 | 발화 | **묻고 멈춘다** (리워드 사다리를 못 짠다) |
| 메이커 스토리 | 발화 | **2막을 비우고 비었다고 표시** |
| 규제 | `brand/profile.md` 업종 | 묻는다 |

## 바꿔서 해 보기

- 실패담을 하나 줘 본다 → 2막이 살아나고 **페이지 전체의 신뢰도가 달라진다**
- 목표 금액을 10배로 올려 본다 → 리워드 사다리 단수가 늘고 **얼리버드 수량 설계**가 바뀐다
