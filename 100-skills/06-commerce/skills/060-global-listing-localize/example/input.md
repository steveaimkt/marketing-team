# 실습 입력 · 060 글로벌 리스팅 로컬라이즈

```
이 상세페이지 미국 아마존용으로 바꿔줘
```

## 번역이 아니라 소구점 재구성이다

| 원본 (KR) | US | JP |
|---|---|---|
| 감성 공감 도입 ("이런 고민 있으시죠") | **기능·수치 선행** | 불안 해소·안심 |
| "판매 1위" | 리뷰·평점 근거 (증빙 가능 시만) | 수상·인증 이력 (문서 병기) |
| 긴 스토리텔링 | **불릿 5줄** | 상세하되 정중하게 |

한국형 감성 도입부를 그대로 번역하면 미국 리스팅에서는 스크롤 이탈이 난다.
**같은 제품을 다른 순서로 파는 일**이다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 원본 | 051 산출물 우선 | 기존 페이지 텍스트 |
| **대상 마켓** | 발화 | **묻고 멈춘다** (마켓마다 소구·규제가 다르다) |
| 인증 현황 | `brand/profile.md` | **미보유 가정** · 관련 문구 전부 `[확인 필요]` |

## ⚠️ 현지 규제 확인은 사람 몫이다

미국 FDA 화장품 표시 규정, 일본 약기법 등은 **마켓마다 다르고 자주 바뀐다.**
이 스킬은 위험 구간을 표시할 뿐, 통과를 보장하지 않는다.

## 바꿔서 해 보기

- 「일본 아마존」으로 바꿔 본다 → 같은 제품인데 **소구 순서가 통째로 바뀐다**
- 인증 보유를 알려 준다 → `[확인 필요]` 가 줄고 쓸 수 있는 문구가 늘어난다
