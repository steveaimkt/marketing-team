# 실습 입력 · 036 커뮤니티 운영 플레이북

```
디스코드 커뮤니티 구조 짜줘
```

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 목적 1개 | 발화 | 팬덤·소속감 |
| 플랫폼 | 발화 | 목적 기준으로 추천하고 **이유를 적는다** |
| 운영자 수 | 발화 | **1명** |

## 운영자 수가 채널 수를 정한다

| 플랫폼 | 언제 고르나 |
|---|---|
| 디스코드 | 실시간 · 세분 채널 · 역할 권한이 필요할 때 |
| 네이버 카페 | **검색 유입**과 아카이브가 자산일 때 |
| 오픈채팅 | 진입장벽을 최소로 · 단일 방으로 충분할 때 |

운영자가 1명인데 채널을 8개 만들면 **6개가 2주 만에 죽는다.**
죽은 채널이 보이는 커뮤니티는 새로 온 사람에게 "여기 망했나"로 읽힌다.

## 바꿔서 해 보기

- 「목적은 고객 지원」으로 바꿔 본다 → 질문·FAQ 채널이 앞으로 나오고 잡담이 뒤로 간다
- 「예상 500명」이라고 해 본다 → 모더레이터 위임 단계가 로드맵에 추가된다
