## ⚠️ 위기 키워드가 걸리면 그 건은 멈춘다

| 계열 | 키워드 예 |
|---|---|
| 법적 | 고소 · 소송 · 변호사 · 공정위 · 소비자보호원 |
| 언론·확산 | 기자 · 제보 · 커뮤니티에 올린다 · 좌표 |
| 안전·신체 | 부작용 · 알레르기 · 병원 · 다쳤 |
| 분쟁 반복 | 환불 3회 이상 언급 · 같은 계정 반복 항의 |

여기 걸린 건은 **초안을 만들지 않는다.** 089 로 넘기고 사람이 먼저 본다.
자동 응대가 나가는 순간 "브랜드가 공식적으로 이렇게 답했다"가 되기 때문이다.

## 공개 댓글과 DM 을 나눠 쓴다

| | 공개 댓글 | DM |
|---|---|---|
| 목적 | **보고 있는 다른 사람들** | 그 사람의 문제 해결 |
| 길이 | 2~3줄 | 필요한 만큼 |
| 내용 | 사과 + 채널 이동 안내 | 구체적 조치 |

## 바꿔서 해 보기

- 악성 댓글을 하나 넣어 본다 → 공개 댓글은 **짧아지고 논쟁하지 않는다**
- 「유튜브야」라고 채널을 바꿔 본다 → 고정 댓글 활용 안내가 붙는다
