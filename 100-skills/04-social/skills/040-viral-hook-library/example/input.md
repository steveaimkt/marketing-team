# 실습 입력 · 040 바이럴 훅 라이브러리

```
이 주제로 훅 10개 뽑아줘. 3시간 → 12분
```

## ⏸ 수치가 없으면 멈춘다

훅은 **뒤에 오는 내용이 감당할 수 있어야** 한다.
감당 못 하는 훅은 클릭을 얻고 신뢰를 잃는다. 그래서 이 스킬의 첫 질문은
"이 훅이 감당할 수치·결과물이 뭔가"다.

## 채널이 훅의 형태를 정한다

| 채널 | 훅의 자리 | 길이 |
|---|---|---|
| 쇼츠·릴스 | 첫 **3초** | 한 문장 |
| 피드 (인스타) | 캡션 첫 줄 | 20자 |
| 텍스트 (링크드인·스레드) | 첫 줄 | 25자 |
| 롱폼 (유튜브·블로그) | 첫 15초 · 첫 문단 | 3문장 |

## 바꿔서 해 보기

- 「롱폼」으로 바꿔 본다 → 한 문장이 아니라 **3문장 구조**로 나온다
- 수치를 빼고 결과물만 줘 본다 → 수치 기반 패턴 3~4개가 비고 **왜 비었는지가 적힌다**
