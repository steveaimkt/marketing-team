# 실습 입력 · 033 인플루언서 발굴·평가

```
인플루언서 후보 평가해줘. 카테고리 민감성 스킨케어, 예산 월 300만원
```

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 후보 계정 | 발화 | 규모 구간부터 제안 (기본 마이크로) |
| 계정 수치 | 캡처·수기 입력 | 공개 프로필 기준 `[추정]` · **먼저 고지** |
| 경쟁사 3사 | `brand/profile.md` | `sample-data/경쟁사-3곳.md` |

## 팔로워는 공개돼 있고 참여율은 아니다

진성도 채점 50점 중 35점이 **참여율과 댓글 질**이다.
이 둘은 인사이트 캡처가 없으면 정확히 못 본다.
그래서 「팔로워 10만」만 보고 고르면 진성도 0점짜리를 뽑는 일이 생긴다.

| 규모 | 참여율 만점 기준 |
|---|---|
| 나노 (1천~1만) | 5% 이상 |
| 마이크로 (1만~10만) | 3% 이상 |
| 미드 (10만~50만) | 2% 이상 |

## 바꿔서 해 보기

- 「나노만」으로 좁혀 본다 → 같은 예산으로 후보 수가 6배가 된다
- 팔로워 급증 구간이 있는 계정을 넣어 본다 → **성장 곡선 감점 + 원인 확인 항목**이 붙는다
