# 실습 입력 · 031 인스타그램 피드 기획

```
인스타 다음 달 피드 기획해줘
```

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 계정 목적 | 발화 | 팔로워 성장 |
| 사진 자산 수준 | 발화 | 보유 컷만 있다고 보고 배치 |
| 톤·금기어 | `brand/tone.md` | A 브랜드 기본 |

## 9칸 단위로 본다

인스타는 개별 게시물이 아니라 **프로필 그리드 9칸**으로 먼저 읽힌다.
그래서 이 스킬은 배치 패턴을 먼저 승인받고 30일치를 그 위에 얹는다.

| 패턴 | 언제 |
|---|---|
| 체커보드 (비주얼 ↔ 텍스트 교차) | 정보성 계정 |
| 세로 열 고정 (가운데 열 = 메시지) | 브랜드 메시지 계정 |
| 가로 줄 테마 (3칸 = 한 캠페인) | 제품 런칭 계정 |

## 바꿔서 해 보기

- 「판매 목적」으로 바꿔 본다 → 제품·오퍼 비중이 20%에서 30%로 오른다 (**연속 배치는 여전히 금지**)
- 「촬영 못 해」라고 말해 본다 → 텍스트 카드·후기 캡처 위주로 유형이 재배합된다
