# 실습 입력 · 029 스레드 콘텐츠 팩

```
스레드 5편 써줘. 주제 〈리뷰 200건 분석〉, 목적은 대화 유발
```

## 목적이 CTA 를 정한다

| 목적 | 5편 CTA |
|---|---|
| 팔로우 확보 | "이런 거 더 올립니다" |
| **대화 유발** (기본) | 질문으로 닫는다 |
| 유입 | 리플에 링크 (본문엔 안 넣는다) |

목적을 안 정하면 **대화 유발**로 간다. 스레드는 링크를 본문에 넣으면 도달이 떨어지기 때문에,
유입 목적이어도 링크는 리플로 내려간다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 주제 | 발화 | 묻는다 |
| 숫자·경험 소재 | 발화 · 027 코어 카드 | 훅이 약해진다 (`[추정]` 안 씀) |
| 톤 | `brand/tone.md` | 해요체 |

## 바꿔서 해 보기

- 「팔로우 확보 목적」으로 바꿔 본다 → 5편 CTA 와 후속 리플이 통째로 바뀐다
- 편수를 3편으로 줄여 본다 → **아크가 안 닫힌다는 경고**가 먼저 온다 (5편이 최소 단위인 이유)
