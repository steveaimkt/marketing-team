# 실습 입력 · 022 블로그 SEO 아티클

```
「민감성 피부 세럼」 키워드로 블로그 글 써줘
```

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 키워드 | 발화 · 또는 001 산출물 | **묻고 멈춘다** |
| 검색의도 | 001 산출물의 의도 칸 | 형태소로 추정 + `[추정]` |
| 톤·금기어 | `brand/tone.md` | A 브랜드 기본 톤 |
| 규제 검사 | `100-skills/gates/compliance-gate.md` | 자동 · 생략 불가 |

## 게이트가 두 개다

| 게이트 | 누가 | 언제 |
|---|---|---|
| 대화형 게이트 | **사람** | 키워드 확인 · 의도 확인 · 발행 전 |
| 컴플라이언스 게이트 | **자동** | 마지막에 한 번 · ⛔ 면 전달 자체를 막는다 |

화장품 카테고리는 후자에 자주 걸린다. "개선·재생·완화"가 본문에 들어가면 잡힌다.
**걸리는 게 정상이고, 걸린 걸 고쳐서 통과시키는 것까지가 이 스킬이다.**

## 바꿔서 해 보기

- 「세럼 추천」으로 바꿔 본다 → 의도가 **비교형**으로 판정되고 구조가 비교표 중심으로 바뀐다
- 「A브랜드 수분세럼」으로 바꿔 본다 → **탐색형**이 되어 공식 정보 정리형 구조가 나온다
