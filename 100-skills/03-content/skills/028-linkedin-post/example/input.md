# 실습 입력 · 028 링크드인 포스트 빌더

```
링크드인 글 써줘. 주제 〈마케터가 리뷰 분석에 쓰는 시간〉
```

숫자 대조 소재가 있으면 같이 주는 게 훨씬 낫다.

```
링크드인 글 써줘. 주제 〈리뷰 분석 시간〉, 3시간 → 12분
```

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 포지셔닝·경력 근거 | `brand/profile.md` | A 브랜드 기본 |
| 숫자 대조 소재 | 발화 | **그 블록을 뺀다** (지어내지 않는다) |
| 목적 | 발화 | 인지도 |

## 형식이 곧 내용이다

링크드인은 **모바일에서 3줄만 보이고 나머지는 「더 보기」에 접힌다.**
그래서 이 스킬은 훅 1줄 + 숫자 예고 2줄에 전부를 건다.
산문 문단을 쓰면 접힌 뒤를 아무도 안 편다. ❶❷❸ 이 규칙인 이유다.

## 바꿔서 해 보기

- 「교육 신청 목적」이라고 붙여 본다 → CTA 가 댓글 유도에서 신청 유도로 바뀐다
- 숫자를 빼고 돌려 본다 → **Before→After 블록이 통째로 사라진다.** 빈 자리를 채우지 않는다
