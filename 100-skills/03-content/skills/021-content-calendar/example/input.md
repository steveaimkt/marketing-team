# 실습 입력 · 021 콘텐츠 캘린더 빌더

```
다음 달 콘텐츠 캘린더 짜줘
```

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 채널·톤 | `brand/profile.md` · `brand/tone.md` | A 브랜드 기본 (자사몰·네이버·인스타·뉴스레터·블로그) |
| 채널 실적 | `sample-data/A브랜드-채널성과-90일.csv` | 비중을 균등 배분하고 `[추정]` |
| 글감 | 001 키워드 · 005 트렌드 · 006 리뷰 산출물 | 브랜드 컨텍스트로 채우고 `[추정]` |

## 캐파부터 답한다

이 스킬은 **주에 몇 편 낼 수 있는지**를 먼저 묻는다. 안 답하면 채널당 주 2편으로 잡는다.
숫자를 부풀리면 예쁜 캘린더가 나오고, 둘째 주에 무너진다.
**1인 운영이면 주 5편이 현실적인 상한**이라고 보면 된다.

## 바꿔서 해 보기

- 「모집기야」라고 말해 본다 → BOFU(전환) 비중이 20%에서 40%로 올라간다
- 「블로그는 못 해」라고 빼 본다 → 슬롯이 다른 채널로 재배분된다
- 캐파를 주 3편으로 줄여 본다 → **채널이 줄지 않고 편수가 준다.** 어느 채널을 버릴지는 사람이 정한다
