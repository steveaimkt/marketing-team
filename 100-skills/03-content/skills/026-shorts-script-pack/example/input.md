# 실습 입력 · 026 쇼츠/릴스 대본 팩

```
이 대본으로 쇼츠 5개 만들어줘
```

024 를 먼저 돌렸으면 파일을 안 줘도 그 산출물을 원본으로 잡는다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 롱폼 원본 | 024 산출물 · 블로그 글 · 링크 | **묻고 멈춘다** |
| 대상 채널 | 발화 | 쇼츠 기준 |
| 톤 | `brand/tone.md` | A 브랜드 기본 |

## 5개를 어떻게 고르나 (우선순위 고정)

1. Before/After 가 가장 극적인 장면
2. 훅의 최강 문장
3. 실패담·반전
4. 단독으로 성립하는 팁
5. 결과물 시연 장면

**단독으로 성립하는지**가 기준이다. 롱폼을 안 본 사람이 봐도 말이 되어야 한다.

## 바꿔서 해 보기

- 「릴스로」라고 바꿔 본다 → CTA 가 프로필 링크 유도로 바뀌고 해시태그 15~20개가 붙는다
- 「틱톡도 같이」라고 해 본다 → 같은 5개가 채널별 3벌로 나온다 (문법이 다르다)
