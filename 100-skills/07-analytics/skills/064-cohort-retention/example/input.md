# 실습 입력 · 064 코호트·리텐션 분석

```
코호트 분석해줘
```

## 언제 떨어지는지를 찾는다

얼마나 남았는지가 아니라 **어느 시점에 꺾이는지**가 이 스킬의 산출물이다.
꺾임 지점이 처방을 정한다.

| 꺾임 | 해석 | 처방 |
|---|---|---|
| **M+1** | 첫 구매 경험 문제 (온보딩·제품 만족) | 제품·안내 |
| **M+2~3** | 재구매 리마인드 부재 (소진 주기 미대응) | 074 시퀀스 |
| 완만한 지속 하락 | 관계 자산 부재 | 콘텐츠·멤버십 |

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 고객ID · 주문일 · 주문금액 | 주문 CSV | **묻고 멈춘다** (3열이 없으면 못 만든다) |
| 구매주기 | `brand/profile.md` §4 | 데이터 중위값 + `[추정]` |

## ⚠️ 마지막 코호트는 아직 결과가 아니다

7월 코호트는 M+1 까지밖에 못 봤다. **관찰 미성숙**이라 회색으로 두고 해석에서 뺀다.
이걸 섞으면 "최근 코호트가 나쁘다"는 착시가 항상 생긴다.

## 바꿔서 해 보기

- 관찰 기간을 6개월로 줄여 본다 → 회색 코호트가 늘고 **비교 가능한 행이 준다**
- 구매주기를 90일로 줘 본다 → 경과 단위가 월에서 분기로 완화된다
