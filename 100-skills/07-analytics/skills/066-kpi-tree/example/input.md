# 실습 입력 · 066 KPI 트리 설계

```
KPI 트리 만들어줘. 목표는 분기 매출 3억
```

## 곱인지 합인지를 적는다

```
월 매출 = 트래픽 × 전환율 × AOV        ← 곱
트래픽  = 오가닉 + 광고 + CRM           ← 합
```

이걸 안 적으면 검산이 안 되고, 검산이 안 되는 트리는 **숫자 장식**이 된다.

## 임계값은 선행에 민감하게, 후행에 완충을

| 지표 성격 | 임계 |
|---|---|
| 선행 (발행 수 · 광고비 · 발송 수) | **민감하게** · 여기서 울려야 대응 시간이 생긴다 |
| 후행 (매출) | 완충 · 여기서 울리면 이미 늦었다 |

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 목표 | 발화 | **묻고 멈춘다** |
| 현재 지표·소스 | 발화 · `brand/profile.md` §4·§5 | 추세 기준으로만 임계 설계 + 명시 |

## 바꿔서 해 보기

- 「구독 서비스야」라고 해 본다 → 북극성 후보가 **활성 구독자**로 바뀐다
- `brand/profile.md` §4 를 채우고 돌려 본다 → 임계값이 추세 기준에서 **목표 경로 기준**으로 바뀐다
