
## 경영진 요약은 마지막에 쓰고 맨 앞에 둔다

먼저 쓰면 분석 결과가 아니라 **미리 정한 결론**이 된다.
전부 분석한 뒤에 3줄로 줄이고, 그걸 맨 앞에 배치한다.

```
결론 3줄 → 의사결정 요청 (각 근거 1줄) → 다음 달 우선순위 3개
```

## ⏸ 두 번 묻는다

| 묻는 것 | 안 하면 |
|---|---|
| Notion 적재 | **안 한다** · 파일로만 |
| 매월 자동 생성 | **안 건다** |
