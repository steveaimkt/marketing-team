## 구분 읽는 법

| 구분 | 뜻 | 사람이 할 일 |
|---|---|---|
| 📄 파일 | `inputs/` 를 먼저 보고, 없으면 이 폴더의 파일로 완주한다 | 없다 |
| 🔗 앞 단계 | 같은 장 앞 단계가 낸 결과를 읽는다 | 없다 |
| 🗣 대화 | AI 마케터가 묻는 것에 답하는 것이 입력이다 | 답한다 |
