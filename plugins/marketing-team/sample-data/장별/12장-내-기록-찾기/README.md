# 12장-내-기록-찾기 · 실습 자료

> 12장 「내 기록을 찾아 다음 업무에 쓰기」는 **과거에 만든 산출물과 실행 기록**을 다시 읽어
> `brand/my-playbook.md`에 기준으로 적는 장이다. 이 폴더는 그 두 가지 자료를 담는다.

| 자료 | 무엇인가 | 12장의 어느 사례에 쓰나 |
|---|---|---|
| `../../build-log-sample.md` | 실행 기록(원장) 36행 · 요청·게이트·보완 횟수 열만 있다 | 되풀이된 **업무**를 묶는 사례(091·098) |
| `산출물-9건/` | 서로 다른 스킬 9개가 낸 산출물 9건 · 각 파일 맨 아래 `### 부족한 것` | 되풀이된 **부족한 것**을 모아 「보완 목록」을 만드는 사례 |

## 왜 따로 있나

`build-log-sample.md`는 원장이다 — 일시·스킬 ID·게이트·보완 횟수만 있고 산출물 **내용**(맨 아래 "부족한 것")은 담지 않는다.
12장이 서술하는 두 번째 사례("산출물 9건의 맨 아래 '부족한 것'을 모아 겹치는 대목을 보완 목록으로 적는다")는
원장만으로는 재현되지 않는다 — 그래서 산출물 9건을 이 폴더에 최소 형태로 추가했다.

## `산출물-9건/` 구성

| # | 스킬 | 맨 아래 「부족한 것」 |
|--:|---|---|
| 1 | 043 메타 광고 카피 작성 | **고객 유형 정리** 없음 |
| 2 | 045 광고 주간 성과 분석 | **고객 유형 정리** 없음 |
| 3 | 051 상세페이지 기획 | **고객 유형 정리** 없음 |
| 4 | 067 월간 마케팅 성과 분석 | **고객 유형 정리** 없음 |
| 5 | 006 소비자 리뷰 분석 | **고객 유형 정리** 없음 |
| 6 | 022 블로그 글 작성 | 내부 링크 부족 (무관) |
| 7 | 031 인스타그램 피드 기획 | 해시태그 세트 부족 (무관) |
| 8 | 083 보도자료 작성 | 담당자 인용문 확인 필요 (무관) |
| 9 | 065 고객 등급 분석 | 리텐션 목표치 미정 (무관) |

9건 가운데 5건(043·045·051·067·006)이 같은 자리 — **고객 유형 정리** — 를 비워 뒀다.
이 반복을 모으면 담당 스킬 2개가 떠오른다: **008 고객 유형 정리**(페르소나가 없다), **064 재구매 유지율 분석**(고객을 신규·재구매로 못 나눴다).
12장 본문의 "9건 가운데 5건에서 같은 자리가 비면… '스킬 008, 고객 유형 정리'와 '스킬 064, 재구매 유지율 분석'을 하나씩 불러 보완 목록을 채우면" 문장과 건수·스킬 번호가 그대로 맞는다.

`brand/my-playbook.md`의 「4. 보완 목록」 절이 이 결과를 담는 자리다.
