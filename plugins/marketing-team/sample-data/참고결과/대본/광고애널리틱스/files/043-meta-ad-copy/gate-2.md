  1) #10·TOP 1 「없는 성분부터 보세요 / 없는지 확인하고 고르세요」         → 해결
     「뺀 성분 5가지, 이름까지 확인하세요」와 「수분 세럼에 넣지 않은 성분은 … 다섯 가지입니다」로 바뀌었습니다.
     우리가 넣지 않았다는 사실만 말하고, 다른 제품을 고르는 기준으로 내밀지 않습니다.
     D안 칩 5개에 X표나 금지 기호를 쓰지 않는다고 명시한 것도 확인했습니다.
  2) 사양 카드 항목 미지정 (이제 B안)                                     → 해결
     넣는 항목과 넣지 않는 항목(자극 지수·흡수 시간·pH·원가·생산 정보)이 명시되어 있습니다.
     「자극 0.00」과 「흡수 42초」가 광고에 들어갈 길이 막혔습니다.
  3) 무첨가 근거 (원료 규격서)                                              → 미해결 · 아래 A
  4) #8 「페녹시에탄올까지」·「대신 에어리스 차광 용기」                     → 해결
     「왜 전성분이 11종뿐일까 / 넣는 성분 수를 줄였기 때문입니다」로 새로 썼습니다. 성분을 평가하는 말도, 보존제가 없다는 뜻도 없습니다.
  5) #3 「뺄 걸 뺐어요」와 파라벤·페녹시에탄올 나열                          → 해결 (자동 점검 수준)
     본문에서 보존 성분 이름이 빠졌고, 남은 「향료·색소·에탄올은 넣지 않았고」는 사실만 적은 문장입니다.
     A안 이미지 위에는 성분 이름 없이 「전성분 11종」만 올라갑니다.
     「뺄 걸 뺐다」는 브랜드가 쓰던 말이고, 다른 제품을 피하라는 뜻이 없습니다. 이번 판정에서는 걸지 않았습니다.
     외부 광고 심의를 받을 때(스킬 049)에는 이 헤드라인도 함께 보여 주기를 권합니다.

근거 필요 (자료를 확인하기 전에는 집행하지 않음)
  A. 무첨가 표현 전체: #1·#2·#3·#5·#6·#9·#10 본문, #5 헤드라인, #9 헤드라인 「뺀 것 5」,
     B안 카드 「넣지 않은 것」, C안 칩 「#향료_안_넣음」, D안 제목과 칩 5개, F안 「뺀 것」
     "넣지 않았다"는 말은 원료에 섞여 들어오는 것까지 없어야 성립합니다. 원료 규격서가 아직 없습니다.
     근거 없이 집행해서 원료에 섞여 있던 성분이 나오면 사실과 다른 광고가 됩니다. (화장품법 §13①4 · 실증 §14)
     무첨가 표현을 어디까지 허용하는지는 식약처 기준 원문과 대조가 필요합니다. 이 기준은 규제 사전에 아직 없어 「확인 필요」로 둡니다.
     → 필요한 것: 세럼 5가지, 크림 3가지(#6)에 대한 제조사 원료 규격서.

  B. 도착 페이지 대조: 산출물의 확인 목록(#1·#3·#4·#7·#8·#10, 소재 A·D·E)에 빠진 곳이 있습니다.
     - 페이지 내용을 약속하는데 목록에 없는 곳:
       #2 「주요 성분 함량도 숫자로 적었습니다」·CTA 「숫자로 확인하기」,
       #9 CTA 「사양 확인하기」, B안 버튼 「사양 확인하기」
     - CTA가 가리키는 내용도 도착 페이지에 있어야 합니다:
       #1 「뺀 성분 보기」, #3 「뺀 것 보기」, #8 「이유 보기」, #7 「리뷰 먼저 보기」
       입력에서 확인되는 것은 전성분과 함량이 맨 위에 있다는 것뿐입니다. 뺀 성분 목록, 11종인 이유, 리뷰로 곧장 가는 링크가 페이지에 있는지는 확인되지 않았습니다.
     - 「함량」의 범위:
       #3 본문·#10 본문·A안 띠·D안 아래 줄은 「전성분(11종)과 함량」, E안 라벨은 「전성분 11종 · 함량 공개」라고 씁니다.
       이러면 11종 전부의 함량을 공개한다고 읽힙니다. 사양서에 적힌 함량은 주요 성분 3가지뿐입니다(#4·#7·#8은 「주요 성분 함량」으로 정확히 씀).
       상세페이지에 주요 성분 함량만 있다면, 광고가 공개 범위를 부풀린 것이 됩니다. (표시광고법 §3①1·2)
     → 필요한 것: 채널별(자사몰·스마트스토어·쿠팡) 상세페이지 첫 화면 캡처. 11종 전부의 함량이 없으면 해당 문구를 「주요 성분 함량」으로 맞춥니다.

  C. #6 「따로보다 14,000원 가볍게」·「따로 사면 81,000원, 세트는 67,000원」
     광고가 도착하는 채널에서 세럼 39,000원과 크림 42,000원에 실제로 따로 팔고 있어야 비교가 성립합니다. (표시광고법 §3①1·2)
     67,000원은 평소 판매가이므로 실제 행사 기간이 없을 때 마감이나 기간 한정을 붙이면 속이는 광고가 됩니다.
     → 필요한 것: 집행 채널의 개별 판매가 화면.

  D. #7 「산 사람들이 뭐라고 했는지 먼저 보세요」·CTA 「리뷰 먼저 보기」
     광고가 리뷰로 사람을 보냅니다. 거기 체험단 후기가 섞여 있는데 「협찬」 표시가 없으면 이 광고도 함께 걸립니다.
     (표시광고법 §3①2 · 프로필 §6)
     → 필요한 것: 리뷰 영역에 체험단 후기가 있는지, 있다면 협찬 표시가 붙어 있는지 확인한 캡처.
