## 여러 샘플을 함께 쓸 때

이 폴더의 파일은 스킬별 연습을 위해 **서로 독립적으로 만든 합성 데이터**다. 같은 A 브랜드와 같은
기간이 적혀 있어도 주문·매출 합계가 서로 맞는 통합 데이터베이스가 아니다.

특히 아래 셋은 한 조합에서 읽을 수는 있지만 **파일 사이의 합산·나눗셈은 금지**한다.

| 파일 | 2026년 6월 실측 | 쓸 수 있는 범위 |
|---|---:|---|
| `A브랜드-2026-06-매출.xlsx` | 매출 104,890,000원 | 이 파일 안의 상품·채널·요일 비율 |
| `A브랜드-고객마스터.csv` | 주문 491건 · 매출 29,447,800원 | 이 파일 안의 RFM·재구매 비율 |
| `A브랜드-퍼널-가입구매-90일.csv` | 결제완료 623건 | 이 파일 안의 단계 전환율 |

세 수치는 주문 범위와 생성 기준이 달라 정본 관계가 없다. `퍼널 623건 × 고객마스터 AOV`처럼
파일을 넘나드는 계산을 하지 않는다. 조합 실행에서는 `[자료 충돌]`을 먼저 밝히고, 각 파일 안에서
완결되는 비율만 사용한다. 통합 합계가 필요한 실습은 별도의 정합 샘플 팩이 생기기 전까지 지원하지 않는다.

## 왜 이 폴더가 있나

이 시스템의 스킬은 대부분 외부 연결(MCP) 없이 돈다. 그런데 **데이터가 필요한 스킬은 데이터가 없으면 시작을 못 한다.** 광고 리포트를 만들려면 광고 데이터가 있어야 하고, 리뷰를 분석하려면 리뷰가 있어야 한다.

그 자리를 이 폴더가 메운다. **계정을 연결하지 않아도, 회사 데이터를 꺼내지 않아도 실습이 끝까지 간다.**

## 쓰는 법

그냥 부르면 된다. 브랜드 프로필이 비어 있으면 팀이 알아서 이 폴더를 쓴다.

```
리뷰 분석해줘
```

특정 파일을 지정하고 싶으면 이렇게 한다.

```
sample-data/A브랜드-리뷰-200건.csv 로 리뷰 분석해줘
```

## 내 데이터로 바꾸기

`brand/profile.md` 를 내 브랜드로 채우고, 내 파일을 같은 형식으로 넣으면 된다.
그때부터 산출물 태그가 `[샘플]` 에서 `[실데이터]` 로 바뀐다.
