> 브랜드 정보를 안 채웠거나, 회사 데이터를 쓸 수 없을 때 이 폴더가 대신 들어간다.

> 이 데이터로 만든 산출물에는 `[샘플]` 태그가 붙는다.

> 셋 다 지금 스킬이 쓰는 것보다 **모양이 더 맞는다** — 퍼널단계는 CRO 진단(048)에,
> ab테스트는 A/B 판독기(047)에, 스냅샷은 상시 모니터링(003)에. 바꾸려면 그 스킬의
> `sample_fallback` 과 `example/` 을 함께 갈아야 한다. **표에 없는 파일을 만들지 않는다.**

## 왜 이 폴더가 있나

이 시스템의 스킬은 대부분 외부 연결(MCP) 없이 돈다. 그런데 **데이터가 필요한 스킬은 데이터가 없으면 시작을 못 한다.** 광고 리포트를 만들려면 광고 데이터가 있어야 하고, 리뷰를 분석하려면 리뷰가 있어야 한다.

그 자리를 이 폴더가 메운다. **계정을 연결하지 않아도, 회사 데이터를 꺼내지 않아도 실습이 끝까지 간다.**

## 쓰는 법

그냥 부르면 된다. 브랜드 프로필이 비어 있으면 팀이 알아서 이 폴더를 쓴다.

```
리뷰 분석해줘
```

특정 파일을 지정하고 싶으면 이렇게 한다.

```
sample-data/A브랜드-리뷰-200건.csv 로 리뷰 분석해줘
```

## 내 데이터로 바꾸기

`brand/profile.md` 를 내 브랜드로 채우고, 내 파일을 같은 형식으로 넣으면 된다.
그때부터 산출물 태그가 `[샘플]` 에서 `[실데이터]` 로 바뀐다.
