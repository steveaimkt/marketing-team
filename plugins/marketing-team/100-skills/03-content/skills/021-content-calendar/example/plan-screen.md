## 이 예시에서 반드시 지킬 것

- **줄 구성 순서**: 프로필 상태 안내(샘플 사용 고지) → `[실행 계획]` → 계획 표 → 근거로 쓰는 것 →
  채널 믹스 → 주제 근거 → 나오는 곳 → 나오는 형식(+ xlsx 대체 안내) → 멈추는 곳 → "말린다" 경고
  문단 → `[승인 요청]`.
- **"나오는 곳"은 `outputs/{날짜}/021-content-calendar/`까지만 적는다.** 개별 파일 형식은
  "나오는 형식" 줄에서 다룬다.
- **나오는 형식은 반드시 세 가지(표 .csv · 화면 .html · 해설 .md)를 다 적고, `.xlsx`로 바꾸려면
  별도 스킬 설치가 필요하다는 대체 안내를 함께 적는다.**
- **"멈추는 곳: 없음"이라도 이유(사내 기획 문서·대외 발행물 아님 → 규제 검토 대상 아님)를 반드시 함께 적는다.**
  이유 없이 "없음"만 적어 사용자가 검토 자체가 누락됐다고 오해하게 하지 않는다.
- **"말린다" 문단(데이터가 가상 브랜드 숫자라는 경고)은 승인 요청 바로 앞에 온다.** 계획 표 중간에
  끼워 넣지 않는다.
- **계획 검증(plan-compiler) 오류 같은 내부 사정은 이 화면 어디에도 적지 않는다.**
