## 이 예시에서 반드시 지킬 것

- **줄 구성 순서**: `inputs/` 확인 결과 안내 → `[실행 계획]` → 계획 표 → 근거로 쓰는 것(지난 원고
  말투 승계 포함) → 검색의도 추정([추정] 표기) → 멈추는 곳 → 나오는 곳 → 나오는 형식 →
  걸리는 시간 → `[승인 요청]`.
- **`inputs/`에 참고 자료가 이미 있으면 그 사실과 무엇을 이어받는지(말투·구조)를 계획 맨 앞줄에서
  먼저 밝힌다.** 질문 없이 바로 계획으로 들어가도 된다.
- **001(키워드 리서치)을 안 돌렸으면 검색의도를 형태소 추정으로 표기하고 `[추정]` 태그를 단다.**
  근거 없이 단정하지 않는다.
- **멈추는 곳에는 규제 검사 대상(어느 법·어떤 금기어인지)까지 구체적으로 적는다.** "규제 검토함"으로
  뭉뚱그리지 않는다.
- **나오는 형식은 초안(.md)과 넘길 문서(.docx) 두 단계를 순서대로 적는다.** 환경에 문서 변환 도구가
  없어 `.docx`를 못 만드는 경우가 있어도, 계획 화면 자체는 스킬 기본 계약(.md → .docx)을 그대로 적는다.
- **계획 검증(plan-compiler)이나 실행 훅 같은 내부 사정은 이 화면 어디에도 적지 않는다.**
