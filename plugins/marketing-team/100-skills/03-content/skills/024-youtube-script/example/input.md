# 실습 입력 · 024 YouTube 스크립트 (성과 증명형)

```
유튜브 대본 써줘. 주제 〈리뷰 200건을 하루 만에 분석한 방법〉, 증거는 3시간→12분
```

## ⚠️ 증거를 안 주면 멈춘다

이 스킬은 **성과 증명형**이다. 증명할 것이 없으면 성립하지 않는다.
「좋아 보이는 걸 소개하는」 영상이 필요하면 다른 포맷을 권한다.

| 증거로 인정하는 것 | 예 |
|---|---|
| Before/After 수치 | 3시간 → 12분 · 전환 0.8% → 1.4% |
| 만들어진 결과물 | 리포트 파일 · 대시보드 화면 |
| 실측 데이터 | 리뷰 200건 분류 결과 |

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 증거 | 발화 | **묻고 멈춘다** |
| 앵글 | 경쟁 채널 데이터 | 타깃 페인포인트 + `[추정]` |
| 길이 | 발화 | 10분 |

## 바꿔서 해 보기

- 「5분짜리로」라고 줄여 본다 → 섹션이 6개에서 4개로 접히고 DEMO 가 가장 먼저 준다
- 증거를 빼고 돌려 본다 → **대본이 안 나오고 증거를 달라는 말이 온다.** 그게 정상이다
