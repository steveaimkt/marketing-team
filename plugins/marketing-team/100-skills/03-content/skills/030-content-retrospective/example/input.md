# 실습 입력 · 030 콘텐츠 성과 회고

```
sample-data/A브랜드-채널성과-90일.csv 로 지난달 콘텐츠 회고해줘
```

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 채널 성과 | `sample-data/A브랜드-채널성과-90일.csv` | 묻고 샘플로 간다 |
| **콘텐츠별** 성과 | 유튜브 MCP · GA4 · 수기 시트 | `[추정]` + **순위 산정에서 가중 하향** |
| 발행 목록 | 021 캘린더 산출물 | 발행 기록에서 역구성 |

## 채널 데이터만 있으면 절반만 된다

이 실습이 그 경우다. 샘플에는 **채널 단위**만 있고 콘텐츠 단위가 없다.
그래서 산출물의 도달·전환 계층은 실측으로 나오지만
**"어느 글이 이겼나"는 표본 부족으로 판단을 보류**한다.

없는 걸 있는 척 채우지 않는 게 이 스킬의 규칙이다. 그 모양을 보는 게 이 실습의 목적이다.

## 바꿔서 해 보기

- 콘텐츠별 조회수를 표로 붙여 본다 → 「표본 부족」이 사라지고 승자·패자 패턴이 나온다
- 기간을 90일로 넓혀 본다 → 표본이 늘어 4축 중 판단 가능한 축이 늘어난다
