# 실습 입력 · 023 뉴스레터 제작 자동화

```
이번 주 뉴스레터 써줘. 주제는 〈환절기 피부 루틴 3스텝〉
```

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 주제 또는 소스 3~7개 | 발화 | **묻고 멈춘다** |
| 톤·이모지 정책 | `brand/tone.md` | A 브랜드 기본 (이모지는 주제어 옆 1개) |
| CTA 링크 | 발화 | `{링크}` 빈칸으로 두고 표시 |

## ⚠️ 이 스킬은 보내지 않는다

제목 5종을 뽑아 주지만 **고르는 건 사람**이고, 발송은 **074 이메일 시퀀스 빌더**의 일이다.
074 에는 ⏸ 승인 게이트가 따로 있다. 초안 작성과 발송을 한 스킬에 두면
"확인했다"와 "보냈다" 사이가 사라진다.

## 바꿔서 해 보기

- 소스 자료 5개를 링크로 던져 본다 → 큐레이션형으로 구조가 바뀐다
- 「CTA 는 사전예약 페이지」라고 붙여 본다 → 빈칸이 채워지고 BOFU 톤이 된다
- 「이모지 쓰지 마」라고 해 본다 → tone.md 정책을 그 회차만 덮어쓴다
