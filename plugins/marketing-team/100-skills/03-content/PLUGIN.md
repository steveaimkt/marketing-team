# 03-content — 콘텐츠 마케팅

## 이 카테고리가 해결하는 문제
콘텐츠 마케팅의 병목은 아이디어가 아니라 "꾸준한 생산량"이다. 캘린더로 기획하고, 블로그·뉴스레터·유튜브·숏폼을 제작하고, OSMU 변환기로 원본 1개를 N개 채널용으로 증식시켜 제작 단가를 낮춘다. 발행 후에는 성과 회고가 다음 달 주제를 다시 캘린더에 공급하는 순환 구조다.

## 추천 진입 경로
- **대표 체인: 「콘텐츠프로덕션 돌려줘」** — `021 → (022|024) → 027 → 030` (월간 콘텐츠 기획 → 블로그 글 작성 또는 유튜브 대본 작성 → 콘텐츠 채널별 재작성 → 콘텐츠 성과 분석)
  > 슬래시 명령이 아니라 **말**이다. AI 마케터가 순서대로 진행한다.
- **처음이면 021(월간 콘텐츠 기획)부터** — 한 달치 기획이 서면 022·024 제작 스킬이 주제를 골라 쓰기만 하면 된다.
