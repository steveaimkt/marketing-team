# 실습 입력 · 073 고객 여정 정리

```
고객 여정 맵 그려줘
```

## 이 실습의 조건

065 세그먼트 리포트도, 070 NPS 인용도 없다. 게이트 기본값을 그대로 따른다 —
**"전체 고객 기준으로 갈까요?" → 답 없음 → 전체 기준 + `[추정]` 명시**로 완주한다.

`brand/profile.md`가 비어 있어 `sample_fallback`인 `A브랜드-퍼널-가입구매-90일.csv`
(90일치 유입·가입·장바구니·결제시작·결제완료 5열)를 읽는다. 이 열 다섯 개가 이번 여정의 유일한
데이터 근거다.

## 공백을 공백으로 그린다

운영하지 않는 채널은 **「공백」으로 표기**한다.
있는 것처럼 그리면 여정이 매끄러워 보이고, **실제 이탈점은 그 공백에 있다.**
이 파일은 90일 단회 유입→구매 퍼널만 담아 재구매 데이터가 없다 — 재구매 단계는
전 구간이 `[자료 없음]` · 공백으로 남는다.

## 4행 매트릭스

| 행 | 무엇 |
|---|---|
| 행동 | 고객이 실제 하는 일 (데이터 근거) |
| **감정** | −2 ~ +2 (VoC 인용 근거 · 없으면 `[추정]`) |
| 이탈 요인 | 여기서 왜 나가나 |
| 개입 | 무엇을 할 수 있나 |

## "가입" 열이 하는 일

`A브랜드-퍼널-가입구매-90일.csv`의 "가입" 열은 인지→탐색 전환(유입 대비 가입률)을
특정하는 유일한 열이다. 이 열이 없으면 유입 이후 첫 이탈점을 수치로 잡을 수 없다.
