# 실습 입력 · 073 고객 여정 맵핑

```
고객 여정 맵 그려줘
```

## 공백을 공백으로 그린다

운영하지 않는 채널은 **「공백」으로 표기**한다.
있는 것처럼 그리면 여정이 매끄러워 보이고, **실제 이탈점은 그 공백에 있다.**

## 4행 매트릭스

| 행 | 무엇 |
|---|---|
| 행동 | 고객이 실제 하는 일 (데이터 근거) |
| **감정** | −2 ~ +2 (VoC 인용 근거 · 없으면 `[추정]`) |
| 이탈 요인 | 여기서 왜 나가나 |
| 개입 | 무엇을 할 수 있나 |

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 세그먼트 | 065 산출물 | 전체 기준 + `[추정]` |
| VoC | 070·078 · 리뷰 | 감정 행이 전부 `[추정]` |
| 터치포인트 | `brand/profile.md` §5 | 발화 |

## 바꿔서 해 보기

- 065 를 먼저 돌려 본다 → 여정의 **주인공이 「이탈 위험 세그먼트」**로 좁혀진다
- 070 NPS 를 같이 줘 본다 → 감정 행에 실제 인용이 붙는다
