# 실습 입력 · 076 멤버십·등급 제도 설계

```
멤버십 등급제 설계해줘
```

## 등급은 3~4개까지다

5등급을 만들면 고객이 **자기 등급을 기억하지 못한다.**
기억 못 하는 등급은 행동을 안 바꾸고, 혜택 원가만 나간다.

## 상위 등급일수록 경험형으로

| 혜택 유형 | 예 | 원가 |
|---|---|---|
| 비용형 | 할인 · 적립 · 무료배송 | 매출에 비례해 계속 나간다 |
| **경험형** | 선공개 · 전용 상품 · 우선 CS | **한계 원가가 거의 0** |

챔피언에게 할인을 주면 **원래 제값에 살 사람에게 할인을 준 것**이다 (065 참조).

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 세그먼트 | 065 산출물 | ⏸ 선행 권고 · 구매 분포 직접 입력 |
| 마진 구조 | `brand/profile.md` §4 · 017 | 묻는다 |

## 바꿔서 해 보기

- 「5등급으로」라고 해 본다 → 3~4개로 줄이자고 되묻는다
- 할인율을 크게 잡아 본다 → **혜택 원가율이 마진을 넘으면 그 등급을 제안하지 않는다**
