## 이 예시에서 반드시 지킬 것

- **줄 구성 순서**: `[실행 계획]` 제목 → 5단계 작업 표 → 근거로 쓰는 것 → 나오는 곳 → 나오는 형식 →

- **작업 표는 5단계를 다 채운다(집계 → 등급 구조 → 혜택 차등 → 마진 시뮬레이션 → 승급/강등 규칙).**
  결과물 하나로 뭉뚱그리지 않고 만드는 과정을 그대로 보여준다.
- **기본값(등급 수 3개)을 쓰는 이유와, 바꾸고 싶을 때 승인 문장에 어떻게 덧붙이면 되는지를

  같은 안내를 괄호로 반복한다.
- **혜택 원가·할인율처럼 마진에 영향을 주는 산출물이 나올 예정이면, 계획 화면에서 미리 "AI
