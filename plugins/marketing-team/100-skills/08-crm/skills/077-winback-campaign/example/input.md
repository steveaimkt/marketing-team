# 실습 입력 · 077 이탈 고객 되찾기 기획

```
휴면 고객 되살리는 캠페인 만들어줘
```

## 고액 휴면부터 본다

| 축 | 분할 |
|---|---|
| 경과 | 이탈 위험 (P×2) · 휴면 (P×3) |
| 가치 | 고액 (M 상위) · 일반 |

4칸 중 **고액 휴면**이 기본 우선순위다. 복귀 기대 매출이 가장 크다.

## 오퍼가 적자면 제안하지 않는다

되살려서 손해 보면 **안 되살린 것만 못하다.**
할인 폭을 줄이거나, 비용형 대신 경험형(선공개·전용)으로 바꾼다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 코호트 곡선 | 064 산출물 | 중위 재구매 간격 `[추정]` |
| 세그먼트 | 065 산출물 | 주문 데이터에서 직접 |
| **이탈 사유** | VoC · 070 · 078 | 업종 표준 가설 + `[추정]` |

## 바꿔서 해 보기

- 070 NPS 를 같이 줘 본다 → 이탈 사유 가설이 **실제 인용**으로 바뀐다
- 오퍼를 「30% 할인」으로 해 본다 → 실마진 검증에서 **적자 판정**이 나올 수 있다
