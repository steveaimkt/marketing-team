# 실습 입력 · 072 CS 응대 매뉴얼 빌더

```
CS 응대 매뉴얼 만들어줘
```

리뷰 파일로도 연습할 수 있다.

```
sample-data/A브랜드-리뷰-200건.csv 로 응대 매뉴얼 만들어줘
```

## 묻고 멈추는 두 가지

1. **고객센터 연락처·영업시간** — 스크립트에 `{연락처}` 를 남기면 그대로 나간다
2. **환불 자동 처리 상한 금액** — 임의로 정하면 상담원이 그 기준으로 실제 돈을 쓴다

## 3분류

| 분류 | 판별 | 스크립트 길이 |
|---|---|---|
| 악성 🔴 | 욕설 · 법적 언급 · 근거 없는 비방 | **200자** (짧게) |
| 문의 🟡 | 질문형 · 절차 확인 | 300자 |
| 칭찬 🟢 | 만족 · 재구매 의사 | 150자 |

악성 응대가 가장 짧은 이유는 **길수록 논쟁이 되기 때문**이다.
