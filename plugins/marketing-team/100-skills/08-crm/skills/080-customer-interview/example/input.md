# 실습 입력 · 080 고객 인터뷰 스크립트 & 요약

```
고객 인터뷰 질문지 만들어줘
```

## ⏸ 검증할 가설이 없으면 멈춘다

「이것저것 물어보기」는 인터뷰가 아니라 잡담이다.
목적을 **가설 3개 이내**로 압축한 뒤에 질문을 만든다.

## 유도 질문을 걸러낸다

| ❌ 유도 | ✅ 행동·경험 |
|---|---|
| "향이 없어서 좋으셨죠?" | "이 제품을 고르실 때 뭘 보셨어요?" |
| "가격이 부담되진 않으셨나요?" | "마지막으로 화장품 사실 때 얼마쯤 쓰셨어요?" |
| "재구매하실 건가요?" | "지금 쓰시는 게 떨어지면 어떻게 하실 것 같아요?" |

**원하는 답을 듣는 인터뷰는 안 하느니만 못하다.** 그 답으로 의사결정을 하게 되기 때문이다.

## 요약할 때는 인용을 원문 그대로

다듬으면 인용이 아니게 된다. "좀 그랬어요"를 "다소 아쉬웠습니다"로 바꾸면
**그 사람이 얼마나 애매했는지가 사라진다.**
