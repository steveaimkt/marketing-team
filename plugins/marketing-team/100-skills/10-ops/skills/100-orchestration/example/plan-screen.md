# 100 나만의 에이전트 만들기 첫 줄

> 이 스킬은 계획 화면을 내지 않는다. `skills/ai-마케터/SKILL.md` 「⚡ 빠른 진입」의 다섯 조건에 하나도 걸리지 않기 때문이다
> (`mutating: false`, `pii` 없음, 예산과 계약 표현 없음, `review:` 없음). 요청 한 줄 뒤 곧바로 결과 보고로 간다.
> 그래서 「틀」이 없고, `plan-compiler.mjs compile` 도 화면을 찍지 않는다. 대신 결과 첫 줄에 무엇으로 돌았는지 밝힌다.
> 아래 「첫 줄」은 자료 조건마다 AI 마케터가 **한 글자도 바꾸지 않고** 내는 결과 첫 줄이다. `{중괄호}` 자리만 실행 때 채운다.
> 조건 순서는 Phase 3 과 같다. 플레이북이 있으면 플레이북, 없으면 실행 기록, 그마저 없으면 샘플.

## 나

```
나만의 마케팅 에이전트 만들어줘
```

## 첫 줄

```첫줄
플레이북: 나만의 마케팅 에이전트 설계서입니다. brand/my-playbook.md 의 업무 기준으로 돌렸습니다
실행 기록: 나만의 마케팅 에이전트 설계서입니다. brand/my-playbook.md 가 없어 logs/build-log.md 실행 기록 {n}행으로 돌렸습니다
샘플: 나만의 마케팅 에이전트 설계서입니다. 내 실행 기록이 없어 연습용 A브랜드 실행 기록 36행으로 돌렸습니다 (결과에 [샘플])
```
