# 실습 입력 · 091 마케팅 업무 자동화 진단

```
우리 업무 자동화 진단해줘
```

## 효과 = 빈도 × 1회 소요

아파 보이는 일이 아니라 **자주 하는 일**이 위로 온다.
월 1회 3시간(월 3시간)보다 **주 3회 20분(월 4시간)**이 크다.

## 발굴 문답 3개

1. 매주 여는 파일·시트는?
2. 챗봇에 붙여넣었다가 결과를 다시 옮기는 일은?
3. 마감·발행 전에 몰아서 하는 손작업은?

두 번째 질문이 가장 많이 건진다. **이미 AI 를 쓰고 있는데 손으로 옮기는 구간**이
자동화 1순위다.

## 4분면

| | 난이도 하 | 난이도 상 |
|---|---|---|
| **효과 상** | 🥇 **먼저** | 🥈 계획 |
| 효과 하 | 🥉 나중 | ⛔ 안 함 |

## 바꿔서 해 보기

- 업무를 12개까지 늘려 본다 → 4분면이 채워지고 **안 할 것**이 명확해진다
- 아픈 정도를 빼 본다 → 효과 축이 시간만으로 계산되고 `[추정]` 이 붙는다
