# 실습 입력 · 098 주간 업무 정리

```
이번 주 회고하고 다음 주 계획 세워줘
```

## 2주 연속으로 넘어온은 다르게 다룬다

세 번째로 넘어온 것은 대개 **미룰 일이 아니라 중단 대상**이다.
"정말 할 일인가"를 먼저 묻고, 중단·넘김을 우선 검토한다.

## 배움은 행동 문장으로

| ❌ 느낀 점 | ✅ 행동 |
|---|---|
| "시간 관리가 아쉬웠다" | "월요일 리포트를 오전으로 고정한다" |
| "커뮤니케이션이 부족했다" | "수요일에 진행 상황 한 줄을 공유한다" |

## TOP 3 를 넘기지 않는다

네 번째를 적으면 세 개가 밀린다.
018 출시 계획 설계 의 「이번 주 할 3가지」와 같은 원칙이다.

## 바꿔서 해 보기

- 지난주 회고를 같이 줘 본다 → **지난 TOP 3 달성 여부부터 채점**하고 시작한다
- 미완료를 10개 넣어 본다 → 다음 조치표가 길어지고 **중단 후보**가 먼저 제안된다
