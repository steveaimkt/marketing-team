## 이 예시에서 반드시 지킬 것

- **줄 구성 순서**: 계획 표 → 근거로 쓰는 것 → 데이터 모드 → 나오는 곳 → 걸리는 시간 → 멈추는 곳
  → 나오는 형식 → `[승인 요청]`.
- **"데이터 모드"에 `[샘플]`인 이유(현행 링크·GA4 내보내기 없음)와 매핑표를 비운 채로 시작한다는
  점을 함께 적는다.** 채널 목록만 받아도 다시 낼 수 있다는 문장으로 다음 행동을 안내한다.
- **"나오는 곳"과 "나오는 형식"에 산출물이 `.csv`(규칙표·매핑표)와 `.md`(해설·가이드) 두 파일로
  나뉜다는 것을 각각 명시한다.** 하나로 뭉뚱그리지 않는다.
- **"멈추는 곳"이 없어도 왜 없는지(내부 문서, 대외 발행물 아님)를 반드시 병기한다.**
- **계획 검증(plan-compiler) 오류 같은 내부 사정은 이 화면 어디에도 적지 않는다.**
