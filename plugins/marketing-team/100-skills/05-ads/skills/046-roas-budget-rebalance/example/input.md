# 실습 입력 · 046 ROAS 진단

```
sample-data/A브랜드-광고매체통합-12주.csv 로 예산 재배분안 만들어줘
```

## 「잘 되는 데 다 몰아라」가 안 나오는 이유

이 스킬은 **한계 효율**을 따로 본다.
ROAS 가 높은 채널에 예산을 두 배 넣는다고 ROAS 가 그대로 유지되지 않는다.
이미 가장 살 만한 사람에게 다 보여 준 뒤라, 다음 100만원은 더 먼 사람에게 간다.

그래서 시나리오가 **보수·중립·공격 3안**이고, 기본 답이 보수안이다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 채널별 성과 | 041·042·045 산출물 · CSV | `sample-data/A브랜드-광고매체통합-12주.csv` (12주 · 메타·쿠팡·네이버쇼핑·구글 4개 매체) |
| 손익분기 ROAS | `brand/profile.md` §4 | 2.0 폴백 + 명시 |
| 추세 (증액 여력) | 같은 파일의 주차별 흐름 | 12주 안에 있다 — 채널별 지출·ROAS 상관을 직접 본다 |

## 이 샘플의 특징 — 4개 다 파란불도 빨간불도 아니다

BEP 2.0 기준으로 나누면 **🔴(BEP 크게 미달) 채널이 하나도 없다.** 메타(2.08)·구글(1.74)이 BEP 부근 🟡,
쿠팡(3.16)·네이버쇼핑(3.11)이 BEP 초과 🟢 다. "빨간불 예산을 파란불로 옮겨라"는 교과서적 그림이
항상 나오는 게 아니라는 것도 이 실습이 보여 주는 것이다.

## 바꿔서 해 보기

- BEP 를 2.5 로 올려 본다 → 메타·구글이 🔴로 내려가고 "옮길 곳이 뚜렷해진다"
- 최근 4주만 잘라서 돌려 본다 → 12주 전체와 다른 채널 순위가 나올 수 있다 (표본 축소 효과)
