## 틀

```틀
무엇이 나오나: 손익분기 ROAS 기준 매체별 기여 진단표, 예산 재배분 3안(보수·중립·공격), 추천안과 근거
샘플 자료: 연습용 A브랜드 광고 성과 12주치(메타·쿠팡·네이버쇼핑·구글) 48행
걸리는 시간: 2~3분
멈추는 곳 더: 3안을 낸 뒤 어느 안으로 갈지 여쭙습니다. 예산은 옮기지 않고 제안까지만 합니다.
우리 자료 안내: 045 광고 주간 성과 분석 결과가 outputs/에 있으면 그것부터 읽습니다. 매체마다 기간이 같아야 한 표에 합칩니다.
우리 자료로 하려면:
- 메타: 광고 관리자 → 보고서 → 열 선택 → 내보내기 → CSV → inputs/ads-meta-{기간}.csv
- 네이버 검색광고: 광고시스템 → 보고서 → 맞춤 보고서 → 기간 → 다운로드 → inputs/ads-naver-{기간}.csv
- 구글: Google Ads → 캠페인 → 우측 상단 다운로드 → CSV → inputs/ads-google-{기간}.csv
- 쿠팡: 쿠팡 윙 → 광고 관리 → 보고서 → 다운로드 → inputs/ads-coupang-{기간}.csv
- 카카오: 카카오모먼트 → 보고서 → 다운로드 → inputs/ads-kakao-{기간}.csv
함께 알려주면 좋은 것:
- 총 예산: 기본은 지금 쓰는 광고비 총액을 그대로 두고 매체 사이에서만 옮깁니다.
```
