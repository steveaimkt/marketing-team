# 실습 입력 · 044 구글·유튜브 광고 세팅 가이드

```
구글 광고 세팅 어떻게 할지 짜줘. 월 예산 200만원
```

## 예산이 구조를 정한다

| 월 예산 | 구조 | 왜 |
|---|---|---|
| ~100만원 | 검색 2개 (브랜드 방어 + 일반) | **전환 데이터부터 쌓는다.** PMax·유튜브 보류 |
| 100~500만원 | 검색 2개 + PMax 1개 | 검색 전환 월 30건 이상 확보 후 PMax 학습 가능 |
| 500만원~ | + 유튜브 | 인지 확장 |

**PMax 를 먼저 켜는 것이 가장 흔한 실수다.** 전환 신호가 없으면 학습할 게 없어
예산만 태우고 "구글 광고는 안 맞더라"로 끝난다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 목표 · 예산 | 발화 | 전환 · profile.md §4 |
| 랜딩 URL | 발화 | 구조만 설계하고 **품질점수 점검은 보류** |

## 바꿔서 해 보기

- 예산을 80만원으로 낮춰 본다 → **PMax 가 빠진다.** 구조가 단순해지는 게 정답인 구간이 있다
- 「목표는 전환이랑 인지 둘 다」라고 해 본다 → 캠페인을 나눈다고 먼저 고지하고 진행한다
