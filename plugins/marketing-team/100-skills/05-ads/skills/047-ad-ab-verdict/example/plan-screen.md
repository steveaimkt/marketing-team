## 이 예시에서 반드시 지킬 것

- **줄 구성 순서**: 계획 표 → 읽는 자료 → 결론 지표 → 게이트 → 나오는 것 → 나오는 곳 → 나오는
  형식 → 멈추는 곳 → 샘플 데이터 고지 → `[승인 요청]`.
- **"게이트"에 표본→확률 순서를 고정해서 적는다.** 표본 미달이면 확률을 계산하지 않는다는 계약을
  계획 단계에서부터 밝힌다.
- **"결론 지표"는 데이터를 보기 전에 확정한 지표 하나만 적는다.** 매출·광고비가 없어 ROAS를 계산하지
  않는다는 사실도 이 줄에서 함께 밝혀, 나중에 지표를 바꾸지 않는다는 원칙을 계획에서부터 지킨다.
- **샘플 데이터 고지는 "결과에 `[샘플]` 표시가 붙는다"는 문장과 "실제 데이터로 하려면 무엇을 하면
  되는지"를 함께 적는다.**
- **계획 검증(plan-compiler) 오류 같은 내부 사정은 이 화면 어디에도 적지 않는다.**
