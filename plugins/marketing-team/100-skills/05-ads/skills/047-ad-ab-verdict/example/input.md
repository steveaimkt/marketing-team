# 실습 입력 · 047 광고 소재 A/B 분석

```
A/B 결과 결정해줘
```

## ⚠️ 두 군데 이상 다르면 판독을 거부한다

A 와 B 가 헤드라인도 다르고 이미지도 다르면, B 가 앞서도 **왜 앞섰는지 모른다.**
그 결과로 다음 소재를 만들 수 없으니 테스트한 의미가 없다.

이때는 결정하지 않고 **019 A/B 설계**로 되돌려 보낸다.

## 019 와의 경계

| | 019 | **047** |
|---|---|---|
| 언제 | 데이터 생기기 **전** | 데이터 나온 **후** |
| 무엇 | 표본수·기준 설계 | 통계 결론 |

019 설계서를 만들어 뒀으면 그 값(지표·표본·임계)을 그대로 쓴다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 안별 노출(진입)·전환 | 퍼널 분석 도구 · CSV | `sample-data/A브랜드-ab테스트-3건.csv` |
| 결과 기준 | 019 설계서 | CVR · 전환 50건 · 95% |

`sample-data/A브랜드-ab테스트-3건.csv` 에는 테스트가 **3건** 들어 있다. 이 실습은 그중
「결제 단계 배송비 사전 고지」 하나를 판독한다 — 광고비·클릭 열이 없는 **퍼널 CRO 테스트**라
지표는 CVR(구간 통과율) 하나뿐이고 ROAS/BEP 대조는 해당하지 않는다.

## 바꿔서 해 보기

- 같은 파일의 「장바구니 버튼 문구 변경」 테스트를 돌려 본다 → A 856/3,042(28.1%) vs B 831/3,018(27.5%),
  **B 가 오히려 근소하게 낮고 승리 확률도 낮다(≈30%).** 표본은 충분한데 확률이 안 되는 **박빙** 결론이 나온다 —
  모든 테스트가 확정승으로 끝나지 않는다는 걸 보여 준다
- 같은 파일의 「상세페이지 첫 화면 가격·후기 노출」 테스트도 돌려 본다 → A 742/6,180(12.0%) vs B 918/6,204(14.8%),
  이것도 확정승이지만 효과 크기(+23%)가 배송비 테스트(+84%)보다 작다. **셋 다 다른 결론이 나온다는 게 이 파일의 핵심이다**
