## 이 예시에서 반드시 지킬 것

- **재료(카피 원문·업종)가 둘 다 없으면 계획을 내기 전에 먼저 되묻는다.** 대외 발행물 심의 도구라
  재료 확인이 계획보다 앞선다 — 샘플로 가겠다는 답을 받은 뒤에야 아래 계획 화면을 낸다.
- **줄 구성 순서**: 계획 표 → 재료 → 근거로 쓰는 것 → 게재 매체 → 나오는 곳 → 나오는 형식 →
  멈추는 곳 → 걸리는 시간 → 샘플 고지 → `[승인 요청]`.
- **"멈추는 곳"은 "없음"이라도 왜 없는지(사전 검토 도구라 별도 호출 대상이 아님)와 "최종 판단은
  매체 심의"라는 한계를 함께 적는다.** 없음 한 마디로 끝내지 않는다.
- **"게재 매체"에 사용자가 요청한 매체(메타·네이버)를 그대로 되짚어 적는다.**
- **계획 검증(plan-compiler) 오류 같은 내부 사정은 이 화면 어디에도 적지 않는다.**
