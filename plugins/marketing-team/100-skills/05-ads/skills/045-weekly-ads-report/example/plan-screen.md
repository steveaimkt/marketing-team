## 틀

```틀
무엇이 나오나: 매체별 성과를 한 장에 모은 주간 리포트(KPI 카드와 차트 3종), 매체 비교표, 전주 대비 해석
샘플 자료: 연습용 A브랜드 광고 성과 12주치(메타·쿠팡·네이버쇼핑·구글) 48행
걸리는 시간: 3~5분
멈추는 곳 더: 매주 자동 실행도 따로 여쭙고, 답이 없으면 걸지 않습니다. 광고 계정의 캠페인과 예산은 읽기만 하고 바꾸지 않습니다.
체인에서 멈추는 곳 더: 광고 계정의 캠페인과 예산은 읽기만 하고 바꾸지 않습니다.
우리 자료 안내: 파일마다 노출·클릭·비용·전환수·전환매출 열이 있어야 ROAS를 냅니다. 메타 광고 MCP를 연결해 두면 메타는 파일 없이 계정에서 읽습니다.
우리 자료로 하려면:
- 메타: 광고 관리자 → 보고서 → 열 선택 → 내보내기 → CSV → inputs/ads-meta-{기간}.csv
- 네이버 검색광고: 광고시스템 → 보고서 → 맞춤 보고서 → 기간 → 다운로드 → inputs/ads-naver-{기간}.csv
- 구글: Google Ads → 캠페인 → 우측 상단 다운로드 → CSV → inputs/ads-google-{기간}.csv
- 쿠팡: 쿠팡 윙 → 광고 관리 → 보고서 → 다운로드 → inputs/ads-coupang-{기간}.csv
- 카카오: 카카오모먼트 → 보고서 → 다운로드 → inputs/ads-kakao-{기간}.csv
함께 알려주면 좋은 것:
- 보고 기간: 기본은 가장 최근 7일이고, 그 전 7일과 비교합니다.
```
