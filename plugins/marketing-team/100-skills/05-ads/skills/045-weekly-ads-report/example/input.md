# 실습 입력 · 045 광고 주간 리포트 자동화

```
이번 주 광고 리포트 만들어줘
```

## ⏸ 두 번 묻는다

| 묻는 것 | 안 하면 |
|---|---|
| 외부 채널로 보낼까요 | **안 보낸다** · 파일로만 |
| 매주 자동 실행으로 걸까요 | **안 건다** · 1회성 |

`mutating: true` 스킬이다. 밖에 뭔가를 쓴다.
**자동으로 걸린 주간 리포트는 6개월 뒤에도 아무도 안 읽고 계속 온다.**

## 빠진 매체를 적는다

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 메타 | meta-ads MCP | CSV 업로드 |
| 네이버 | 검색광고 API | 광고주센터 CSV |
| 쿠팡 | **공식 MCP 없음** | 키워드 리포트 CSV |

미연결 매체는 **뺐다고 리포트에 적는다.** 안 적으면 그 리포트가 전부인 줄 알게 된다.

## 바꿔서 해 보기

- 매체를 하나만 줘 본다 → 매체 비교표가 사라지고 **"비교 대상 없음"** 이 적힌다
- 지난주 데이터를 같이 줘 본다 → WoW 칸이 `[추정]` 에서 실측으로 바뀐다
