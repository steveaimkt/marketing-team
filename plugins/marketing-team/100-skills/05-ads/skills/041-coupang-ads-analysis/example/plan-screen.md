## 틀

```틀
무엇이 나오나: 광고비·매출·ROAS 요약, 키워드 분류표(효자·양호·잠재·낭비·관찰), 지면별·캠페인별·상품별 상세, 전환 0 키워드 목록, 그래프 3개, 긴급·주간·월간으로 나눈 입찰 조정안
샘플 자료: 연습용 A브랜드 쿠팡 키워드 리포트(키워드 9개, 30일치)
걸리는 시간: 2~3분
멈추는 곳 더: 끝나면 입찰 조정안을 어떤 순서로 손볼지 여쭙니다. 키워드 끄기와 입찰 변경은 쿠팡 광고센터에서 직접 하셔야 바뀝니다.
우리 자료 안내: 키워드 리포트여야 합니다. 캠페인 리포트와 광고그룹 리포트는 열 구성이 달라 읽지 못합니다.
우리 자료로 하려면:
- 쿠팡: 쿠팡 광고센터 → 리포트 → 키워드 리포트 → 기간 설정 → 다운로드 → inputs/ads-coupang-{기간}.csv
함께 알려주면 좋은 것:
- 스토어 일별 매출 요약: 함께 넣으시면 광고를 껐을 때 매출이 얼마나 빠지는지 보는 광고 의존도 카드를 냅니다. 없으면 이 카드는 빠집니다.
```
