# 실습 입력 · 048 랜딩페이지 CRO 진단

```
sample-data/A브랜드-상세페이지.md CRO 진단해줘
```

광고 소재를 같이 주면 검사 항목이 하나 늘어난다.

```
sample-data/A브랜드-상세페이지.md 진단해줘. 유입 광고는 "좋은 향은 좋은 성분이 아닙니다"
```

## Scent 검사

광고가 약속한 것과 첫 화면이 말하는 것이 다르면, **클릭은 나오고 전환은 안 나온다.**
광고 소재를 같이 주면 그 정합을 본다. 이게 CRO 에서 가장 자주 놓치는 항목이다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 랜딩 | URL · 스크린샷 · 샘플 파일 | **묻고 멈춘다** |
| 전환 데이터 | GA4 · 광고 관리자 | 구조만 진단 · 처방 순서에 `[추정]` |
| 광고 소재 | 발화 | Scent 검사 생략 |

샘플 파일에는 30일 퍼널(조회 12,400 → 완료 96)이 들어 있다.

## 바꿔서 해 보기

- 전환 데이터를 빼고 돌려 본다 → 처방 우선순위가 전부 `[추정]` 이 된다
- 광고 소재를 넣어 본다 → **Scent 불일치**가 1순위로 올라오는 경우가 많다
