## 이 예시에서 반드시 지킬 것

- **줄 구성 순서**: 계획 표 → 읽는 자료(없는 것 ⬜ / 대신 쓰는 것 ✅) → 근거로 쓰는 것 → 나오는 곳 →
  나오는 형식 → 멈추는 곳 → 걸리는 시간 → 실제 데이터 유도 문장 → `[승인 요청]`.
- **"읽는 자료"는 없는 자료(⬜)와 대신 쓰는 샘플 자료(✅)를 나란히 적는다.** 왜 샘플로 가는지 한
  줄로 끝내지 않고 무엇이 없어서 무엇으로 대체했는지 구체적으로 밝힌다.
- **"멈추는 곳"에는 담당 이름(`staff-reviewer`)·관점(경영)·SKILL.md의 어느 필드(`review: 경영`)에서
  왔는지까지 적는다.** "검토를 거칩니다"로 뭉뚱그리지 않는다.
- **실제 데이터로 전환하는 방법(랜딩 URL·스크린샷·`inputs`)과 브랜드 전체 세팅으로 넘어가는 경로를
  함께 안내한다.**
- **계획 검증(plan-compiler) 오류 같은 내부 사정은 이 화면 어디에도 적지 않는다.**
