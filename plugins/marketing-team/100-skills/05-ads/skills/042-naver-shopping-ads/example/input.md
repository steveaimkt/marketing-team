# 실습 입력 · 042 네이버 쇼핑광고 진단

```
sample-data/A브랜드-네이버쇼핑검색광고-30일.csv 로 네이버 광고 최적화해줘
```

## 이 리포트는 유형이 다르다

이 CSV엔 `키워드` 열이 없다. `광고그룹`·`소재(상품)` 열만 있다 — **쇼핑검색(SHOPPING)형**이다.
파워링크처럼 내가 산 키워드가 없으니 **브랜드/일반 분리는 강행하지 않는다.**

대신 같은 착시를 **광고그룹 → 상품(소재) 단위**로 해부한다.
합산 ROAS 1.54는 "BEP(2.0)에 조금 못 미친다"처럼 보이지만,
실제로는 세트기획 그룹 하나(광고비의 12.9%)가 전체를 끌어올리고
나머지 세 그룹(광고비의 87.1%)은 전부 BEP 미달이다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 보고서 CSV | 광고주센터 → 보고서 → 대용량 다운로드 | 샘플 파일 (쇼핑검색형) |
| 손익분기 ROAS | `brand/profile.md` §4 | `sample-data/profile-sample.md`(A브랜드) 2.0 폴백 |
| 수요 교차검증 | 데이터랩 MCP | 생략하고 **생략했다고 적는다** |

## 바꿔서 해 보기

- 키워드형 리포트(`키워드` 열이 있는 CSV)로 바꿔 넣어 본다 → 그때는 브랜드/일반 분리로 갈아탄다. 같은 스킬, 다른 집계 단위
- BEP 를 1.5 로 낮춰 본다 → 진정크림 그룹이 「미달」에서 「초과」로 넘어간다. 분류는 BEP 상대값이다
