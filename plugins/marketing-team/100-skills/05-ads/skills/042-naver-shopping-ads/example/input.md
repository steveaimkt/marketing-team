# 실습 입력 · 042 네이버 쇼핑검색광고 최적화

```
sample-data/naver-ads-sample-report.csv 로 네이버 광고 최적화해줘
```

## 이 스킬의 존재 이유 하나

**브랜드 키워드와 일반 키워드를 나눠서 본다.**

「A 브랜드」를 검색하는 사람은 **이미 살 마음이 있는 사람**이다.
거기에 광고를 걸면 ROAS 가 7~8 이 나온다. 광고를 잘해서가 아니라 방어 입찰이라서다.

이 둘을 합쳐서 보면 전체 ROAS 가 그럴듯해 보이고, **적자 나는 일반 키워드가 안 보인다.**
샘플 파일이 정확히 그 모양이다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 보고서 CSV | 광고주센터 → 보고서 → 대용량 다운로드 | 샘플 파일 |
| 브랜드명 시드 | `brand/profile.md` §1 | **묻고 멈춘다** (판별 기준이 없다) |
| 수요 교차검증 | 데이터랩 MCP | 생략하고 **생략했다고 적는다** |

## 바꿔서 해 보기

- 브랜드 키워드를 빼고 일반만 돌려 본다 → **진짜 성적표**가 나온다
- 데이터랩을 붙여 본다 → 수요↑·수익↓ 키워드가 「컷 금지 · 진단 대상」으로 분리된다
