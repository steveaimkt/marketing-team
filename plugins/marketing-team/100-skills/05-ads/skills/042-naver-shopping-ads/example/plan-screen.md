## 이 예시에서 반드시 지킬 것

- **줄 구성 순서**: 계획 표 → 입력 → 브랜드 기준 → 집계 단위 → 근거로 쓰는 것 → 나오는 곳
  → 나오는 형식 → 멈추는 곳 → 걸리는 시간 → `[승인 요청]`.
- **"입력"은 실데이터가 없을 때 어떤 샘플 파일로 대체하는지 경로까지 적는다.** "샘플로 진행합니다"라고만
  뭉뚱그리지 않는다.
- **"집계 단위"는 리포트의 실제 열 구성을 근거로 쇼핑검색형/파워링크형 같은 판정을 밝히고, 그 판정이
  집계를 어떻게 바꾸는지까지 적는다.** 판정만 던지고 근거를 생략하지 않는다.
- **"나오는 형식"에서 계획한 형식(xlsx)을 못 낼 사정이 있으면 대체 형식(csv)과 이유를 이 줄에서 같이
  밝힌다.** 실행 후 보고에서 처음 알리지 않는다.
- **"멈추는 곳"은 광고 진단처럼 대외 발행물이 아닌 내부 분석이면 "없음"이라고 명시하고 왜 없는지(대외
  발행물 아님)를 함께 적는다.** 게이트 유무를 사용자가 추측하게 하지 않는다.
- **계획 검증(plan-compiler) 오류나 셸 승인 같은 내부 사정은 이 화면 어디에도 적지 않는다.**
