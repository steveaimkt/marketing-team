# 실습 입력 · 068 데이터 정리

```
이 데이터 정리해줘
```

## ⏸ 결측을 어떻게 할지는 사람이 고른다

| 처리 | 대가 |
|---|---|
| 행 제거 | 표본이 준다 |
| 0 대체 | **평균이 왜곡된다** |
| 전후값 보간 | 없던 추세가 생긴다 |
| **유지 + 표기** | 분석에서 매번 신경 써야 한다 |

안 정하면 **「유지 + 표기」**로 간다. 가장 덜 파괴적인 선택이다.
자동으로 지우거나 0으로 채우면, 나중에 왜 숫자가 다른지 아무도 못 찾는다.

## 원본을 덮어쓰지 않는다

정리본은 **사본으로만** 낸다. 클리닝 로그에 변경 내역이 전수로 남는다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 로우데이터 | Sheets MCP · CSV·XLSX | `sample-data/A브랜드-메타광고-30일.csv` (실제 열: 날짜·캠페인·목표·노출·클릭·CTR·광고비·전환·매출·ROAS) |
| 목표 스키마 | 발화 | 현재 열 구성 유지 |

이 샘플 파일은 실제로 열어 보면 결측·중복·형식 문제가 거의 없다. **깨끗하면 깨끗하다고
낸다.** 매출 0원처럼 눈에 띄는 값도 캠페인 목표(인지·트래픽)와 교차 확인하면 정상인
경우가 많다. 검출됐다고 바로 지우지 않는다.

## 바꿔서 해 보기

- 「결측은 다 지워」라고 해 본다 → 제거 행 수와 **표본 감소율**이 로그에 먼저 나온다
- 목표 스키마를 줘 본다 → 열 이름·타입까지 맞춘 정리본이 나온다
