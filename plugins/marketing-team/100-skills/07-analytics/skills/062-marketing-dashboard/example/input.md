# 실습 입력 · 062 마케팅 대시보드 작성

```
마케팅 대시보드 만들어줘
```

## 지표를 4~8개로 먼저 확정한다 ⏸

지표가 20개인 대시보드는 아무도 안 본다.
안 정하면 기본 6종으로 간다: **매출 · 광고비 · ROAS · 전환 · CPA · 트래픽**

## 데이터 없는 지표는 회색 카드로 남는다

빼 버리면 **없는 줄 알고**, 회색으로 남기면 **붙여야 할 것으로 보인다.**
대시보드는 지금 아는 것과 아직 모르는 것을 같이 보여 주는 물건이다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 채널 데이터 | GA4 · Sheets MCP · CSV | `sample-data/A브랜드-퍼널-가입구매-90일.csv` (유입~결제완료, 금액 열 없음) |
| 광고비·ROAS 근거 | 광고 관리자 CSV | `sample-data/A브랜드-메타광고-30일.csv` (7월 합계) |
| 지표 정의 | 066 산출물 | 기본 6종 |

퍼널 CSV에는 매출·비용 열이 없다. 광고비·ROAS 카드는 다른 파일(메타광고 CSV)에서 온다는
것을 지표 정의 각주에 반드시 밝힌다. 두 파일을 섞어서 하나의 숫자인 척 내지 않는다.

## ⏸ 자동 갱신은 걸지 않는다

갱신 가이드만 붙인다. 자동으로 걸어 둔 대시보드는 **소스가 바뀌어도 아무도 모른 채**
틀린 숫자를 계속 보여 준다.

## 바꿔서 해 보기

- 지표를 12개로 늘려 본다 → 4~8개로 줄이자고 되묻는다
