# 067 월간 마케팅 성과 분석 계획 화면

> 이 화면은 모델이 짓지 않는다. `scripts/plan-compiler.mjs compile` 이 아래 「틀」과 계획(plan.json), 스킬 선언으로
> 찍고, AI 마케터는 **한 글자도 바꾸지 않고** 그대로 낸다 (2026-09-15, 원고와 코워크 화면 100% 일치).
> 틀의 문구는 실측 2026-09-13(`원고소스/05_실측정리_원본자료/7장/067_20260913/대화로그/067_run_turn1_plan.jsonl`)과
> 원고 7장 067 절(8월을 7월과 비교, 노션 게시와 매월 자동 생성은 따로 묻는다, 캠페인 로그가 있으면 원인까지 본다)의 내용을 옮겼다.
> 재무 관점 검토와 「한 번 더 묻고 합니다」 문장은 `review: 재무` 와 `mutating: true` 선언에서 스크립트가 붙인다.
> 아래 「찍힌 화면」은 샘플·빈 프로필·형식 선택 없음 조건의 출력이다. `test-plan-compiler.mjs` 가 글자 단위로 대조한다.

## 틀

```틀
무엇이 나오나: 경영진 요약 한 장(결론 3줄과 결정 요청), 지난달·목표와 견준 지표 요약표, 채널별 성과표, 차트 3종, 다음 달 액션
샘플 자료: 연습용 A브랜드 채널 6곳의 6~8월 성과 자료(8월을 7월과 비교)
걸리는 시간: 3~5분
멈추는 곳 더: 노션에 올릴지와 매월 자동으로 만들지는 완성 뒤 따로 묻고, 답이 없으면 둘 다 하지 않습니다.
우리 자료 안내: 채널마다 월, 유입, 주문, 매출, 광고비 열이 있으면 됩니다. 두 달 이상 있어야 지난달과 견줍니다.
우리 자료로 하려면:
- 스마트스토어: 스토어센터 → 통계 → 판매분석 → 기간 → 엑셀 → inputs/sales-smartstore-{기간}.xlsx
- GA4: 보고서 → 우측 상단 공유 → 파일 다운로드 → CSV → inputs/ga4-{보고서명}.csv
- 메타 광고: 광고 관리자 → 보고서 → 열 선택 → 내보내기 → CSV → inputs/ads-meta-{기간}.csv
- 네이버 검색광고: 광고시스템 → 보고서 → 맞춤 보고서 → 기간 → 다운로드 → inputs/ads-naver-{기간}.csv
- 쿠팡 광고: 쿠팡 윙 → 광고 관리 → 보고서 → 다운로드 → inputs/ads-coupang-{기간}.csv
함께 알려주면 좋은 것:
- 월 목표: 목표 ROAS나 월 예산을 알려주면 달성률까지 붙이고, 없으면 지난달 대비만 적습니다.
- 캠페인·이벤트 기록: 있으면 성과가 튄 원인이 프로모션인지까지 봅니다.
```
