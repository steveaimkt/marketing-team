## 이 예시에서 반드시 지킬 것

- **줄 구성 순서**: `[실행 계획]` 제목 → 결과물 표 → 데이터 기간 보정 설명(2줄) → 불릿 목록(근거로
  쓰는 것 → 나오는 곳 → 멈추는 곳 → 검수 → 나오는 형식) → 리스크 한 줄 → `[승인 요청]`.
- **데이터가 요청한 기간과 다르면("이번 달"이 실제로는 몇 월인지) 계획 화면에서 미리 못박는다.** 침묵하고
  넘어가지 않는다 — "9월 실측 데이터 없음"처럼 이유도 함께 적는다.
- **"멈추는 곳"에는 Phase 뒤 사용자에게 되물을 구체적 질문 두 가지와 그 기본값을 함께 적는다.** 질문만
  적고 기본값을 빼먹지 않는다.
- **예산·금액이 걸린 의사결정 요청이 산출물에 들어갈 것으로 예상되면, 계획 화면에서 미리 "AI
  사업검토자(재무 관점)"를 완료 직후 부른다고 밝힌다.** 검수가 사후에 조용히 붙는 것처럼 숨기지 않는다.
- **나오는 형식은 `.html`(대시보드)과 `.xlsx`(표) 둘 다 적는다.** 실제 실행에서 `.xlsx`가
  `document-skills` 미설치로 `.csv`로 대체될 수 있지만, 그 사정은 계획 화면이 아니라 완료 응답에서
  밝힌다 — 계획 화면 자체는 스킬의 기본 형식 그대로 적는다.
- **계획 검증(plan-compiler) 경로 표기 버그 같은 내부 사정은 이 화면 어디에도 적지 않는다.**
