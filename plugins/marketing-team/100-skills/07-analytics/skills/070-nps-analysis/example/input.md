# 실습 입력 · 070 설문 응답 분석

```
NPS 응답 분석해줘
```

## 응답이 30건 미만이면 단일 수치를 안 낸다

NPS 는 **추천 − 비추천 비율**이라 표본이 적으면 크게 흔들린다.
20명 응답에서 나온 「NPS 34」는 **두 명만 바뀌어도 통째로 달라진다.**

그럴 때는 분포만 보여 주고 숫자 하나로 압축하지 않는다.

## 어느 열이 점수인지 추측하지 않는다

문항 구조를 모르면 **묻고 멈춘다.** 5점 척도인지 11점(0~10)인지에 따라
추천·중립·비추천 경계가 완전히 달라진다.

## 이 실습이 쓰는 샘플은 정식 NPS 설문이 아니다

`sample-data/A브랜드-리뷰-200건.csv` 에는 0~10 점수 열이 없다. **별점(1~5)** 만 있다.
이럴 때 지어내지 않고 Contract의 환산식 `NPS등가 = (별점−1) ÷ 4 × 10` 으로 그룹만 배정하고,
결과 전체에 `[추정]` 을 붙인다. 이 파일은 별점 2점 72건·3점 51건·5점 77건으로 구성돼 있어
환산하면 4점(중립) 구간이 통째로 비고, NPS등가는 음수가 나온다. 지어낸 게 아니라 실제로 그렇다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 응답 데이터 | CSV · 시트 (여기선 리뷰 별점 + 본문) | 묻고 멈춘다 |
| 문항 구조 | 발화 (여기선 별점 열 = 환산 대상) | **묻고 멈춘다** |
| 고객이 사는/떠나는 이유 | `brand/profile.md` §2 | 테마 명명이 자유로워진다 |

## 바꿔서 해 보기

- 응답을 25건으로 줄여 본다 → **NPS 수치가 사라지고** 분포만 나온다
- 주관식 열을 빼 본다 → 점수만 나오고 **왜 그런지는 안 나온다.** 이 스킬의 절반이 사라진다
