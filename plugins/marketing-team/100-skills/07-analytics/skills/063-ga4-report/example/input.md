# 실습 입력 · 063 GA4 분석 리포트

```
GA4 리포트 뽑아줘
```

## ⏸ 전환 이벤트가 0건이면 숫자를 해석하지 않는다

세팅 오류를 먼저 보고하고 진행 여부를 묻는다.
**안 잡히는 전환 위에서 만든 리포트는 전부 헛것**이라서다.

## 세팅 신뢰도 4검사

1. 핵심 전환 이벤트가 기간 내 수집되는가 (**0건이면 중단**)
2. 같은 전환이 중복 발화하는가 (전환/세션 비율이 비정상인가)
3. `unassigned` · `(not set)` · `direct` 가 과다한가 → **050 어트리뷰션 신호**
4. 자사 트래픽·봇이 걸러지는가

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| GA4 데이터 | GA4 MCP · 탐색 CSV 3종 | 묻고 멈춘다 |
| 핵심 전환 이벤트 | 발화 (한 번만 묻는다) | `purchase` |

CSV 폴백 시 필요한 3종: **트래픽 획득 · 방문 페이지 · 이벤트/전환**

## 바꿔서 해 보기

- 전환 이벤트를 「없음」으로 해 본다 → **세팅 오류 보고서**가 나오고 해석이 멈춘다
- `direct` 비중을 크게 해 본다 → 050 어트리뷰션 정리가 1순위 액션으로 올라온다
