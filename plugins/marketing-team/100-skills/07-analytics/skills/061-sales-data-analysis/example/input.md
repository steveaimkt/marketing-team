# 실습 입력 · 061 판매 데이터 분석

```
매출 데이터 분석해줘
```

이 실습은 게이트 표 기본값인 `sample-data/A브랜드-채널성과-90일.csv`(2026-05-01~07-29 · 채널·일별)를
그대로 쓴다. 광고 리포트는 묻지 않고 `sample-data/A브랜드-메타광고-30일.csv`(2026-07)로 교차한다.

⚠️ 이 CSV엔 **상품 열이 없다**(날짜·채널·세션·이탈률·주문·매출·신규비율뿐). 상품별 파레토가
필요하면 상품 단위 데이터를 `inputs/`에 추가로 올려야 한다. 없는 상품명을 지어내지 않는다.

## 합계를 쪼갠다

매출이 늘었다는 사실만으로는 다음 달에 뭘 할지 안 나온다.

```
Δ매출 = Δ수량 기여 + Δ단가 기여 + Δ믹스 기여
```

수량이 늘어서 오른 것과, 비싼 상품이 더 팔려서(믹스) 오른 것은 **다음 달 처방이 다르다.**

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 매출 로우데이터 | 시트 MCP · CSV·XLSX | 샘플 파일 |
| AOV·마진율 | `brand/profile.md` §4 | 데이터에서 산출 + `[추정]` |

권장 열: 날짜 · 상품 · 채널 · 수량 · 단가 · 매출
(이 샘플 CSV는 상품·수량·단가 열이 없어, 주문 건수를 수량 대용으로 · 매출÷주문을 단가 대용으로 쓴다)

## ⚠️ 지저분하면 분석하지 않는다

결측·중복이 심하면 **분석을 멈추고 068 데이터 클리닝을 먼저 권한다.**
지저분한 데이터로 만든 리포트는 틀린 걸 확신 있게 말한다.

## 바꿔서 해 보기

- 기간을 2개월로 늘려 본다 → 이상치 검출의 이동평균이 안정되어 오탐이 준다
