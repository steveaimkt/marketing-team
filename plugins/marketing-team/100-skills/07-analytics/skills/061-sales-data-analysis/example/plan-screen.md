# 061 판매 데이터 분석 계획 화면

> 이 화면은 모델이 짓지 않는다. `scripts/plan-compiler.mjs compile` 이 아래 「틀」과 계획(plan.json), 스킬 선언으로
> 찍고, AI 마케터는 **한 글자도 바꾸지 않고** 그대로 낸다 (2026-09-15, 원고와 코워크 화면 100% 일치).
> 틀의 문구는 실측 2026-09-13(`원고소스/05_실측정리_원본자료/7장/061_20260913/대화로그/061_run_1차_xlsx막힘.jsonl`)과
> 원고 7장 061 절(읽는 자료 두 가지, 걸리는 시간 3~5분, 자료 정리를 먼저 권하는 경우)의 내용을 옮겼다.
> 아래 「찍힌 화면」은 샘플·빈 프로필·형식 선택 없음 조건의 출력이다. `test-plan-compiler.mjs` 가 글자 단위로 대조한다.

## 틀

```틀
무엇이 나오나: 종합 요약(전체 매출, 광고비, 종합 ROAS, 광고 의존도), 수량·단가·믹스로 나눈 매출 증감 원인, 채널별 집계, 캠페인 목표별 광고 성과, 이상치와 원인 가설, 차트 6종
샘플 자료: 연습용 A브랜드 판매 자료 90일치(채널 6곳, 540행)와 메타 광고 자료 30일치(캠페인 4개, 120행)
걸리는 시간: 3~5분
멈추는 곳 더: 필수 열이 빠졌거나 겹치는 주문이 많으면 분석하지 않고 자료 정리(스킬 068)를 먼저 권합니다.
우리 자료 안내: 날짜, 상품, 채널, 수량, 매출 열이 있으면 됩니다. 광고 리포트를 함께 넣으면 광고 의존도까지 봅니다.
우리 자료로 하려면:
- 스마트스토어: 스토어센터 → 통계 → 판매분석 → 기간 → 엑셀 → inputs/sales-smartstore-{기간}.xlsx
- 쿠팡: 쿠팡 윙 → 정산 → 매출내역 → 다운로드 → inputs/sales-coupang-{기간}.csv
- 자사몰: 관리자 → 주문/매출 통계 → 엑셀 → inputs/sales-{몰이름}.csv
- 메타 광고(선택): 광고 관리자 → 보고서 → 열 선택 → 내보내기 → CSV → inputs/ads-meta-{기간}.csv
함께 알려주면 좋은 것:
- 분석 기간: 따로 말하지 않으면 판매 자료 전체를 보고, 광고와 맞대는 계산은 두 자료가 겹치는 날만 셉니다.
- 공헌이익률: 알려주면 손익분기 ROAS와 목표 CPA를 그 값으로 계산합니다.
```

## 나

```
매출 데이터 분석해줘.
```
