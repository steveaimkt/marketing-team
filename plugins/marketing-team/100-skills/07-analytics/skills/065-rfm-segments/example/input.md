# 실습 입력 · 065 고객 등급 분석

```
RFM 으로 고객 나눠줘
```

## 표본이 적으면 등급을 줄인다

고객이 **200명 미만이면 5분위 대신 3분위**로 자동 완화한다.
150명을 5등급으로 쪼개면 등급당 30명이라 세그먼트가 의미를 잃는다.

## 분위 경계값을 산출물에 적는다

같은 데이터를 다시 돌렸을 때 같은 결과가 나와야 하기 때문이다.
경계값이 없으면 다음 달 RFM 과 비교가 안 된다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 고객ID · 주문일 · 주문금액 | 주문 CSV | `sample-data/A브랜드-구매이력-12개월.csv` (고객 320명, 064와 같은 파일) |
| AOV · 구매주기 | `brand/profile.md` §4 | 데이터 중위값 + `[추정]` |

320명은 200명 기준을 넘어 5분위를 쓴다. 다만 F(구매 횟수)는 이 파일에서 1~4회에 값이
몰려 있어 5분위 대신 원값(1회·2회·3회+) 3단계를 쓴다. 지어낸 등급보다 실측 구간이 낫다.

## 바꿔서 해 보기

- 고객 수를 150명으로 줄여 본다 → **3분위로 자동 완화**되고 사유가 적힌다
- 064 를 먼저 돌려 본다 → 낮은 재구매율(M+1 평균 4.5%)이 「신규」 세그먼트의 비중과 겹친다
