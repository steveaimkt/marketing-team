## 텍스트 규칙 적용

| 규칙 | 적용 |
|---|---|
| 기본 가운데 정렬 | 01·04·05·09~14 헤드 |
| 나열형만 좌측 | 18 전성분 · 09~14 혜택 3줄 · 17 비교표 |
| 긴 문장 `width: 760` | 본문 24px 이상 텍스트 전부 |
| 줄바꿈 후 들여쓰기 | **금지** ✅ |
| 기능 섹션 72px 번호 | 09~14 ✅ |

## 어디를 봐야 하나

**24개 프레임을 아직 안 만들었다.** 승인 요청만 있다.
피그마에 24개를 만들어 놓고 "컬러가 아닌데요"를 들으면
지우고 다시 만드는 게 처음부터 만드는 것보다 오래 걸린다. `mutating` 스킬의 게이트는 그래서 앞에 있다.

**검수 포인트 2번이 결손을 지키라고 한다.** 051 에서 03·17 을 비웠는데
디자이너가 "빈 프레임이 있네" 하고 지우면 **결손이 사라진 것처럼 보인다.**
비어 있음을 시각적으로 남기는 것이 이 단계의 일이다.

**HTML 폴백이 실패가 아니다.** 피그마가 없어도 시안은 나온다.
중요한 건 **매핑 JSON 이 남는다**는 것이다. 나중에 연결하면 같은 JSON 으로 그대로 생성된다.
