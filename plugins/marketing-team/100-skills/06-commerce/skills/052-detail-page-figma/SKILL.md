# 052 상세페이지 디자인 시안

051의 24섹션 기획서를 받아 섹션→프레임 매핑 JSON을 설계하고, **브라우저에서 바로 열리는 HTML 시안**을 만든다.
피그마 MCP가 연결돼 있으면 같은 매핑으로 **프레임까지 추가로** 생성한다.
카피는 손대지 않는다 — 이 스킬은 텍스트를 레이아웃으로 옮기는 디자인 파이프라인이다.

> ✅ **피그마 없이도 완주한다.** HTML 시안이 기본 산출물이고, 피그마는 **있으면 더 가는 것**이다.
> 「피그마가 없어서 못 합니다」는 이 스킬에 없다.

> ⚠️ **051 을 거치지 않은 카피가 들어오면 시안을 내기 전에 AI 규제검토자를 먼저 태운다.**
> 정상 경로는 `상세페이지 24섹션(051)` → 여기다. 051 은 `gate: true` 라 카피가 이미 검사를 받았다.
> 사용자가 자기 카피를 직접 넣고 이 스킬만 돌리면 **검사 없이 시안이 나간다.**

## Contract
1. 기획서의 섹션 구조를 1:1로 Figma 프레임에 매핑한다 — 섹션 수 = 프레임 수, 순서 동일.
2. 색상은 브랜드 토큰(brand_main·accent) + 고정 다크 팔레트(#111111 · #1A1A1A · 서브텍스트 #888888)만 사용한다 — 매핑 JSON에 없는 색은 캔버스에 없다.
3. 타이포는 표준 스케일을 따른다: 메인 카피 56px/700 · 섹션 제목 40~48px/700 · 답변(A) 36px/700 · 본문 22px/400.
4. ⏸ Figma 파일 생성·수정(mutating)은 매핑 설계안을 사용자에게 보여주고 승인받은 뒤에만 실행한다.
5. **HTML 시안은 언제나 만든다.** 피그마 연결 여부와 무관하다 — 그것이 이 스킬의 기본 산출물이다.
6. 피그마 MCP 가 연결돼 있으면 같은 매핑 JSON 으로 프레임을 **추가** 생성한다. 없으면 그 사실만 한 줄 알리고 끝낸다 — 실패가 아니다.

## 게이트 (대화형에서만 멈춘다)

> ⚠️ **이 스킬은 재료가 없으면 멈춘다.** 없는 것을 지어내면 산출물 전체가 거짓말이 된다.
> 대시보드·cron 에서는 아래 기본값으로 완주하고 산출물에 그 사실을 밝힌다.

| 멈추는 곳 | 묻는 것 | 기본값 (답 없으면) |
|---|---|---|
| Phase 1 | 051 기획서가 없으면 **묻고 멈춘다** | 없음 · **즉석 카피 창작 금지** · **051 을 여기서 바로 이어 준다**(권하고 끝내지 않는다) |
| Phase 4 ⏸ | 피그마가 **연결돼 있을 때만** — "설계안입니다. 피그마에도 만들까요?" | **만들지 않는다** · HTML 시안까지가 완주다 |
| — | 피그마가 없으면 **묻지 않는다** | HTML 시안으로 완주하고 「피그마 연결 시 프레임도 생성됩니다」 한 줄만 |

⛔ **여기서 멈추는 것은 재료가 없어서가 아니라 순서가 있기 때문이다.**
**「먼저 하세요」로 끝내지 않는다** — 051 상세페이지 24섹션 를 **지금 이어서 돌린다** (⏸ 승인 후).
사용자가 스킬 번호를 외워 다시 부르게 만들면 거기서 끊긴다.

## Phases
1. **입력 로드** — 051 기획서(24섹션)와 브랜드 토큰을 로드. 기획서가 없으면 051 실행을 먼저 제안한다 (즉석 카피 창작 금지).
2. **컬러 결정** — 제품 이미지·브랜드에서 메인/강조 컬러를 추출해 다크 팔레트와 병합. 컬러 칩 미리보기 제시.
3. **섹션→프레임 매핑 설계** — 섹션별 `{프레임명, 텍스트 요소, 이미지 플레이스홀더, 정렬}` JSON 생성. 텍스트 규칙(원본 검증 자산):
   - 기본 가운데 정렬(CENTER) — 스펙 목록·비교표 등 나열형만 좌측 정렬
   - 긴 텍스트는 `width: 760` 지정 + `\n`으로 자연스러운 문장 단위 줄바꿈, 줄바꿈 후 들여쓰기 금지
   - 기능 상세 섹션은 기능 번호 72px 큰 숫자 + Q/A + 혜택 3줄 구조 유지
4. ⏸ **설계안 승인** — 프레임 목록·컬러·타이포를 요약해 보여주고 실행 승인을 받는다. 승인 전 Figma에 쓰지 않는다.
5. **HTML 시안 생성** — 매핑 JSON 으로 셀프컨테인드 HTML 시안을 만든다. **여기까지가 완주다.**
5-b. **(선택) 피그마 반영** — MCP 가 연결돼 있을 때만: 채널 확인 → 프레임 생성 → 텍스트·플레이스홀더 배치.
   ⛔ 연결이 없으면 **묻지도 멈추지도 않는다.** 「피그마를 연결하면 프레임도 자동 생성됩니다」 한 줄만 덧붙인다.
6. **검수 안내** — 이미지 교체 위치 목록 + 텍스트 오버플로 체크포인트 전달. 다음: 053 상품명·검색 최적화로 리스팅 마무리.

7. **파일로 남긴다** — 위 산출물을 `outputs/{날짜}/052-detail-page-figma/052-detail-page-figma.html` 로 저장하고 경로를 알린다. 화면에만 띄우고 끝내지 않는다 — 마케터가 다음 날 다시 열 수 있어야 한다.
   > 쓰기 권한이 없으면 **실패로 처리하지 않는다.** 산출물은 그대로 화면에 내고 맨 아래에 "`outputs/{날짜}/052-detail-page-figma/052-detail-page-figma.html` 로 저장하려 했으나 권한이 없어 남기지 못했습니다" 를 적는다. 못 한 일을 못 했다고 말하는 것도 산출물의 일부다.

> ⛔ **착지 · 여기로 쓴다** — `outputs/{날짜}/052-detail-page-figma/052-detail-page-figma.html`
> 경로를 새로 만들지 않는다. 위 줄을 그대로 쓰고 `{날짜}` 만 오늘로 바꾼다.
> 아티팩트·스크래치패드·화면 출력은 착지가 아니다. **파일이 없으면 안 한 것이다.**
> **형식** · `<!doctype html>` + `charset=utf-8` 완전 문서 · **자체 완결**(CDN·외부 폰트 금지) · 아티팩트로 발행하지 않는다 (`docs/공통규약.md §H`)

## Output Format · **파일에 들어갈 내용**

⛔ **아래는 `outputs/{날짜}/052-detail-page-figma/052-detail-page-figma.html` 안에 들어갈 것이다. 화면에 그대로 쓰는 것이 아니다.**
파일에 쓰고 나서, 화면에는 **경로 · 결론 3줄 · 부족한 것**만 낸다 (15줄 이내).

## Anti-Patterns
- **카피 재창작** — 디자인 단계에서 문구를 "다듬는" 것. 카피 수정이 필요하면 051로 되돌린다 (규제 게이트를 통과한 문구가 변형되면 안 된다).
- **승인 전 Figma 쓰기** — mutating 스킬이 ⏸ 없이 외부 파일을 만드는 것. 설계안 승인이 항상 먼저다.
- **토큰 밖 색상 즉흥 추가** — "여기만 포인트로" 하며 팔레트에 없는 색을 넣으면 브랜드 일관성이 깨진다.
- **긴 문장 방치** — width 미지정 긴 텍스트는 캔버스를 뚫고 나간다. 760 제한 + `\n` 분리는 선택이 아니라 규칙.
- **MCP 미연결 시 포기 선언** — "Figma가 연결 안 돼서 못 합니다"로 끝내는 것. HTML 폴백이 규정되어 있다.

## 실습해 보기

```
이 기획서로 피그마 시안 만들어줘
```

**051 기획서가 없으면 멈춘다.** 여기서 카피를 즉석으로 지어내면
디자인은 나오는데 그 카피가 어디서 왔는지 아무도 모른다.

## 활용
- **기획→시안 당일 완성**: 051 기획서 승인 직후 이어 실행하면 카피·디자인 초안이 하루에 나온다 — 디자이너에게는 빈 캔버스 대신 구조 잡힌 시안을 전달.
- **브랜드 토큰 재사용**: 한 번 확정한 컬러·타이포 토큰을 저장해 두면 신제품마다 같은 톤의 상세페이지가 자동으로 유지된다.
- **HTML 폴백의 역활용**: Figma를 안 쓰는 팀은 폴백 HTML을 그대로 시안 공유·내부 컨펌용으로 사용한다.
