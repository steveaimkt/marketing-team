# 실습 입력 · 055 스마트스토어 진단

```
스마트스토어 진단해줘
```

## 3단계 중 하나만 병목으로 찍는다

| 단계 | 이 단계가 병목인 신호 |
|---|---|
| **노출** | 유입 자체가 적다 |
| **전환** | 유입은 있지만 결제가 없다 |
| **재구매** | 첫 구매만 있고 반복이 없다 |

셋을 동시에 고치라는 진단은 아무것도 안 고치게 만든다.
동점이면 **노출**부터 본다. 앞단이 막히면 뒤를 고쳐도 늘지 않기 때문이다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 스토어 통계 | 스마트스토어센터 (유입·전환·재구매) | `sample-data/A브랜드-채널성과-90일.csv` 로 완주 · **재구매는 이 CSV에 없어 `[데이터 없음]`** |
| 대표 상품 | 발화 | 스토어 대표 상품 |
