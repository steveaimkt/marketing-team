# 실습 입력 · 054 리뷰 관리 시스템

```
sample-data/A브랜드-리뷰-200건.csv 로 리뷰 답변 달아줘
```

## 4단계로 나눈다

| 분류 | 초안 |
|---|---|
| 긍정 · 중립 | ✅ 자동 생성 |
| **부정** | ⏸ 2안(사과·보상형 / 안내·해명형)으로 정리 → **판단을 받는다** |
| **위험** (법적·안전·언론) | ⛔ **초안을 만들지 않는다** · 대응 가이드만 |

리뷰 답변에서 사고가 나는 건 대부분 부정·위험 건에서
**빠르게 답하려다** 보상을 약속하거나 해명이 길어질 때다.

## 답변에서 금지하는 것

- 효능 재주장 ("정말 개선되실 거예요")
- **보상 약속** ("환불해 드리겠습니다" ← 공개 리뷰에 쓰면 다른 사람도 요구한다)
- 경쟁사 언급

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 리뷰 원문 | CSV · 캡처 · 텍스트 | **묻고 멈춘다** |
| 톤 | `brand/tone.md` | A 브랜드 기본 |

## 바꿔서 해 보기

- 위험 리뷰를 하나 넣어 본다 → **초안 자리가 비고** 대응 가이드만 나온다
- 별점 1점만 걸러서 넣어 본다 → 에스컬레이션 리스트가 산출물의 대부분이 된다
