# 실습 입력 · 057 프로모션 일정 기획

```
올해 프로모션 캘린더 짜줘
```

## 프로모션은 마진율로 결정한다

「빅세일이니까 20% 깎자」가 아니다. **프로모션 할인 + 쿠폰 분담 + 광고 분담**을 다 뺀
실마진이 흑자인 프로모션만 남긴다.

```
실마진 = 프로모션가 − 원가 − (프로모션가 × 수수료율) − 쿠폰 분담 − 광고 분담
마진율 = 실마진 ÷ 프로모션가
```

원가나 수수료율이 없으면 **묻고 멈춘다.** 실마진 계산의 구멍은 진행 결정을 그대로 뒤집는다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 원가·수수료율 | 발화 · 017 산출물 | **묻고 멈춘다** |
| 프로모션 날짜 | 사용자 제공 | 연례 패턴 `[예상]` 표기 |
| 재고 | 발화 | 물량 계획을 비운다 |

## 바꿔서 해 보기

- 쿠폰 분담을 15%로 올려 본다 → **흑자였던 프로모션가 적자로 뒤집힌다.** 분담분이 결과의 핵심이다
- 재고를 넣어 본다 → 프로모션별 최대 물량과 품절 예상일이 붙는다
