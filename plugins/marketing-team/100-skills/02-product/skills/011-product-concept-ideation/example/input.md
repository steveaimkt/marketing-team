# 실습 입력 · 011 신제품 컨셉 브레인스토밍

아래 한 줄을 클로드에게 그대로 말하면 된다.

```
sample-data/경쟁사-3곳.md 로 신제품 컨셉 뽑아줘
```

## 이 실습이 쓰는 것

| 무엇 | 어디서 |
|---|---|
| 브랜드 정보 | `brand/profile.md` · 비어 있으면 아래 A 브랜드로 돈다 |
| 시장 갭의 원재료 | `sample-data/경쟁사-3곳.md` (B·C·D사) |
| 불만 신호 | `sample-data/A브랜드-리뷰-200건.csv` (있으면 자동으로 같이 읽는다) |

## A 브랜드 (샘플 · `brand/` 가 비었을 때 쓰는 가상 브랜드)

- 화장품 D2C · 2년차 · 대표 상품 수분 세럼 30ml **39,000원**
- 타깃 27~38세 민감성 피부 · 채널 자사몰 45% · 네이버 35% · 쿠팡 20%
- 포지셔닝 "민감 피부의 데일리 루틴을 가장 단순하게" (3스텝)

## 바꿔서 해 보기

컨셉의 질은 **갭의 질**을 넘지 못한다. 입력을 갈아 보면 그게 보인다.

- 경쟁 자료만 준다 → 포지셔닝 공백 위주의 갭이 나온다
- 리뷰까지 준다 → 「불만에서 출발한」 갭이 하나 더 붙는다
- 아무것도 안 준다 → 전부 `[추정]` 이 붙고, 확정 전에 할 리서치 과제가 함께 나온다

세 번째를 한 번 돌려 보는 것을 권한다. **근거 없이 낸 아이디어가 어떻게 생겼는지**가 보인다.
