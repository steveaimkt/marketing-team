# 실습 입력 · 019 A/B 테스트 설계

아래 한 줄을 클로드에게 그대로 말하면 된다.

```
sample-data/A브랜드-메타광고-30일.csv 기준으로 상세페이지 A/B 테스트 설계해줘
```

## 이 실습이 쓰는 것

| 무엇 | 어디서 |
|---|---|
| 기준 전환율 | `sample-data/A브랜드-상세페이지.md` · 결제 완료 96 / 조회 12,400 = **0.8%** |
| 일 트래픽 | 같은 파일 · 12,400 ÷ 30일 = **413/일** |
| 바꿀 것 | 같은 파일의 알려진 문제 · "첫 화면에 가격과 용량이 안 보인다" |

## 이 실습은 실패를 보여 준다

돌려 보면 **표본이 안 나온다.** 22주가 걸린다는 답이 온다.
그게 오류가 아니라 결과다. 이 스킬이 존재하는 이유의 절반이 거기 있다.

**표본수를 안 세고 시작한 테스트는, 결과가 나와도 그 결과를 믿을 수 없다.**
"일주일 돌려보고 이긴 쪽으로 가자"가 왜 안 되는지를 이 실습이 숫자로 보여 준다.

## 바꿔서 해 보기

- 「MDE 를 상대 50%로 올려서」라고 붙여 본다 → 22주가 5.5주로 줄어든다
- 「장바구니 담기를 지표로」라고 바꿔 본다 → 24일로 줄어든다 (기준값이 0.8%가 아니라 5.0%라서)
- 일 트래픽을 「2,000」이라고 줘 본다 → 같은 설계가 갑자기 성립한다

## ⚠️ 이 스킬이 하지 않는 것

**테스트를 켜지 않는다.** 판정도 하지 않는다.
결과 데이터를 읽고 "어느 쪽이 이겼나"를 판정하는 건 **047** 의 일이다.
019 는 데이터가 생기기 전에 끝난다.
