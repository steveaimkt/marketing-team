# 실습 입력 · 017 가격 전략 설계

아래 한 줄을 클로드에게 그대로 말하면 된다.

```
가격 전략 짜줘. 수분 세럼 매입원가 11,000 · 채널 수수료 10%(3,900) · 결제 수수료 3%(1,170) · 배송비 2,500 · 반품충당 930 · 월 고정비 4,500,000
```

## ⚠️ 이 스킬은 원가가 없으면 멈춘다 · VAT 도 함께 묻는다

**VAT 를 말하지 않으면 별도 기준으로 계산하고 그 사실을 산출물에 적는다.**
매입가는 포함, 판매가는 별도로 섞어서 계산하면 마진이 통째로 10% 왜곡된다.
이 스킬이 가장 자주 잡는 오류가 그것이다.

## 샘플 원가 카드 (숫자를 안 주면 이 표로 돈다 · `sample-data/A브랜드-원가구조.csv` · VAT 별도)

| 항목 | 수량 | 단가/비율 | 구분 |
|---|---|---|---|
| 제조원가 | 1 | 11,000 | 변동비 |
| 채널 수수료 | - | 판매가 × 10% (39,000원 기준 3,900) | 변동비 |
| 결제 수수료 | - | 판매가 × 3% (39,000원 기준 1,170) | 변동비 |
| 배송비 | 1 | 2,500 | 변동비 |
| 반품충당 | - | 판매가 × 2.38% (39,000원 기준 930) | 변동비 |
| 고정비 배부 | 월 | 4,500,000 | 고정비 |

- 최소 마진 정책: 판매가의 25%
- 현재 판매가 39,000원 (30ml) · 현재 공헌이익 19,500원(50.0%) — `A브랜드-원가구조.csv` 실측
- 경쟁 30ml 환산가: C사 6,600 · B사 27,600 · D사 58,000

## 바꿔서 해 보기

- 「VAT 포함 기준으로」라고 붙여 본다 → 공급가액 = 합계 ÷ 1.1 로 다시 계산된다
- 제조원가를 13,000 으로 올려 본다 → **바닥가가 어디까지 밀리는지**를 본다 (원자재 인상 시뮬레이션)
- 고정비를 2,000,000 으로 낮춰 본다 → 손익분기 수량이 절반 아래로 내려간다

## ⚠️ 이 스킬이 하지 않는 것

정가만 정한다. **행사 할인가·번들가는 016 의 일이다.** 여기서 할인을 설계하면
정가가 할인을 전제로 부풀려져, 첫 행사에서 바닥가를 깬다.
