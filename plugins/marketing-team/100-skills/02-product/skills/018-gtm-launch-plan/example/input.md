# 실습 입력 · 018 출시 체크리스트 & GTM 플랜

아래 한 줄을 클로드에게 그대로 말하면 된다.

```
런칭 플랜 짜줘. 제품 〈수분 세럼 리뉴얼〉, 출시일 30일 뒤, 채널 자사몰·네이버·인스타, 혼자 함
```

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 출시일 | 발화 | 오늘 + 30일로 잡고 그 사실을 밝힌다 |
| 채널 | 발화 또는 `brand/profile.md` | **보유 채널만 쓴다.** 없는 채널은 넣지 않는다 |
| 팀 | 발화 | 1인으로 가정 · RACI 대신 본인/외주/자동화 |
| 앞 산출물 | 012 가치제안 · 013 확정명 · 017 확정가 | 각 자리를 빈칸으로 두고 선행 태스크로 잡는다 |

## 「혼자 함」이 바꾸는 것

| 팀일 때 | 혼자일 때 |
|---|---|
| RACI 표 (R/A/C/I 4열) | **본인 / 외주 / 자동화** 3분류 |
| 태스크 40개 | 주차별 **「이번 주 할 3가지」** |
| 병렬 배치 | 한 사람이 못 나누므로 순차 |

1인 마케터가 60일 플랜에서 실패하는 이유는 계획이 나빠서가 아니라
**동시에 3개를 하도록 그려져 있어서**다. 이 모드가 그걸 막는다.

## 바꿔서 해 보기

- 채널에 「유튜브」를 넣어 본다 → 영상 제작 리드타임 때문에 D-30 이 아니라 D-45 를 권한다
- 「출시일 10일 뒤」로 줄여 본다 → **무엇을 포기해야 하는지**를 먼저 말한다 (광고 심사 리드타임)
