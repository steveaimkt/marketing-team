# 실습 입력 · 014 소싱 상품 평가

아래 한 줄을 클로드에게 그대로 말하면 된다. **숫자를 말에 실어 주는 것이 요령이다.**

```
소싱 후보 평가해줘. 매입원가 4,200 · 판매가 12,900 · 쿠팡 수수료 10.8% · MOQ 300 · 리드타임 14일
```

## ⚠️ 이 스킬은 숫자가 없으면 멈춘다

원가를 모르면 실마진을 못 구하고, 실마진이 틀리면 **판정 전체가 거짓말**이 된다.
그래서 이 스킬만은 "일단 돌려 보고 나중에 채우자"가 없다. 없는 항목만 되묻는다.

## 샘플 소싱 후보 (숫자를 안 주면 이 카드로 돈다)

| 항목 | 값 |
|---|---|
| 상품 | 실리콘 세안 브러시 (A 브랜드 세럼의 부착 판매 후보) |
| 매입원가 | 4,200원 |
| 목표 판매가 | 12,900원 |
| 판매 채널 | 쿠팡 로켓그로스 · 수수료 10.8% |
| 입출고·배송 | 2,100원 |
| 예상 반품률 | 5% |
| 월 보관비 | 예상 월판매량 나눔 기준 180원/개 |
| MOQ | 300개 |
| 리드타임 | 14일 |

## 바꿔서 해 보기

- 판매가를 14,900 으로 올려 본다 → 마진 점수가 오르고 판정이 바뀌는지 본다
- 반품률을 15% 로 올려 본다 → **명목 마진은 그대로인데 실마진이 얼마나 깎이는지**가 보인다
- MOQ 를 100 으로 낮춰 본다 → 초도 발주 제안과의 격차가 사라진다

두 번째를 꼭 해 보시길 권한다. 소싱 실패의 대부분이 그 칸에서 난다.
