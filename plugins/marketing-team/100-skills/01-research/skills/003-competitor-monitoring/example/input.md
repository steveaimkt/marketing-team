```
sample-data/경쟁사-3곳.md 로 경쟁사 모니터링 걸어줘
```

## ⚠️ 첫 실행은 결과가 안 나온다

이 스킬은 **지난 회차와 비교**하는 스킬이다. 처음 부르면 비교할 것이 없으니
**기준선 스냅샷만 저장하고 끝난다.** 고장이 아니다.

```
📸 기준선 저장 완료 — 경쟁 3사 · 다음 회차부터 변화 비교 시작
```

한 주 뒤 같은 명령을 다시 부르면 그때 변화 리포트가 나온다.

## 멈추는 곳 셋

| 언제 | 묻는 것 | 그냥 두면 |
|---|---|---|
| 대상 확정 | 3곳·주 1회 맞나 | 샘플 3사 · 주 1회 |
| 노션 적재 | 쌓을까 | **안 쌓음** (로컬만) |
| 자동 가동 | 주 1회 걸까 | **안 걺** |

뒤의 둘은 **외부에 쓰는 일**이라 기본값이 "안 함"이다. 승인해야만 한다.
