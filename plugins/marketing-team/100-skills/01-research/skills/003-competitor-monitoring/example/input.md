# 실습 입력 · 003 경쟁사 상시 조사

```
경쟁사 모니터링 걸어줘
```

## 이 실습이 쓰는 것

경쟁사 URL 목록이 없으므로 `sample_fallback`(`sample-data/경쟁사-스냅샷/`)로 완주한다.
이 폴더는 **날짜별 스냅샷 JSON**이다(한 시점 프로필이 아니다 — 003이 진짜로 하는 일인
"전회 대비 diff"를 그대로 보여주려고 두 날짜분을 넣어 뒀다).

| 파일 | 역할 |
|---|---|
| `2026-08-17.json` | 전회 스냅샷(기준선) |
| `2026-08-18.json` | 금회 스냅샷 |

담긴 브랜드: B 브랜드(성분 중심 더마) · C 브랜드(가성비 대용량) · D 브랜드(감성 라이프스타일) · A 브랜드(우리 자신, 비교 참고용).
수집 항목: 정가·할인가·랜딩 H1·서브카피·프로모션 배너·채널 구성·리뷰수·인스타 팔로워·주간 블로그 발행·배송 배지.

## ⚠️ 이 fallback은 "첫 실행이 기준선만 저장"하는 경우가 아니다

기준선(`2026-08-17.json`)이 샘플 폴더에 이미 있기 때문에, 이 예시는 **두 번째 회차처럼
바로 diff 결과가 나온다.** 직접 URL을 넣어 처음 돌리면 그때는 진짜로 기준선 저장만 하고 끝난다 —
이 예시가 보여주는 건 그다음 상태다. 결과는 `example/output.md` 참조.

## 멈추는 곳 셋

| 언제 | 묻는 것 | 그냥 두면 |
|---|---|---|
| 대상 확정 | 3곳·주 1회 맞나 | 샘플 3사(B·C·D) · 주 1회 |
| 노션 적재 | 쌓을까 | **안 쌓음** (로컬만) |
| 자동 가동 | 주 1회 걸까 | **안 걺** |

뒤의 둘은 **외부에 쓰는 일**이라 기본값이 "안 함"이다. 승인해야만 한다.
