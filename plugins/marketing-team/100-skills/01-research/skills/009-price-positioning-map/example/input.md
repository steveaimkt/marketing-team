# 실습 입력 · 009 가격 조사

```
sample-data/경쟁사-3곳.md 로 가격 포지셔닝 맵 그려줘
```

## 이 실습의 핵심 · 단위가격

그냥 보면 이렇다.

| | 가격 | 인상 |
|---|---|---|
| 자사 A | 30ml **39,000원** | 비싸다 |
| C사 | 100ml **22,000원** | 싸다 |

ml당으로 바꾸면 이렇다.

| | ml당 | 배율 |
|---|---|---|
| 자사 A | **1,300원** | - |
| C사 | **220원** | **6배 차이** |

**정규화하지 않으면 경쟁을 잘못 읽는다.** C사와 우리는 애초에 같은 싸움이 아니다.

## 평점·리뷰수는 원본에 없으면 `[추정]`을 붙인다

`sample-data/경쟁사-3곳.md`에는 **평점 수치가 하나도 없다.** 리뷰수도 C사의 "1.2만 건"만
텍스트로 있고 B·D사는 그마저 없다. 자사(A)는 `sample-data/A브랜드-리뷰-200건.csv`의
수분 세럼 리뷰(57건)에서 실제 평점(3.25)·건수(57)를 계산해 쓴다 — 이건 [추정]이 아니라
실측이다. 반면 B·D사의 평점·리뷰수, C사의 평점은 원본에 없어 **반드시 `[추정]`을 붙인다**
(`example/output.md` 참조).

## 가치 점수는 감으로 매기지 않는다

```
가치 = 평점(/5 × 60) + 리뷰규모(log10 × 5, 최대 20) + 스펙 충족률(× 20)
```

공식이 고정이라 다시 실행해도 같은 점수가 계산된다.

## 바꿔서 해 보기

- 자기 카테고리 경쟁사 가격을 캡처해 넣으면 그대로 돈다
- 스펙 체크리스트 5개를 바꾸면 가치 점수가 달라진다 (표에 공개된다)
