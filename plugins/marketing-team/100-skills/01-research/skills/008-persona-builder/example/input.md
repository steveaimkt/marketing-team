# 실습 입력 · 008 고객 유형 정리

```
sample-data/A브랜드-리뷰-200건.csv 로 페르소나 만들어줘
```

006 소비자 리뷰 분석을 먼저 돌렸다면 **그 산출물을 넣는 것이 가장 좋다.**
이미 5분류·클러스터가 되어 있어 바로 패턴으로 간다.

## ⚠️ 데이터가 없으면 안 돈다

이 스킬은 **최소 리뷰 50건 또는 인터뷰 3건**이 있어야 시작한다.
없으면 멈추고 요청한다. 상상으로 만들지 않는다.

```
❌ "30대 직장인 김지영 · 워라밸 중시 · 인스타 자주 봄"
     → 교과서 페르소나. 어느 브랜드에나 붙고 아무 데도 못 쓴다
✅ "용기 끝까지 못 써서 아깝다 — 리뷰 20건 + 헐거운 펌프 13건 + 잔량 안 나옴 6건, 총 39건(19.5%)에서 관찰된 패턴"
     → 실제 문구·건수가 붙어 있어 검증할 수 있다
```

리뷰 데이터에는 **연령·직업 같은 인구통계가 없다.** 그래서 페르소나 카드의 나이·직업 칸은
지어내지 않고 "데이터 없음"으로 비워 둔다 — 007 설문 설계로 넘어가야 채워지는 칸이다.

## 나이만 다른 페르소나는 만들지 않는다

3~5종은 **서로 다른 니즈·행동 축**이어야 한다.
「30대 김지영 / 40대 박서연」처럼 나이만 바뀐 건 하나의 페르소나다.

## 바꿔서 해 보기

- 자기 쇼핑몰 리뷰 CSV 를 넣으면 그대로 돈다
- 007 설문 응답이 있으면 함께 넣는다 (구매 동기가 훨씬 선명해진다)
