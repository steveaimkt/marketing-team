## 이 예시에서 반드시 지킬 것

- **줄 구성 순서**: 계획 표 → 분석할 데이터 → 저장 위치 → 파일 형식(+ csv 대체 안내) → 확인 절차
  → 예상 시간 → (자료 없으면) 데이터 수급 HANDOFF → 기간·업종 질문 → (연결 여부에 따라) 바깥
  연결 고지 → `[승인 요청]`.
- **"저장 위치"는 `outputs/{날짜}/006-review-mining/`까지만 적는다.** 개별 파일명은 "파일 형식"
  줄에서 다룬다.
- **파일 형식은 반드시 세 가지(표 .xlsx · 화면 .html · 해설 .md)를 다 적는다.** 하나라도 빠지면
  `writes_to` 계약 위반이다.
- **"확인 절차"에 pii 마스킹과 "광고 표현 검사는 하지 않는다"(gate:false)를 함께 적는다.**
  둘 중 하나만 적어서 사용자가 "아예 검토가 없다"고 오해하게 하지 않는다.
- **데이터 수급 HANDOFF는 플랫폼별(스마트스토어·쿠팡·자사몰) 경로 + 넣을 곳을 구체적으로 적는다.**
  "CSV를 넣어주세요" 처럼 뭉뚱그리지 않는다.
- **계획 검증(plan-compiler) 오류 같은 내부 사정은 이 화면 어디에도 적지 않는다.**
