# 실습 입력 · 006 소비자 리뷰 마이닝

```
sample-data/A브랜드-리뷰-200건.csv 로 리뷰 분석해줘
```

파일을 안 주면 한 번 묻고 이 샘플로 진행한다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 |
|---|---|
| 리뷰 200건 | `sample-data/A브랜드-리뷰-200건.csv` |
| 업종·"사는/떠나는 이유" | `brand/profile.md` · 비어 있으면 A 브랜드 |

## 샘플에 든 것

수분 세럼 리뷰 200건 · 평균 별점 **3.25** · 별점 1~5 고루 섞여 있다.
좋은 말만 있으면 분석할 게 없어서 **일부러 낮은 별점을 섞어 두었다.**

## 개인 정보는 자동으로 가린다

```
김민지 → 김**   ·   010-1234-5678 → 010-****-****
```

묻지 않는다. 항상 가린다. 산출물 전 구간에 적용된다.

## 바꿔서 해 보기

- 자기 쇼핑몰 리뷰를 CSV 로 내려받아 넣으면 그대로 돈다
- 열 이름이 달라도 된다 · 리뷰 본문이 든 열만 있으면 찾는다
