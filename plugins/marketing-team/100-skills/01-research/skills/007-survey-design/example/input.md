# 실습 입력 · 007 설문 설계 & 분석

## ⚠️ 이 스킬은 두 번에 나눠 돈다

```
1차 (설계)  → 사람이 설문을 돌린다 → 2차 (분석)
```

**1차 · 설계만**
```
설문 설계해줘. 목적 〈왜 재구매를 안 하는지 알고 싶다〉
```

**2차 · 응답 받아 온 뒤**
```
설문 응답 분석해줘. 〈응답 CSV〉 첨부
```

1차만 돌려 봐도 된다. 설문지가 나온다.

## 목적을 「가설」로 바꾸는 것이 핵심

```
❌ "고객을 알고 싶다"        — 검증할 수 없다
✅ "30대는 가격보다 성분을 먼저 본다"  — 문항으로 물어볼 수 있다
```

Phase 2 에서 이걸 먼저 확인한다. 가설이 안 나오는 목적은 여기서 구체화한다.

## 자동으로 막는 것 셋

| 금지 | 예 |
|---|---|
| 유도 질문 | "이 제품이 좋다고 생각하시죠?" |
| 이중 질문 | "가격과 품질에 만족하십니까?" (둘 중 뭘 답하나) |
| 어려운 말 | "본 제품의 세라마이드 함유 비율에 대한 인식은" |

문항표에 3종 검사 통과 여부가 표기된다.
