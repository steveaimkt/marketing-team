# 실습 입력 · 035 이벤트·기브어웨이 설계

```
팔로워 늘리는 이벤트 기획해줘. 경품 예산 50만원
```

## ⚠️ 목표를 2개 고르면 멈춘다

「팔로워도 늘리고 구매도 유도하고 싶다」는 가장 흔한 요청이고 **가장 확실한 실패**다.
참여 조건이 충돌하기 때문이다.

| 목표 | 참여 조건 | 충돌 |
|---|---|---|
| 팔로워 | 팔로우 + 댓글 (진입장벽 최소) | ← 쉬워야 한다 |
| 전환 | 구매 인증 | ← 어려워야 한다 |

둘을 같이 걸면 **쉬운 쪽만 하고 빠진다.** 그래서 주 목표 1개를 먼저 고르게 한다.

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 목표 1개 | 발화 | **묻고 멈춘다** |
| 경품 예산 | 발화 | **묻고 멈춘다** |
| 하지 않는 것 | `brand/profile.md` | A 브랜드 기본 |

## 바꿔서 해 보기

- 「UGC 목표」로 바꿔 본다 → 해시태그 챌린지로 바뀌고 **2차 활용 동의 문구**가 붙는다 (037 연결)
- 경품을 100만원으로 올려 본다 → **경품류 고시** 관련 고지가 추가된다
