# 실습 입력 · 034 인플루언서 계약·브리프

```
이 인플루언서한테 보낼 브리프 만들어줘
```

033 을 먼저 돌렸으면 선정 사유와 ⚠️ 플래그를 그대로 이어받는다.

## 안 정하면 가장 좁게 잡는다

| 항목 | 기본값 | 왜 |
|---|---|---|
| 2차 활용권 | **3개월 · 자사 채널만** | 광고 소재까지 쓰려면 단가가 다르다 |
| 독점 | **없음** | 「영구 독점」은 쓰지 않는다 · 기간 없는 독점은 무효 다툼이 난다 |
| 원본 파일 | 제공 요청 | 나중에 요청하면 안 준다 |

## 대가성 표기가 브리프의 본체다

공정위 추천·보증 심사지침 기준이다.

- **첫 화면 / 제목 / 첫 해시태그**에 「광고」 또는 「협찬」
- 「더 보기」 뒤나 해시태그 더미 속에 숨기면 위반
- 유튜브는 **「유료 광고 포함」 기능 + 구두 언급** 둘 다
- 스토리는 **매 컷** 표기

이걸 브리프에 안 적으면 인플루언서가 알아서 하지 않는다. **책임은 광고주에게 온다.**

## 바꿔서 해 보기

- 「광고 소재로도 쓸 거야」라고 붙여 본다 → 2차 활용 조항이 확장되고 **단가 인상 안내**가 붙는다
- 「6개월 독점」이라고 해 본다 → 경쟁사 범위(경쟁 3사)가 명시되고 단가 영향이 표기된다
