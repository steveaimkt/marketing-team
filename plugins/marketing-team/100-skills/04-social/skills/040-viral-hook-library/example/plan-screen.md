무엇이 나오나: 패턴 태그와 어울리는 채널이 붙은 훅 10종 표, 그 가운데 TOP 3 추천

- 인스타그램: 인스타그램 앱 → 프로페셔널 대시보드 → 인사이트 → 기간 선택 → 데이터 내보내기 → inputs/instagram-insights.csv

- 근거 수치: 훅이 약속할 숫자나 결과물을 적어주세요. 예) 「3시간 → 12분」
