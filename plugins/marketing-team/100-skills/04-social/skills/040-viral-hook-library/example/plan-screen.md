# 실습 계획 화면 · 040 바이럴 훅 정리

> 실측 2026-09-13 · `원고소스/05_실측정리_원본자료/9장/039-021-031-040_20260913_체인/대화로그/9장_run_t1_시작-계획.jsonl`
> 스트림 JSON 캡처의 assistant 텍스트 블록에서 그대로 옮겼다. 040 은 단독 호출 실측이 따로 없다 —
> "콘텐츠 마케팅팀 업무 시작하자"로 부른 **039→021→031→040 체인**의 1차 계획 화면에서, 040 이
> 4단계 행으로 들어간 형태가 유일한 실측이다. 같은 요청에 대한 2차 화면("경로 재조정")은 내부
> 도구("실행 영수증 도구가 …를 요구해서") 사정을 노출해 이 예시로 쓰지 않았다 — 1차가 내부 사정
> 언급 없이 더 깨끗하다. **이 스킬이 체인 안에서 불리면 아래와 같은 구성·순서로 낸다** —
> 문장을 토씨까지 맞출 필요는 없지만, 어떤 줄이 있고 어떤 순서로 오는지는 이 예시를 따른다.

## 나

```
콘텐츠 마케팅팀 업무 시작하자
```

## AI 마케터

````text
[실행 계획]
콘텐츠마케팅팀 · 039 → 021 → 031 → 040

프로필(`brand/profile.md`)·톤(`brand/tone.md`)이 아직 빈 템플릿입니다. **[샘플] 가상의 A브랜드(화장품)** 기준으로 4단계를 완주합니다.

| 순서 | 스킬 | 무엇이 나오나 | 멈추는 곳 |
|---|---|---|---|
| 1 | 스킬 039 · 채널 성장 진단 | 인스타 계정 병목 진단, 저성과 콘텐츠 훅 분석, 우선 액션 3가지 | 없음 (내부 문서) |
| 2 | 스킬 021 · 월간 콘텐츠 기획 | 채널 믹스·퍼널 배분이 반영된 30일 캘린더 | 없음 (내부 문서) |
| 3 | 스킬 031 · 인스타그램 피드 기획 | 그리드 무드보드 + 30일 캡션·해시태그 + 이미지 프롬프트 | AI 규제검토자 (오퍼·효능 표현 검사) |
| 4 | 스킬 040 · 바이럴 훅 정리 | 1·3단계 저성과 콘텐츠 대상 훅 10종 + TOP 3 | AI 규제검토자 (효능 과장 검사) |

읽는 자료 · 샘플 A브랜드-인스타-인사이트-30편.csv, A브랜드-콘텐츠성과-90일.csv (각 스킬 sample_fallback)
근거로 쓰는 것 · 1단계 진단 결과를 2단계 기획 근거로, 2·3단계 산출물을 4단계 훅 대상으로 이어 받습니다
나오는 곳 · `outputs/2026-09-콘텐츠마케팅팀/01-039-…/` ~ `04-040-…/`
걸리는 시간 · 6~8분

나오는 형식 · 표 `.xlsx`, 화면/캘린더 `.html`(1·2단계), 해설 `.md`
다른 그릇 · 표를 `.csv`로 받으시려면 "진행 승인. 표는 csv로"

말린다 · 없음 (해당 없음)
리스크 한 줄 · 3·4단계는 대외 발행 콘텐츠라 AI 규제검토자 통과 전에는 전달하지 않습니다

[승인 요청]
⏸ 이대로 갈까요? 진행하려면 **`진행 승인`**이라고 답해주세요.
````

## 이 예시에서 반드시 지킬 것

- **체인으로 부르면 계획 화면은 스킬마다 따로 뜨지 않고, 4단계 전부를 한 표(순서·스킬·무엇이
  나오나·멈추는 곳)에 담아 승인을 한 번만 받는다.** 040 을 체인 밖에서 단독 호출했을 때 이
  구성 그대로 쓰라는 뜻이 아니다 — 040 만 단독으로 부른 실측이 아직 없다는 점을 그대로 밝힌다.
- **표의 "멈추는 곳" 칸에 040 은 "AI 규제검토자 (효능 과장 검사)"라고 구체적으로 적는다.** 1·2
  단계처럼 "없음"으로 뭉뚱그리지 않는다 — 040 은 대외 발행 콘텐츠(훅 문구)라 게이트가 있다.
- **줄 구성 순서**: `[실행 계획]` → 체인 제목(039→021→031→040) → 데이터 모드([샘플] 고지) →
  4단계 표 → 읽는 자료 → 근거로 쓰는 것 → 나오는 곳 → 걸리는 시간 → 나오는 형식(+ csv 대체
  안내) → 말린다 → 리스크 한 줄 → `[승인 요청]`.
- **"리스크 한 줄"에 3·4단계(031·040)가 대외 발행 콘텐츠이며 규제검토자 통과 전에는 전달하지
  않는다는 사실을 명시한다.** 040 산출물이 검토 없이 그대로 나가는 것처럼 적지 않는다.
- **내부 도구 사정(예: "실행 영수증 도구가 …를 요구해서" 같은 저장 경로 재조정 사유)은 이
  화면 어디에도 적지 않는다.** 실측에서 실제로 2차 화면에 이렇게 샌 적이 있다.
