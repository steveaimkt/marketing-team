# 실습 입력 · 039 채널 성장 진단

```
인스타 성장 진단해줘
```

성과 파일로도 연습할 수 있다.

```
sample-data/A브랜드-채널성과-90일.csv 로 성장 진단해줘
```

## 병목은 하나만 찍는다

퍼널을 **유입 → 도달 → 참여 → 전환**으로 쪼개고, **낙폭이 가장 큰 한 구간**만 병목으로 지목한다.
세 군데를 동시에 고치라는 진단은 아무것도 안 고치게 만든다.

| 구간 | 참고 벤치마크 |
|---|---|
| 인스타 팔로우 전환 (프로필 방문 → 팔로우) | 3~5% |
| 릴스 비팔로워 도달 | 50% 이상 |
| 유튜브 노출 CTR | 2~10% |

## 이 실습이 쓰는 것

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 계정 수치 | 인사이트 캡처 · 유튜브 MCP | 공개 지표만으로 `[추정]` · **먼저 고지** |
| 지난 진단 | `logs/` 또는 이전 리포트 | 첫 진단으로 진행 |

## 바꿔서 해 보기

- 지난 리포트를 같이 줘 본다 → **지난 액션 3가지의 실행 여부부터** 확인하고 시작한다
- 기간을 90일로 넓혀 본다 → 계절성이 분리되어 진짜 정체인지 아닌지가 갈린다
