# 실습 입력 · 038 소셜 리스닝 리포트

```
우리 브랜드 언급 주간 리포트 뽑아줘
```

## ⏸ 이 스킬은 두 번 묻는다

| 묻는 것 | 안 하면 |
|---|---|
| Notion 에 적재할까요 | **화면에만 낸다** |
| 주 1회 자동 실행으로 걸까요 | **1회성으로 끝낸다** |

`mutating: true` 인 스킬이다. 밖에 뭔가를 쓴다.
**한번 걸어 둔 자동화는 아무도 안 끈다.** 그래서 승인 없이는 상시 가동하지 않는다.

## 키워드 세트에 무엇이 들어가나

- 브랜드명 + **오타·띄어쓰기 변형** (A브랜드 / A 브랜드 / 에이브랜드)
- 제품명
- 비교 문구 (`A브랜드 vs`)
- 대표 해시태그
- **제외어**: 동음이의로 오염되는 말
