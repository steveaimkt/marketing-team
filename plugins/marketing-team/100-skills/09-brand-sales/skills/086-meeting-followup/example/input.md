# 실습 입력 · 086 회의 결과 정리

```
이 미팅 정리해줘
```

## 없는 신호를 만들지 않는다

영업 신호가 안 보이면 **「신호 없음」이라고 적는다.**
없는 신호를 만들어 내면 그 제안서가 **엉뚱한 Pain Point 를 바탕으로** 만들어진다.

## 3구획으로 나눈다

| 구획 | 내용 |
|---|---|
| ✅ 결정사항 | 양측이 합의한 것 (**근거 발언 위치 표기**) |
| ⏳ 보류·미결 | 다음 접점으로 넘어간 것 + **막힌 이유** |
| ☑️ 할 일 | **우리 것 vs 상대 것 분리** |

상대 대기 항목을 따로 두는 이유는 **팔로업 리듬**을 설계하기 위해서다.

## 내부 회의면 이 스킬이 아니다

판별되면 **093 으로 안내하고 종료**한다.

## 바꿔서 해 보기

- 내부 회의 메모를 넣어 본다 → 093 으로 안내하고 끝난다
- 예산 언급이 있는 녹취를 넣어 본다 → **영업 신호 메모**가 채워지고 084 입력이 된다

## 이 실습이 쓰는 재료

재료가 없으면 `sample_fallback`(`A브랜드-미팅메모.md`)으로 채운다. **H드럭스토어와의 오프라인
입점 협의 손메모**로, 합의된 결정사항은 없고 대부분 보류·미결과 "못 물어본 것"이다.
합의가 없는데 있는 것처럼 만들지 않고, **결정사항 0건을 0건 그대로** 낸다.
