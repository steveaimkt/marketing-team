# 사용 가이드 · 3분

> ⚠️ **경로 규칙은 `docs/공통규약.md §0` 이다.**
> `100-skills/` 는 **패키지 안**, `brand/` · `outputs/` 는 **작업 폴더**다.

**설명을 길게 하지 않는다.** 아래 네 토막을 순서대로, 각각 짧게 낸 뒤 **바로 ⑤로 간다.**

---

## ① 이게 뭔가 · 3줄

```
마케팅 업무 100가지를 절차로 만들어 둔 것입니다.
키워드 조사 · 경쟁사 분석 · 상세페이지 · 광고 리포트 · 보도자료 …
하고 싶은 일을 그냥 말하면 알맞은 절차를 찾아 결과를 파일로 만들어 드립니다.
```

**「스킬 100개」와 「메뉴의 6개」를 반드시 구분해 준다.** 여기서 안 짚으면 첫날 신뢰가 깨진다.

```
메뉴에 보이는 6개는 준비·안내용입니다.
실제 마케팅 업무 100개는 그 뒤에 있고, 말로 부릅니다.
```

## ② 무엇을 시킬 수 있나 · 부를 말과 함께

`100-skills/ROUTING.md` 를 열어 **카테고리 10개와 대표 「부를 말」** 을 낸다.
100줄을 다 내지 않는다. **말이 붙어 있어야 「아, 저렇게 말하면 되는구나」가 된다.**

```
번호      분야          이렇게 말하면 됩니다

001~010  시장조사       "키워드 조사해줘"  "경쟁사 분석해줘"  "리뷰 분석해줘"
011~020  제품기획       "차별점 정리해줘"  "가격 어떻게 잡지?"  "런칭 플랜 짜줘"
021~030  콘텐츠         "블로그 글 써줘"  "뉴스레터 써줘"  "유튜브 대본 써줘"
031~040  소셜           "인스타 피드 기획해줘"  "인플루언서 찾아줘"
041~050  광고           "이번 달 광고 어땠어"  "예산 다시 짜줘"  "광고 카피 만들어줘"
051~060  커머스         "상세페이지 써줘"  "상품명 최적화해줘"  "리뷰 답변 달아줘"
061~070  데이터         "매출 분석해줘"  "월간 리포트 만들어줘"
071~080  CRM            "이메일 시퀀스 짜줘"  "이탈 고객 되돌리자"
081~090  브랜드·세일즈   "보도자료 써줘"  "제안서 만들어줘"  "브랜드 스토리 써줘"
091~100  운영           "반복 업무 진단해줘"  "예산 계획 짜줘"
```

> **여기서는 「부를 말」이 주인공이다.** 번호와 이름을 훑는 것은 `스킬-100-보기` 의 일이다.
> **한 분야를 자세히 보고 싶다**거나 **전체 목록을 달라**고 하면 거기로 보낸다. 여기서 펼치지 않는다.

## ③ 어떻게 부르나 · 세 가지

```
그냥 말한다      "리뷰 분석해줘"   "이번 달 광고 어땠어"   "상세페이지 써줘"
번호로 부른다    "046 돌려줘"
한 바퀴 돌린다   "광고애널리틱스 돌려줘"    ← 여러 개를 순서대로 (체인 15종)
```

**명령어를 외우지 않는다.** 위에 적은 것은 예시일 뿐이고, **부르는 말이 454개** 등록돼 있다.
비슷하게만 말하면 걸리고, 그래도 안 걸리면 가장 가까운 것을 찾아 준다.

## ④ 두 단계뿐이다

```
지금       스킬 100개를 바로 쓴다. 브랜드 정보가 없으면 샘플로 돌고 [샘플] 이 붙는다
브랜드 등록 「2-브랜드-등록하기」 · 정보를 채우면 100개 중 우리 것 15~30개만 골라
           내 에이전트로 조립된다. 그때부터 [실데이터] 가 붙는다
```

**따로 「구축」을 부르지 않는다.** 정보를 채우면 그 자리에서 조립까지 이어진다.

> **데이터는 둘 중 아무거나로 시작할 수 있다.** 다음 단계에서 한 번 고르게 된다.
> **샘플**(가상의 A브랜드 · 준비할 것 없음) 또는 **내 파일**(`inputs/` 에 넣으면 됨).
> 지금 데이터가 없어도 전 과정이 그대로 돈다.

> 대외로 나가는 산출물 32개는 **발행 전 규제 검토**를 거친다.
> 발송·발행·예산처럼 되돌릴 수 없는 일은 **직전에 멈추고 묻는다.**

## ⑤ 넘긴다 · 생략 불가

⚠️ **설명하고 끝내지 않는다.** 여기서 멈추면 읽기만 한 것이 된다.
**직접 실행하지도 않는다** — 세팅과 첫 실행은 `1-시작하기` 의 일이다.

이렇게 말하고 **바로 `1-시작하기` 를 실행한다.** 「해볼까요?」라고 묻고 기다리지 않는다.

```
이제 준비하고 첫 결과물을 하나 만들어 보겠습니다.
쓸 수 있는 상태인지 확인하고, 작업 폴더를 만들고, 스킬 하나를 실제로 돌립니다. 1~2분입니다.
```

- 사용자가 **하고 싶은 일을 이미 말했으면** 그것을 `1-시작하기` 에 함께 넘긴다.
  「인스타 피드 기획하고 싶다」고 했으면 첫 실행을 031 로 하도록 알려 준다.
- 아무 말도 없으면 그냥 넘긴다. `1-시작하기` 가 알아서 고른다.
- **묻지 않고 넘긴다.** 여기서 한 번 더 물으면 3분이 5분이 된다.

## 규칙

- **길게 설명하지 않는다.** ①~④는 각각 표 하나·줄 셋이면 충분하다
- **없는 것을 있다고 하지 않는다.** 스킬이 100개가 아니면 실제 개수를 말한다
- **검사하지 않는다.** 세고 고치는 것은 `1-시작하기` 의 일이다
- **여기서 업무를 실행하지 않는다.** 보여주고 넘기는 데까지다
- 뭔가 안 뜨거나 버전이 옛것 같으면 → `1-시작하기` 가 세 층 중 어디가 어긋났는지 짚어 준다
