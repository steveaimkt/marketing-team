# 사용 가이드 · 3분

> ⚠️ **경로 규칙은 `docs/공통규약.md §0` 이다.**
> `100-skills/` 는 **패키지 안**, `brand/` · `outputs/` 는 **작업 폴더**다.

**설명을 길게 하지 않는다.** 아래 네 토막을 순서대로, 각각 짧게 낸 뒤 **바로 ⑤로 간다.**

---

## ① 이게 뭔가 · 3줄

```
마케팅 업무 100가지를 절차로 만들어 둔 것입니다.
키워드 조사 · 경쟁사 분석 · 상세페이지 · 광고 리포트 · 보도자료 …
하고 싶은 일을 그냥 말하면 알맞은 절차를 찾아 결과를 파일로 만들어 드립니다.
```

**「스킬 100개」와 「메뉴의 6개」를 반드시 구분해 준다.** 여기서 안 짚으면 첫날 신뢰가 깨진다.

```
메뉴에 보이는 6개는 준비·안내용입니다.
실제 마케팅 업무 100개는 그 뒤에 있고, 말로 부릅니다.
```

## ② 무엇을 시킬 수 있나 · 표 하나

`100-skills/ROUTING.md` 를 열어 카테고리 10개만 낸다. **100줄을 다 내지 않는다.**

```
001~010  시장조사    키워드 · 경쟁사 · 시장규모 · 트렌드 · 리뷰 · 페르소나
011~020  제품기획    컨셉 · USP · 네이밍 · 가격 · GTM
021~030  콘텐츠      캘린더 · 블로그 · 뉴스레터 · 유튜브 · OSMU
031~040  소셜        인스타 · 응대 · 인플루언서 · 이벤트 · 리스닝
041~050  광고        쿠팡 · 네이버 · 메타 · 구글 · ROAS · 심의
051~060  커머스      상세페이지 · 상품명 · 리뷰 · 프로모션
061~070  데이터      매출 분석 · GA4 · 코호트 · KPI · 월간 리포트

091~100  운영        업무 진단 · 스킬 제작 · 예산 · 오케스트레이션
```

## ③ 어떻게 부르나 · 세 가지

```
그냥 말한다      "리뷰 분석해줘"   "이번 달 광고 어땠어"   "상세페이지 써줘"
번호로 부른다    "046 돌려줘"
한 바퀴 돌린다   "광고애널리틱스 돌려줘"    ← 여러 개를 순서대로 (체인 15종)
```

**명령어를 외우지 않는다.** 부르는 말이 454개 등록돼 있고, 안 걸리면 비슷한 것을 찾아 준다.

## ④ 두 단계뿐이다

```
지금       스킬 100개를 바로 쓴다. 브랜드 정보가 없으면 샘플로 돌고 [샘플] 이 붙는다
브랜드 등록 「2-브랜드-등록하기」 · 정보를 채우면 100개 중 우리 것 15~30개만 골라
           내 에이전트로 조립된다. 그때부터 [실데이터] 가 붙는다
```

**따로 「구축」을 부르지 않는다.** 정보를 채우면 그 자리에서 조립까지 이어진다.

> 대외로 나가는 산출물 32개는 **발행 전 규제 검토**를 거친다.
> 발송·발행·예산처럼 되돌릴 수 없는 일은 **직전에 멈추고 묻는다.**

## ⑤ 지금 하나 만들어 본다 · 생략 불가

⚠️ **여기서 끝내면 읽기만 한 것이다.** 설명 다음에 반드시 결과물이 나와야 한다.

이렇게 묻는다.

```
지금 바로 하나 만들어 볼까요? 셋 중에 고르셔도 되고, 하고 싶은 걸 말하셔도 됩니다.

  ① 키워드 조사      팔고 싶은 것 한 단어만 주시면 됩니다
  ② 경쟁사 분석      경쟁사 이름 2~3개
  ③ 리뷰 분석        리뷰가 있으면 붙여 주세요 (없으면 샘플로 보여드립니다)
```

- 답이 없으면 **①로 간다.** 입력이 가장 적고 결과가 눈에 보인다.
- 브랜드 정보가 없어도 **멈추지 않는다.** 샘플로 완주하고 `[샘플]` 을 붙인다.
- 끝나면 **산출물 파일 경로**를 알려 준다. 화면에만 띄우고 끝내지 않는다.

## ⑥ 마치며 · 한 줄만

결과를 보여준 뒤 **하나만** 권한다. 여러 개를 늘어놓지 않는다.

| 방금 나온 것이 | 이렇게 말한다 |
|---|---|
| `[샘플]` 이 붙었다 | 「우리 회사 걸로 바꾸려면 **`2-브랜드-등록하기`** 입니다. 3분이면 됩니다.」 |
| `[실데이터]` 다 | 「다음은 **{chains_to 의 스킬}** 을 권합니다.」 |
| 뭔가 안 떴다 | 「**`1-시작하기`** 로 점검해 보겠습니다.」 |

## 규칙

- **길게 설명하지 않는다.** ①~④는 각각 표 하나·줄 셋이면 충분하다
- **없는 것을 있다고 하지 않는다.** 스킬이 100개가 아니면 실제 개수를 말한다
- **점검하지 않는다.** 세고 고치는 것은 `1-시작하기` 의 일이다. 여기서는 안내만 한다
- 산출물 첫 줄의 출처 태그(`[실데이터]`·`[샘플]`·`[추정]`)는 **지우지 않는다**
