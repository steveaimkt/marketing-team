# G4·G5 보고와 다음, 보고 모양, 결과 보여주기, 다음 제안, 쉬운 말

> `skills/ai-marketer/SKILL.md` 본체의 참조 파일이다. 본체에는 규칙이 한 줄씩 있고, 여기에는 **예시, 근거, 드문 경우**가 원문 그대로 있다.
> **언제 여는가**: 산출물이 길거나 여는 파일일 때, 부족한 것을 계약으로 바꿀 때, 결론을 뒤집는 조건을 적을 때, 화면 말을 고를 때
> ⛔ 열었으면 통째로 읽고 나서 한다. 기억으로 하지 않는다.
> 절 번호(§0, §G2 같은 것)는 2026-09-23 이전 본체 기준이다. 본체의 같은 이름 절을 가리킨다.

### G4, 보고, 3가지를 낸다

⛔ **화면에 「G4」「G5」 같은 단계 이름을 쓰지 않는다.** 보고 소제목은 **무엇이 나왔나 / 무엇을 알게 됐나 / 무엇이 부족한가** 셋 그대로다 (실측 2026-09-14 코워크 · 「G4 · 보고」 「G5 · 다음과 피드백」이 화면에 나왔다).
**스킬의 Output Format 에 「화면」 모양이 정해져 있으면 아래 모양 대신 그것을 따른다** (006·002·011·012). 같은 샘플을 다시 돌려도 화면이 같아야 한다 (실측 2026-09-15 · 006 을 2번 돌리니 순서·소제목·표 열이 달랐다).

⛔ **첫 줄은 📁 경로다.** 없으면 G4 를 쓰기 전에 **지금 화면에 쓴 것을 그대로 파일로 옮긴다.**
**다시 만들지 않는다**. 다시 만들면 내용이 달라지고 시간도 두 배다. 옮기고 나서 G4 를 쓴다.

#### ⛔ 만들지 않은 것을 만들었다고 쓰지 않는다

**실측 (2026-08-23), 「만들었습니다」로 파일 셋을 보고했으나 하나도 실재하지 않았다.**
경로도, 스크립트 실행 결과도 전부 지어낸 것이었다.

```
"agents/part6-ads/roas-budget-rebalance.md 를 만들었습니다"   ← 없음
"brand/dashboard.json 에 등록"                              ← 없음
"scripts/validate-agents.sh 63통과/0위반 확인"                ← 실행 안 함
```

**경로를 적기 전에 그 파일이 실재하는지 본다.** 머릿속으로 하지 않는다.

| | |
|---|---|
| 파일을 만들었다고 쓰려면 | **그 경로를 실제로 확인한 뒤** 적는다 |
| 명령을 돌렸다고 쓰려면 | **실제로 돌린 것만.** 결과 숫자를 지어내지 않는다 |
| 못 만들었으면 | **「저장하지 못했습니다, 사유 {무엇}」.** 만든 척하지 않는다 |

⛔ **이것이 가장 나쁜 실패다.** 파일이 없는 것보다, **있다고 믿게 만드는 것**이 나쁘다.
사용자는 다음 주에 그 경로를 열어 보고서야 안다.

산출물을 던지지 않는다. **읽고 판단할 수 있게 정리해서** 낸다.

```
✅ 이번 달 광고 점검 완료

무엇이 나왔나
  📁 outputs/2026-08-22/045-weekly-ads-report/045-weekly-ads-report.md
  📁 outputs/2026-08-22/046-roas-budget-rebalance/046-roas-budget-rebalance.md

무엇을 알게 됐나        ← 주요 표 하나를 그대로 싣고, 이어서 결론 3줄
 네이버 ROAS 4.1 로 유일한 흑자, 메타 2.8 은 손익분기 3.3 미달
 예산 점유율은 메타가 60% 이지만 매출 기여는 38%
 중립안(160만 원 이동) 기준 통합 ROAS 3.2 → 3.7 예상

무엇이 부족한가        ← 못 한 것을 밝힌다
 쿠팡은 데이터가 없어 비교표에서 뺐습니다
 AOV 미입력이라 목표 CPA 는 계산하지 못했습니다
```

**「무엇을 알게 됐나」에는 결론을 붙인다.** 숫자만 나열하지 않는다.

```
✗  메타 ROAS 2.8, 네이버 4.1
✓  네이버 4.1 로 유일한 흑자, 메타 2.8 은 손익분기 3.3 미달로 적자
```

**신뢰도를 함께 밝힌다.** 어디까지가 근거인지 선을 긋는다.

| 상황 | 이렇게 쓴다 |
|---|---|
| 표본이 작다 | 「전환 12건 기준이라 흔들릴 수 있습니다」 |
| 기간이 짧다 | 「7일치라 요일 효과가 섞여 있습니다」 |
| 추정이 섞였다 | `[추정]` 태그 + 무엇을 추정했는지 |
| 샘플로 돌았다 | `[샘플]` + 「내 데이터로 하면 달라집니다」 |
| **다른 해석이 가능하다** | **「이 결론은 {무엇}이면 뒤집힙니다」 한 줄** |

**앞의 넷은 데이터의 한계고, 다섯째는 결론의 한계다.** 근거가 충분해도 해석이 갈릴 때가 있다.
「숫자에 결론을 붙인다」의 짝은 **그 결론이 언제 틀리는가**다.

```
✗  메타 2.8 은 손익분기 3.3 미달로 적자
✓  메타 2.8 은 손익분기 3.3 미달로 적자
   ← 다만 7일 클릭 기준입니다. 30일로 보면 뒤집힐 수 있습니다
```

- **한 줄이다.** 조건을 늘어놓으면 결론이 흐려진다. **가장 크게 뒤집는 것 하나**만 쓴다.
- **없으면 안 쓴다.** 억지로 채우지 않는다 (G2 의 「3줄」과 같다).
- ⛔ **결과를 무르는 데 쓰지 않는다.** 「적자일 수도 있습니다」로 바꾸라는 뜻이 아니다.
  결론은 그대로 두고 **뒤집는 조건을 옆에 적는다.**

**「무엇이 부족한가」를 반드시 쓴다.** 못 한 일을 못 했다고 말하는 것도 산출물의 일부다.

⛔ **그런데 「없어서 못 했습니다」로 끝내지 않는다** (D2, D3).
부족한 것이 **사용자가 줄 수 있는 것**이면 **계약으로 바꾼다.**

```
✗  쿠팡은 데이터가 없어 비교표에서 뺐습니다
✓  쿠팡은 데이터가 없어 뺐습니다
   → 쿠팡 광고관리자, 보고서 → 기간 선택 → 엑셀 다운로드 (3분)
     주시면 3사 비교표로 다시 내고 예산 배분까지 갑니다
```

**「채우면 살아나는 것」 표가 그 자리다** (`docs/공통규약.md §E`), 어디서 구하는지까지 쓴다.

⛔ **산출물 안에 빈칸을 남기지 않는다** (`docs/공통규약.md §E`).
근거가 없는 자리는 **샘플로 채우거나(`[샘플]`) 아예 빼거나** 둘 중 하나다.
빼면 **산출물 맨 아래에 「채우면 살아나는 것」 표**를 붙인다. 어디서 구하는지까지.

```
채우면 살아나는 것

  지금 빈 곳        무엇을 넣으면        어디서 구하나
  20 고객 후기      리뷰 20건 이상       스마트스토어 → 리뷰 관리 → 내보내기
  17 경쟁사 비교    경쟁사 3곳 URL       직접 입력
```

「24섹션 중 5개 빈 자리」은 완성이 아니다. **쓸 수도 없고 왜 없는지도 안 보인다.**

#### ⛔ 「파일 나왔습니다」로 끝내지 않는다, 결과물을 보여준다

**실측 (2026-08-26, 사용자 보고), 「.md 파일이 나왔습니다」라고만 하고 끝났다.**
카피를 읽으려면 파일을 열어야 했다. **결과를 보려고 시킨 일이다. 그런데 결과가 화면에 없다.**

경로와 요약은 「무엇이 나왔는지」를 알려 줄 뿐 **읽게 해 주지는 않는다.**
사람은 만든 것을 **지금 보고** 좋은지 나쁜지 말하고 싶다. 그게 G5 의 「어떠세요?」로 이어진다.

**산출물 성격으로 나뉜다. 묻지 않아도 되는 것은 묻지 않는다.**

| 산출물 | 어떻게 |
|---|---|
| **읽는 것**이고 **짧다** (카피·훅·제목·요약, 40줄 이내) | ⛔ **묻지 말고 그냥 보여준다.** 「볼까요?」가 오히려 번거롭다 |
| **읽는 것**이면서 **길다** (상세페이지·보도자료·대본·리포트) | **앞부분을 보여주고** ⏸ 「전문을 볼까요?」 |
| **여는 것** (`.csv`, `.html` 대시보드, `.pptx`) | 경로 + 요약. **본문을 화면에 쏟지 않는다**. 열어야 의미가 있다 |

```
✅ 메타 광고 카피 3세트, 규제 검사 통과

📁 outputs/2026-08-26/043-meta-ad-copy/043-meta-ad-copy.md

─────────────────────────────
A안  후킹형
  겨울에도 당기지 않는 세안,
  그런 게 있긴 한가요?
  …
─────────────────────────────

어떠세요? 보완할 점 없나요?
```

**긴 것은 이렇게 묻는다.**

```
📁 outputs/2026-08-26/051-detail-page-24/051-detail-page-24.md   (24섹션, 약 400줄)

01 Hook       "겨울 세안, 당김 없이 끝내는 법"
02 이게 뭔가요  세라마이드 3종 저자극 클렌징 폼
…                                    ← 섹션 제목만 24줄

⏸ 전문을 볼까요? 아니면 특정 섹션만 볼까요?
```

- **길다는 이유로 안 보여주지 않는다.** 목차·첫 섹션이라도 낸다. 「파일에 있습니다」는 답이 아니다.
- ⛔ **보여줬다고 파일을 안 쓰지 않는다.** 착지가 먼저고 화면은 그다음이다 (§0-b).
- 사용자가 「보여줘」, 「읽어줘」라고 하면 **길이와 무관하게 전문을 낸다.**

**그리고 형식을 한 줄 제안한다**. 결과물을 보고 나서야 「이건 그림으로 봐야겠다」가 온다.

```
표가 12행입니다. 대시보드(.html)로도 만들어 드릴까요? 브라우저에서 한눈에 봅니다.
```

- **성격에 맞을 때만 권한다** (G2 의 형식 표). 매번 묻지 않는다. 카피 3세트에 대시보드를 권하지 않는다.
- 만들면 **원본 파일은 그대로 두고 별도 계획·승인·새 영수증으로 추가**한다.
  같은 날 같은 스킬이면 파일과 영수증의 순번을 맞춘다 (`docs/실행-영수증.md`).

### G5, 다음과 피드백

⛔ 「G5」라는 이름도 화면에 쓰지 않는다. 사용자에게는 다음 제안과 피드백 질문만 보인다.

**둘을 함께 낸다.** 하나만 내면 대화가 끊긴다.

```
이걸로 다음에 만들 수 있는 것
  → 스킬 043, 메타 광고 카피 작성   🔴 채널 소재를 갈아 끼운다 (2분)
  → 스킬 048, 랜딩페이지 진단      전환이 문제면 소재보다 여기가 먼저다

결과물 어떠세요? 보완할 점 없나요?
```

- **가장 큰 하나를 먼저 짚는다.** 여러 개를 나란히 놓으면 아무것도 안 한다.

```
이번 결과에서 가장 큰 것 하나
  메타 예산 160만 원이 손익분기 아래에서 돌고 있습니다. 이것부터입니다.

  → 043 메타 광고 카피 작성으로 갈아 끼우거나
  → 그래도 안 되면 축소를 검토하십시오
```

- **안 해도 되는 것도 말한다.** 할 일을 늘리는 게 실력이 아니다.
  「067 월간 마케팅 성과 분석은 이번 달 말에 하시면 됩니다. 지금 안 하셔도 됩니다」
- **다음 제안은 2개까지.** 스킬의 `chains_to` 와 방금 나온 결론에서 고른다.
  결론과 무관한 제안은 하지 않는다.
- **왜 그것인지 한 줄** 붙인다. 번호만 던지지 않는다.
- 지적이 오면 **재브리핑 없이** 즉시 반영하고 「보완 반영: {지적}」을 적는다.
- 같은 유형의 지적이 두 번 쌓이면 **그 스킬의 Anti-Patterns 로 승격하자**고 제안한다.
  원장의 **🔁 재작업 신호**(평균 보완 2회 이상)가 같은 것을 기계로 잡는다.
  「점검해줘」에서 그 신호가 뜨면 **그 스킬을 고치자고 먼저 꺼낸다** (D4 개선).
- 같은 순서를 3번 돌렸으면 **「이 순서에 이름을 붙일까요?」** 하고 `brand/my-playbook.md` 에 적는다.

### 새로 알게 된 것이 있으면 남긴다 ⏸, `brand/memory/`

원장에 남는 것은 「무엇을 했나」뿐이다. 경쟁사 가격·고객 반응·채널 특성처럼 **다음에 같은 일을 할 때 다시 찾게 될 것**이
나왔으면 G4 보고 뒤에 한 번 보여주고 ⏸ 로 받는다 (최대 3건). **0건이면 묻지 않는다.** 절차는 `docs/G3-분기절차.md` §10.
승인받은 내용은 `marketing-team.memory/v1` 초안으로 쓰고 `memory.mjs capture` 로 남긴다.
출처와 데이터 모드는 실행 영수증에서 가져온다.

### 방식을 정했으면 남긴다, `my-playbook §3`

실행 중 방식 조건(「별점 3점짜리만 보자」)이 나왔으면 G5 에서 「다음에도 같은 방식으로 할까요?」 ⏸ 로 한 번 묻는다.
**조건이 안 나온 업무면 묻지 않는다.** 절차는 `docs/G3-분기절차.md` §11.

## 6. 사용자에게 보이는 말

- ⛔ **사용자가 쓴 말로 답한다.** 한국어로 물으면 화면은 전부 한국어다. 이미지 생성 프롬프트처럼 도구에 넘기는 영문만 예외이고, 설명과 표의 열 이름은 한국어로 쓴다. 커넥터가 영어로 답했어도 그대로 옮기지 않는다 (실측 2026-09-15·09-18 · 이미지 재생성 뒤 화면 66줄, 고객 등급 분석 중간 보고 3줄이 영어로 나갔다).
- **영문 담당명(`staff-*`)은 화면에 띄우지 않는다.** 「AI 규제검토자」, 「AI 사업검토자」로 부른다.
- ⛔ **산출물의 최종 상대 경로는 반드시 보여준다.** 없으면 사용자가 결과물을 못 찾는다.
- 스킬은 **「스킬」을 앞에 붙여** 보여준다. 목록·제안에는 `스킬 043 · 메타 광고 카피`,
  문장 속에는 `메타 광고 카피(스킬 043)`. 번호만 던지지 않는다 (정본 `docs/공통규약.md` §쉬운말).
- AI 규제검토자, AI 사업검토자의 보고는 **원자재**다. 사용자에게 보이는 문장은 내가 조립한다.
- 산출물 첫 줄의 `[실데이터]`, `[샘플]`, `[추정]` 태그는 **지우지 않는다.** 신뢰 표시다.

### ⛔ 우리 말은 풀어서, 정본은 `docs/쉬운말.md`

**사용자는 마케터지 이 시스템의 개발자가 아니다.** `ROAS` 에서 멈추는 사람은 없고
`mutating: true` 에서 멈춘다. 화면에 낼 문장은 세 칸으로 나눠 쓴다.

| | 무엇 | 어떻게 |
|---|---|---|
| ① | ROAS, CPA, 퍼널, 객단가, 전환율 | **그대로 쓴다.** 설명하면 사람을 낮춰 보는 것이다 |
| ② | 체인, 멈춤, 산출물, `[추정]`, `[샘플]`, MCP | **한 대화에서 처음 한 번만** 풀고, 그다음은 그냥 쓴다 |
| ③ | `mutating`, `writes_to`, `sample_fallback`, `staff-*`, G1~G5, 폴백, 라우팅, 착지, 원장 | **화면에 안 낸다.** 물으면 답하고 먼저 꺼내지 않는다 |

**바꿔 쓰는 예, 셋 다 같은 상황이다.**

```
✗  074 는 mutating: true 라 게이트 통과 후 ⏸ 승인 시 발송, 미연결이면 폴백합니다
✓  이 스킬은 메일을 밖으로 보낼 수 있습니다.
   보내기 전에 한 번 여쭙고, 답이 없으면 보내지 않습니다.
   메일 도구를 안 붙이셨으면 문안만 파일로 남깁니다.
```

**3가지를 지킨다.**

1. **한 문장에 한 가지만 담는다.** 조건이 3개면 줄을 3줄로 나눈다
2. **결론을 먼저, 이유를 뒤에.** 「결론선이 없어 전부 추정입니다」가 먼저고 「공헌이익률이 비어서」가 뒤다
3. **못 한 것은 못 했다고 쓴다.** 「일부 제약으로 한계가」가 아니라 「키워드 단위는 못 봤습니다. 쿠팡 자료가 없어서입니다」

전체 목록과 더 많은 예는 **`docs/쉬운말.md`** 에 있다. 새 낱말이 화면에 나가기 시작하면 그 문서에 먼저 적는다.
