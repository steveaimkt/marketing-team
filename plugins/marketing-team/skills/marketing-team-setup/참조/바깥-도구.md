# 바깥 도구 · 브라우저와 문서 스킬

> `SKILL.md` ①에서 떼어 냈다 (2026-11-13 · 본문 500줄 기준). 글은 그대로 옮겼다.
> **브라우저 도구나 문서 스킬(.pptx·.docx·.xlsx·.pdf)이 붙었는지 볼 때** 이 파일을 통째로 읽고 나서 그 단계를 한다. 기억으로 하지 않는다.

### 브라우저 도구는 따로 붙는다 · 7개 항목에 넣지 않는다

**이 플러그인은 `.mcp.json` 으로 브라우저 도구(`playwright`)를 함께 낸다.** 플러그인을 설치할 때
클로드가 「이 MCP 서버를 붙일까요?」를 한 번 묻고, 승인하면 그때 붙는다. **따로 설치할 것은 없다.**

⛔ **①의 7개 항목에 넣지 않는다.** 7개는 플러그인 안을 확인하는 것이고 브라우저 도구는 밖에서 붙는다.
「여덟 항목」이라고 말하지 않는다.

| | |
|---|---|
| **무엇이 달라지나** | 공개된 웹 페이지를 직접 읽는다 · `[추정]` 이 실측으로 바뀐다 |
| **어느 스킬이** | `001` 키워드 수요 조사 · `002` 경쟁사 분석 · `003` 경쟁사 상시 조사 · `005` 트렌드 조사 · `038` 소셜 언급 분석 |
| **못 붙었으면** | 그 스킬들은 **그대로 돈다.** 자료를 손으로 받는 길로 돌아갈 뿐이다 |

### 문서 스킬 · 있으면 더 되고 없어도 완주한다

`.pptx`·`.docx`·`.xlsx`·`.pdf` 는 **앤트로픽 공식 스킬**이 맡는다. **대부분 이미 깔려 있다.**
점검에서 없으면 **한 줄로만 알린다.** ⛔ 설치를 강요하지 않는다.

```
발표자료를 .pptx 로 받거나 PDF·워드 문서를 읽으려면 공식 문서 스킬이 필요합니다.
  /plugin marketplace add anthropics/skills
  /plugin install document-skills@anthropic-agent-skills
없어도 전 과정이 완주됩니다. 그때는 .md 로 나갑니다.
```

**`.pptx`·`.docx` 를 짓는 도구도 함께 본다.** 공식 스킬은 `.pptx` 를 `pptxgenjs` 로, `.docx` 를 `docx` 로 짓는다.
둘 다 node 도구이고 **작업 폴더 맨 위 `node_modules`** 에 있어야 산출물 스크립트가 찾는다.
컴퓨터 전체에 깐 것(전역 설치)은 `outputs/` 안 스크립트가 찾지 못한다 (실측 2026-10-15).
공식 스킬에 「미리 깔려 있다」고 적힌 것은 클로드 웹 환경 이야기다. 사용자 컴퓨터에는 대개 없다.

| 확인하는 것 | 어떻게 · 파일을 열어 본다 | 열리면 |
|---|---|---|
| `pptxgenjs` | 작업 폴더의 `node_modules/pptxgenjs/package.json` | 「있음 (v`version`)」 |
| `docx` | 작업 폴더의 `node_modules/docx/package.json` | 같음 |

⛔ `node -v`·`npm ls` 로 확인하지 않는다. AI 마케터가 켜진 대화에서는 실행 보호 훅이 막는다.
파일이 안 열리면 「없음」이다. 터미널이 있으면 `ls node_modules/pptxgenjs` 도 돈다.
⛔ **우리가 설치하지 않는다.** `npm install` 은 훅이 막는다. 사용자 컴퓨터에 까는 일은 사용자가 한다.

없으면 아래를 **그대로** 낸다. `{작업 폴더}` 만 지금 작업 폴더 경로로 바꾼다.
이 문구가 정본이다. `084` 와 `docs/공통규약.md §H` 가 여기를 가리킨다.

```
발표자료(.pptx)와 워드 문서(.docx)를 파일로 받으려면 도구 두 개를 작업 폴더에 한 번 깔아 주세요.
공식 문서 스킬이 이 두 도구로 파일을 만듭니다.

  1. 터미널을 엽니다
       클로드 코드: 지금 대화하는 창 말고 터미널 창을 하나 더 엽니다
       데스크톱 앱: 맥은 「터미널」 앱, 윈도우는 「PowerShell」을 엽니다
  2. 작업 폴더로 갑니다
       cd "{작업 폴더}"
  3. 아래 한 줄을 붙여 넣고 엔터를 누릅니다
       npm install pptxgenjs docx

「npm 을 찾을 수 없다」고 나오면 node 가 없는 것입니다.
nodejs.org 에서 LTS 버전을 받아 깔고 3번을 다시 하세요.

깔지 않아도 다른 업무는 그대로 됩니다. 발표자료와 문서는 .md 개요로 나갑니다.
```

⛔ **①의 7개 항목에 넣지 않는다.** 브라우저 도구와 같다. 플러그인 밖에서 붙는다.

**안 붙어도 멈추지 않는다.** 사용자가 승인을 안 했거나 `node` 가 없으면 안 붙는다.
그때 **구축을 멈추지 않는다.** 위 넷을 부를 때 「브라우저 도구가 없어 손으로 주셔야 한다」고 그 자리에서 말한다.

🔴 **로그인이 필요한 페이지는 읽지 않는다.** `--isolated` 로 띄워 사용자의 로그인 상태를 쓰지 않는다.
광고 관리자·스토어 관리자처럼 로그인 뒤에 있는 값은 **사용자가 내려받아 준다.**
