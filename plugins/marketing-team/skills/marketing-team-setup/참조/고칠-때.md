# 고칠 때 · 업데이트와 초기화

> `SKILL.md` ①에서 떼어 냈다 (2026-11-13 · 본문 500줄 기준). 글은 그대로 옮겼다.
> **「업데이트가 안 돼」·「처음부터 다시 하고 싶어」·「옛날 버전이 그대로야」가 나왔을 때** 이 파일을 통째로 읽고 나서 그 단계를 한다. 기억으로 하지 않는다.

### 「업데이트가 안 돼요」면 · 세 층을 나눈다

```
① 마켓플레이스   저장소에서 받아 온 목록      계정에 저장
      ↓
② 플러그인       그 목록에서 설치한 것        계정에 저장
      ↓
③ 대화          열 때 설치된 것을 읽는다      대화마다
```

| 결론 | 어떻게 |
|---|---|
| **③** | **이 스킬이 돌고 있으면 정상.** 더 볼 것 없다 |
| **②** | `plugin.json` 의 `version` 을 읽는다 |
| **①** | 같은 파일의 `repository` 에서 raw 주소를 만들어 저장소 최신과 비교. 못 읽으면 **결정하지 않는다** |

| 결과 | 사용자에게 |
|---|---|
| 같다 | 「최신입니다 (vX.Y.Z)」 |
| 설치본이 낮다 | 「저장소는 vA, 설치본은 vB. **마켓플레이스를 먼저 동기화**한 뒤 플러그인을 업데이트하세요」 |
| 못 읽음 | 「설치본은 vB. 최신인지는 확인하지 못했습니다」 |

⚠️ **「업데이트하세요」만 말하지 않는다.** 사용자는 플러그인 버튼부터 누르고,
그 버튼은 낡은 목록과 비교하므로 「새것 없음」으로 표시된다. **거기서 대부분 막힌다.**

| 증상 | 층 | 대처 |
|---|---|---|
| 담당이 하나도 안 보인다 | 플러그인 로드 실패 | ①의 7번부터 |
| 설치했지만 `/` 목록에 없다 | ③ | **새 대화**를 연다 |
| 되다가 안 되다가 한다 | ③ | 같음 |
| 「더 이상 마켓플레이스에 없습니다」 | ①–② 끊김 | 플러그인 제거 → **앱 재시작** → 마켓플레이스 동기화 → 재설치 → 새 대화 |
| 폴더로 열었지만 안 보인다 | `.claude/` 연결이 텍스트 파일로 풀림 (윈도우) | 그 파일을 지우고 `agents`·`skills` 를 `.claude/` 안으로 복사 |

**⛔ 마켓플레이스를 먼저 지우지 않는다.** 플러그인이 출처를 잃고 고아가 된다. 지울 때는 아래층부터.

### 「처음부터 다시 하고 싶어요」 · 완전 초기화

「지웠다 다시 깔았는데 옛날 것이 그대로다」는 **캐시가 남아서**다.
플러그인을 제거해도 **버전별 사본과 설치 기록이 남는다** (실측 2026-08-26 · 3.4MB · 466개 파일).
그래서 재설치해도 같은 버전을 다시 집는다.

**⚠️ 먼저 나눈다. 무엇을 리셋하려는 것인가.**

| 하고 싶은 것 | 해야 할 일 |
|---|---|
| **내 데이터만 새로** (처음 쓰는 것처럼) | **새 폴더를 하나 잡고 「구축하자」.** 그것뿐이다 |
| **최신 버전 받기** | 마켓플레이스 동기화 → 플러그인 업데이트 |
| **찌꺼기까지 전부** | 아래 순서 |

⛔ **대부분은 첫 줄이면 된다.** 플러그인은 읽기 전용이라 내 데이터를 갖고 있지 않다.
지웠다 깔아도 달라지는 것이 없다. **기억은 작업 폴더에 있다.**

**그래도 전부 밀어야 하면 · 순서를 지킨다**

```
① 플러그인 제거
② 마켓플레이스 제거          ← 여기를 건너뛰면 낡은 목록이 남아 옛 버전을 다시 집는다
③ 앱 재시작
④ 캐시·설치 기록 삭제 (아래)
⑤ 마켓플레이스 다시 추가 → 플러그인 설치
⑥ 새 대화
```

④는 **터미널이 있어야 한다.** 데스크톱 앱에는 없으므로 ①②③⑤⑥만 하고,
그래도 옛 버전이면 클로드 코드에서 ④를 하거나 지원에 문의한다.

```
~/.claude/plugins/cache/marketing-team/           버전별 사본 (제일 큰 찌꺼기)
~/.claude/plugins/data/marketing-team-*/          플러그인 데이터
~/.claude/plugins/installed_plugins.json          "marketing-team@marketing-team" 항목
~/.claude/plugins/known_marketplaces.json         "marketing-team" 항목
```

⛔ **뒤 두 JSON 은 다른 플러그인 기록도 함께 들어 있다. 파일째 지우지 않는다.**
해당 항목만 뺀다. 지우기 전에 **두 파일을 복사해 둔다.**

⚠️ **작업 폴더는 이 절차로 지워지지 않는다.** `brand` · `outputs` · `logs` 는 그대로 남는다.
**그것이 맞다.** 제품을 밀어도 내 데이터는 남아야 한다.
작업 데이터까지 버리려면 그 폴더를 직접 지우거나, **새 폴더에서 시작한다** (이쪽을 권한다).
