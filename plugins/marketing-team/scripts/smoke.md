# 발화 점검 · smoke

> **정적 검사로 원리적으로 못 잡는 것이 있다.** `verify.mjs` 는 「파일 안에 그 문자열이 있나」를
> 볼 뿐이다. 스킬이 **실제로 열리는가**, 화면에 **그 문장이 나오는가**는 사람이 밟아야 안다.
>
> 실제로 두 번 당했다 —
> **① 디렉터 스킬이 발화 자체를 안 했다** (description 을 명령형으로 바꿔 해결).
> 문서는 완벽했고 verify 는 🔴 0 이었다.
> **② 서브에이전트가 있는데 「제한돼 있다」고 짐작하고 안 불렀다.**
>
> 릴리스마다 아래를 밟고, 결과를 `logs/smoke-{버전}.md` 로 남긴다.

## 어디서 밟나 · 두 판이다

| 판 | 어디서 | 왜 |
|---|---|---|
| ① 개발 확인 | 저장소 폴더 (`.claude/` 심링크 경유) | 빠른 반복 |
| ② **배포 확인** | **로컬 마켓플레이스로 설치한 빈 폴더** | ①은 **거짓 통과**가 난다 |

> ⚠️ **①에서 통과 판정을 내지 않는다.** 심링크로 새 스킬이 즉시 뜨는데 설치본은 옛 이름일 수 있다.
> 둘 다 켜져 있으면 같은 스킬이 두 벌 등록돼 어느 쪽이 열렸는지 알 수 없다.
> **②를 밟기 전에는 태그를 찍지 않는다.**

---

## 1. 입구 · 서로 가로채지 않는가

세 트리거가 전부 「마케팅팀 ~」으로 시작하므로 **가로채기 위험이 구조적으로 있다.**
셋을 **각각** 새 대화에서 친다.

| 입력 문장 | 열려야 하는 스킬 | 화면에 반드시 있어야 하는 것 |
|---|---|---|
| `마케팅팀 업무 시작하자` | `마케팅-CMO` | ⏸ · 「어떤 일부터」 |
| `1-시작하기` 를 누른다 | `1-시작하기` | 작업 폴더 생성 안내 · CMO 가 가로채지 않는다 |
| `뭐 시킬 수 있어` | `스킬-100-보기` | 카테고리 10줄 |

## 2. 다섯 게이트 · 실제로 밟는가

입력 — `상세페이지 써줘`

| 확인 | 통과 기준 |
|---|---|
| G1 | 되짚기 한 번 · **필요한 데이터를 먼저** 말한다 · ⏸ |
| G2 | 계획 한 화면 · **말린다/더 싼 길/리스크** 중 해당하는 것 · ⏸ |
| G3 | 실행 · **CCO(규제) 판정 블록**이 나온다 |
| G4 | 무엇이 나왔나 / 알게 됐나 / **부족한가** 셋 다 |
| G5 | 다음 제안 · **가장 큰 하나** · ⏸ |

## 3. 완주 조건 · 파일이 실제로 남는가

| 확인 | 통과 기준 |
|---|---|
| 파일 착지 | `outputs/{날짜}/{번호}-{슬러그}/` 에 실물이 있다 |
| 규제 게이트 | 같은 폴더에 `gate.md` 가 있다 |
| 원장 1행 | `logs/build-log.md` 에 행이 늘었다 |

⚠️ 화면에만 뜨고 파일이 없으면 **실패다.** 「저장하지 못했습니다」라고 적혀 있어도 실패다.

## 4. 담당 둘 · 짐작하지 않고 실제로 부르는가

| 확인 | 통과 기준 |
|---|---|
| CCO(규제) | 발행물에서 **호출된다.** 「CCO 미호출」·「제한돼 있습니다」가 나오면 **실패** |
| CSO(검수) | 「이 예산안 검토해줘」에 CEO·CFO·고객·CLO·CBO 중 지정한 관점으로 판정이 온다 |

> 폴백은 허용하되 **⚠️ 로만 착지한다.** 서브에이전트를 못 불렀는데 ✅ 가 나오면 실패다.

## 5. 직함 · 화면에 옛 이름이 없는가

| 확인 | 통과 기준 |
|---|---|
| 표기 | 화면에 **디렉터 · 감사관 · 검수관**이 한 번도 안 나온다 |
| 병기 | **`CCO(규제)` · `CSO(검수)`** 로 괄호가 붙어 있다 |

## 6. 샘플 · 브랜드 정보 없이도 완주하는가

`brand/` 가 빈 폴더에서 `리뷰 분석해줘`.

| 확인 | 통과 기준 |
|---|---|
| 완주 | 멈추지 않고 끝까지 간다 |
| 태그 | `[샘플]` 이 붙는다 |
| 안내 | 끝에 「우리 회사 걸로 바꾸려면 `1-시작하기`」 한 줄 |
