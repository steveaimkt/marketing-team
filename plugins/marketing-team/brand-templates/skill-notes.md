# 우리 보완 · skill-notes

> **스킬 원본은 읽기 전용이다** (`100-skills/…`). 업데이트하면 갈린다.
> 우리 회사에 맞춘 것은 여기 `brand/skill-notes/{번호}.md` 에 둔다 — 업데이트에도 남는다.
> 정본 규칙은 `docs/공통규약.md §0`.

## 어떻게 쓰나

```
brand/skill-notes/051.md      051 상세페이지 기획의 우리 구조
brand/skill-notes/043.md      043 메타 광고 카피의 우리 규칙
```

스킬이 돌 때 **원본 → 도메인 금기 → 우리 보완** 순으로 겹쳐 읽는다.
충돌하면 보완이 이긴다. **단 게이트·안전 규칙은 약화시킬 수 없다 — 강화만 된다.**

## ⛔ 바뀐 것만 적는다

24섹션을 통째로 복사하지 않는다. **표준이 개정되면 우리 것도 함께 따라가야 하기 때문이다.**
통째로 베껴 두면 원본이 좋아져도 우리만 옛것에 묶인다.

## 예 · `brand/skill-notes/051.md`

```
# 051 우리 구조
제외   03 브랜드 의미 · 17 경쟁사 비교
추가   25 사용 후기 영상   (20 고객 후기 뒤)
순서   20 고객 후기 → 06 페인포인트 앞으로
정한 날 2026-08-25
```

## 언제 생기나

**사용자가 「바꿔줘」 하고 「계속 이렇게」를 고를 때만** 생긴다 (⏸).
AI 마케터가 알아서 만들지 않는다 — 우리 회사의 기본값을 바꾸는 것은 사람이 정할 일이다.
