# 내 마케팅 에이전트

> **상태: 미작성** — `2-브랜드-등록하기` 로 브랜드 정보를 채우면 **그 흐름에서 자동으로 조립된다.**
> 따로 부르지 않아도 된다. 다시 조립할 때만 `3-내-에이전트-만들기` 를 부른다.

## 채워질 내용

| 층 | 뜻 |
|---|---|
| **상시** | 매주·매월 반복하는 스킬. 이게 내 에이전트의 얼굴이다 |
| **필요할 때** | 사건이 생기면 부르는 스킬 |
| **한 번** | 셋업용. 한 번 하고 끝 |
| **내 체인** | 상시 스킬을 우리 업무 순서로 엮은 것 · 부를 말이 붙는다 |
| **내 기본값** | 업종 규제 · 손익분기 ROAS · 톤 · 기본 채널 |
| **대기** | 지금 안 쓰는 스킬. **지운 것이 아니다** |

> **100개를 다 쓰는 사람은 없다.** 걷어내면 대개 15~30개가 남는다.
