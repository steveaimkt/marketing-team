# WMBB 브랜드 결 · 말과 그림

> 저자가 2026-09-04 에 명세 전문을 넘겨 주었다. 원본은 **「브랜드 톤앤매너.fig」** 다.
> `tokens.css` 가 **값**이라면 이 문서는 **어떻게 쓰는가**다.
> 🔴 여기 없는 값은 만들지 않는다.

## 한마디로

조용하고, 종이처럼 따뜻하고, **활자가 이끈다.** SaaS 제품 화면이 아니라
공들여 짠 잡지나 진(zine)에 가깝다. 오프화이트 바탕에 따뜻한 먹빛 글자,
빽빽한 활자 위계, 넉넉한 여백, 큰 둥근 이미지 블록, 그리고 아주 가끔 한 번의 강한 색.

## 말

| 무엇 | 어떻게 |
|---|---|
| 인칭 | **1인칭 · 따뜻하게.** 회사말을 쓰지 않는다 |
| 부름 | 읽는 사람에게 바로 말한다 — 「같이 이야기해 볼까요?」 |
| 맺음 | 개인적으로 닫는다. 이름 · 자리 · 이모지 하나 |
| 대소문자 | **문장 형태로.** 제목·버튼·메뉴 전부. 전부 대문자로 쓰지 않는다 |
| 절 제목 | 짧은 명사구 한두 낱말 — 「선택한 작업」 |
| 이끄는 줄 | **한 문장.** 두 줄 높이, 쉬운 말로 |
| 긴 글 | **문단으로 쓴다.** 글머리표로 잘게 쪼개지 않는다 |
| 버튼 | 동사 두세 낱말 — 「통화 예약하기」 · 「미리 보기 →」 |

### 안 쓰는 것

전부 대문자 눈썹글 · 마케팅 상투구(「팀을 강화하는…」) · 줄표 남발 ·
숫자 자랑 늘어놓기 · 대표 어록.

### 이모지

**한 자리에 하나.** 문장부호처럼 쓰지 장식으로 쓰지 않는다.
줄줄이 늘어놓지 않고, 글머리표로 쓰지 않는다.
화살표 `→` `↗` 는 링크 표시로 **뒤에** 붙이고 앞에 한 칸 띄운다.

## 그림

### 색

| 자리 | 값 | 규칙 |
|---|---|---|
| 바탕 | `#F3F3F2` Paper | 페이지 전체 |
| 올라온 면 | `#FFFFFF` | 카드·네비 등 **떠 있는 면에만** |
| 글자·역상 면 | `#2A2A28` Ink | 순검정이 아니라 따뜻하다 |
| 회색 사다리 | `#444444` → `#4C4D59` → `#848383` → `#AFAFAC` | |
| 강조 | `#E0CCBE` Sand · `#747264` Olive | **아껴 쓴다** |
| 하이라이트 | `#EBFF2C` | 한 쪽에 한 번 |
| 스펙 페이지 | `#E6E9FF` · `#C4C9E5` 라벤더 | **문서용** · 고객 화면에 안 쓴다 |

🔴 **강조는 한 쪽에 한 번.** 그라데이션 바탕 · 무늬 · 텍스처 · 삽화를 쓰지 않는다.

### 서체

```
Pretendard         일꾼. 라틴과 한글을 한 벌로 덮는다. 14px 버튼부터 73px 표제까지
Manrope            라틴 전용 대체. 둘 다 있으면 Pretendard 가 앞선다
Bricolage Grotesque  50~55px 편집형 표제에만 · 아주 가끔
Roboto 14px        푸터 저작권 한 줄 · 이 시스템에서 Roboto 가 서는 유일한 자리
```

글줄 · 제목 100% · 표제 1.1 · 본문 1.6 · 이끄는 줄 1.4.
자간 · 거의 0. 표제만 `-0.01em` 로 조인다.

### 자리

```
본문 폭 1200px · 양옆 100px
절 위 60~100px · 절 아래 100~150px · 제목과 내용 사이 40~50px
카드 격자 20px · 낱칸 14px
```

**히어로 카드 아래 모서리 60px 쓸기**(`0 0 60px 60px`)가 이 브랜드의 서명이다.

### 모서리

| 값 | 자리 |
|--:|---|
| 5px | 버튼 · 작은 칩 |
| 10px | 본문 속 이미지 블록 |
| 13px | 카드 · 이미지 판 |
| 20px | 아이콘 블록 (드물다) |
| 30px | 큰 면 · CTA 패널 |
| 60px | 히어로 아래 쓸기 (위는 각지게) |
| 50% | 원형 아바타 · 소셜 버튼 |

### 선과 그림자

헤어라인 `#EBEBEB` **1px 만.** 역상 면의 구분선은 `#444444`.
그림자는 아껴 쓴다 — 카드는 **뜨지 않고 앉는다.**
`rgba(0,0,0,.04)` · `.15` · `.26` · 이미지 덮개는 `.61`.

### 유리

**딱 두 면뿐이다.** 더 늘리지 않는다.

```
네비    rgba(255,255,255,.7)          + blur(50px)
카드    .7 → .35 세로 그라데이션        + blur(80px) + 1px 흰 테두리
```

### 움직임

**은은하게.** 페이드와 색 변화뿐이다. 튀지 않고, 스프링도 없고, 스크롤을 가로채지 않는다.

```
hover   링크 opacity .7 · 외곽선 버튼은 옅은 회색 채움
press   translateY(1px) · 색이 번쩍이지 않는다
focus   먹빛 2px 고리 · offset 2px
전이     200ms ease-out
```

## 아이콘

원본이 주는 것은 **소셜 넷뿐**이다 — LinkedIn · Behance · Dribbble · X.
16×16 단색 채움 글리프가 42×42 원형 바탕에 앉는다.

- 아이콘 폰트 · 스프라이트 · PNG 를 쓰지 않는다
- **있는 SVG 를 먼저 쓴다.** 없는 글리프가 필요하면 Lucide 16~20px · 굵기 1.5~2 ·
  `currentColor` 로 대신하고, **쓴 자리에 대체했다고 적는다**

## 로고

**글자가 곧 로고다.** 별도 심벌이 없다.
네비에서는 16px 보통, 역상 푸터에서는 16px 굵게.
심벌을 새로 만들면 같은 크기·굵기 자리에 앉힌다.
