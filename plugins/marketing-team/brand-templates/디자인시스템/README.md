# 산출물 디자인 시스템

책에 실리는 결과물과 제품이 내는 결과물이 **한 벌로 보이게** 하려고 만들었다.

```
tokens.css   색 · 서체 · 크기 · 여백    ← 갈아 끼우는 자리는 여기 하나다
산출물.css   컴포넌트 (표 · 카드 · 차트 · 상자)
브랜드결.md   말과 그림을 어떻게 쓰는가 · WMBB 명세 전문
슬라이드.md   .pptx · .docx · .xlsx 규격 ← 🔴 원본에 없어 파생으로 세웠다
```

## 어디에 쓰이나

| 어디 | 무엇 |
|---|---|
| 산출물 `.html` 20개 | 두 파일을 `<style>` 안에 그대로 박아 넣는다 |
| 도판 미리보기 SVG | 같은 색값을 쓴다 (`tokens.css` 의 `:root` 값만) |
| `.xlsx` · `.docx` · `.pptx` | 같은 색값과 Pretendard |
| 제품 플러그인 | `brand-templates/디자인시스템/` 에 같은 사본 |

## 왜 인라인인가

독자가 파일 하나만 받아 두 번 클릭하면 열려야 한다.
CSS 를 따로 두면 그 파일이 빠진 채 전달되는 순간 화면이 무너진다.

## 색을 바꾸려면

`tokens.css` 의 `:root` 블록만 고친다. 컴포넌트는 토큰만 부르므로
그 파일 하나로 밝은 화면과 어두운 화면이 함께 바뀐다.

지금 색은 **책 도판 팔레트**를 그대로 옮긴 것이다.

```
바탕             #F3F3F2   Paper
글자             #2A2A28   Ink · 따뜻한 먹빛, 순검정이 아니다
강조 면           #E0CCBE   Sand
강조 글자·막대     #747264   Olive
사람이 답할 자리   #EBFF2C   하이라이트 · 한 쪽에 한 번
```

🔴 **2026-09-04 에 고쳤다.** 그전까지 이 자리에 `#D97757`(주황)·`#E8CDBE`(베이지)가
「AI 마케터」·「검토자」 색으로 적혀 있었다. **둘 다 WMBB 명세에도 `tokens.css` 에도 없다.**
책 도판의 캐릭터 색과 산출물 팔레트를 섞어 적은 것으로 보인다.
`084-proposal-generator.pptx` 가 아직 `D97757` 을 쓰는데 그 파일은 손대지 않았다.

⚠️ 어두운 화면 값은 `@media (prefers-color-scheme: dark)` 와
`:root[data-theme="dark"]` **두 곳에 함께** 적혀 있다. 한쪽만 고치면 어긋난다.

## 서체

Pretendard 가 깔려 있으면 그것을 쓰고, 없으면 시스템 한글 서체로 내려간다.
산출물 파일은 인터넷 없이 열려야 해서 웹폰트를 불러오지 않는다.
