# 원장 운영 · 스키마 · 롤오버 · 진단

> `docs/공통규약.md §H` 에서 갈라져 나왔다. **매 업무에 필요한 것은 「원장에 1행 적는다」뿐**이고,
> 아래는 **점검할 때만** 쓴다 — `마케팅팀-구축하기` 주기 점검과 `scripts/ledger-stats.mjs`.
>
> ⛔ **원장을 손대기 전에 해당 절을 통째로 읽는다. 기억으로 하지 않는다.**
> 열 순서 하나가 틀리면 저장 누락 점검과 90일 호출 분석이 함께 깨진다.

| 언제 | 무엇을 읽나 |
|---|---|
| 원장에 행을 쓰거나 열을 확인할 때 | §1 스키마 |
| 800행을 넘었거나 연도가 바뀌었을 때 | §2 롤오버 |
| 「점검해줘」 · 훅이 신호를 냈을 때 | §3 진단 신호 |

---

## 1. 원장 스키마 · 열 순서를 바꾸지 않는다

정본 템플릿 — `brand-templates/build-log.md`.
`마케팅팀-구축하기` 가 `logs/build-log.md` 가 없을 때 복사한다. **있으면 덮어쓰지 않는다.**

```
| 일시 | 스킬 ID | 요청 | 데이터 모드 | 산출물 경로 | 게이트 | 보완 횟수 | 상태 |
```

| 열 | 허용값 |
|---|---|
| 데이터 모드 | `실데이터` · `샘플` · `추정` · `혼합` |
| 게이트 | `해당없음` · `✅` · `⚠️` · `⛔` · `AI 규제검토자 미호출` |
| 상태 | `완료` · `차단됨` · `저장실패` · `중단` |

- 일시 `YYYY-MM-DD HH:MM` · 스킬 ID `이름(번호)` · 보완 횟수는 숫자
- 값에 `|` 가 들어가면 `\|` 로 이스케이프한다
- ⛔ **열 순서를 바꾸지 않는다.** 저장 누락 점검과 90일 호출 분석이 이 스키마를 읽는다
- ⛔ 차단도 `(차단됨)`만 쓰지 않고 `run.json (차단됨)`으로 적는다. 반복 실행은 `run-2.json`처럼 실제 순번을 쓴다

세 가지가 각각 한 행으로 남는다.

```
| 2026-08-22 14:10 | 광고 주간 리포트(045) | 이번 달 광고 어땠어 | 샘플 | outputs/2026-08-22/045-weekly-ads-report/045-weekly-ads-report.md | 해당없음 | 0 | 완료 |
| 2026-08-22 14:32 | 메타 광고 카피(043) | 카피 만들어줘 | 샘플 | outputs/2026-08-22/043-meta-ad-copy/run.json (차단됨) | ⛔ | 2 | 차단됨 |
| 2026-08-22 15:01 | 상세페이지 카피(051) | 상세페이지 써줘 | 샘플 | (저장 실패 — 쓰기 승인 없음) | ⚠️ | 0 | 저장실패 |
```

## 2. 원장 롤오버 · 옮기고 지우지 않는다

원장은 지우지 않고 쌓는다. 그래서 **언젠가 반드시 커진다.** 하루 3건이면 연 780행,
하루 10건이면 연 2,600행이다. 디스크는 문제가 아니고, **매 작업 앞에서 읽는 비용**이 문제다.

```
logs/build-log.md                    현재 연도만
logs/build-log-summary.md            스킬별 최초일 · 최종일 · 누적 건수
logs/archive/build-log-{연도}.md      지난 연도 — 옮긴 것이지 지운 것이 아니다
```

| 언제 | 무엇을 |
|---|---|
| 데이터 행 **800행 초과** 또는 **연도가 바뀜** | 롤오버를 ⏸ 로 **제안**한다 |
| 승인받으면 | 헤더를 남기고 **데이터 행만** `logs/archive/build-log-{연도}.md` 로 옮긴다 |
| 옮긴 뒤 | `scripts/ledger-stats.mjs --summary` 로 요약 원장을 갱신한다 |

- ⛔ **세는 것은 기계다.** `scripts/ledger-stats.mjs` 가 부피·집계·진단을 한 번에 낸다.
  사람이 눈으로 세면 안 센다 — **임계는 스크립트가 정본이고, 이 문서의 숫자는 `verify.mjs` 가 대조한다.**
- **부르는 주체는 `마케팅팀-구축하기` 주기 점검이다.** 원장을 세는 유일한 자리다.
- ⛔ **묻지 않고 옮기지 않는다.** 원장 이동은 사용자 승인이 필요한 상태 변경이다.
- ⛔ **행을 지우지 않는다.** 아카이브는 `outputs/…/archive/` 와 같은 규칙이다 — 옮길 뿐이다.
- 아카이브 파일도 **스키마가 같다.** 열 순서가 같아야 나중에 합쳐 읽을 수 있다.

**요약 원장이 있는 이유** — 90일 무호출 점검은 스킬별 마지막 실행일 하나만 있으면 된다.
그것 때문에 아카이브 전체를 여는 것은 낭비다. 정본 템플릿 — `brand-templates/build-log-summary.md`.

⛔ **요약은 롤오버를 기다리지 않는다. 세션 훅이 주마다 다시 만든다.**
예전엔 롤오버(800행)만 만들었다 — 하루 3건이면 **수년 뒤**다. 그동안 §A 는
「스킬별 마지막 실행일은 요약을 읽어라」고 말하는데 **그 파일이 없었다.**
없으면 원장을 통째로 읽게 되고, 그게 §A 가 막으려던 바로 그 일이다.
**「읽으라」고 적은 파일은 쓰기 시작하면 바로 있어야 한다.**
정확히는 **첫 작업이 원장에 한 행 남은 뒤 첫 훅**에서 생긴다 — 0행이면 요약할 것이 없으니
그때는 안 만든다. 「수년 뒤」와 「첫 작업 뒤」는 다르다.

```
| 스킬 ID | 최초 실행 | 최종 실행 | 누적 건수 |
|---|---|---|---:|
| 광고 주간 리포트(045) | 2026-03-04 | 2026-08-22 | 24 |
```

- 누적 건수는 **`상태 = 완료` 행만** 센다. `차단됨` · `저장실패` · `중단` 은 넣지 않는다
  (원장 머리말의 누적 카운터 규칙과 같다).
- 요약은 **파생물이다.** 원장·아카이브와 어긋나면 원장이 맞다. 언제든 다시 만들 수 있다.

## 3. 원장이 시스템을 고친다 · 쓸수록 나아지는 자리

**쌓기만 하면 무거워지기만 한다.** 원장에는 이미 고칠 자리가 적혀 있다 —
`scripts/ledger-stats.mjs` 가 열을 신호로 바꾼다. 주기 점검에서 이것부터 본다.

| 열 | 신호 | 무엇이 잘못됐다는 뜻인가 |
|---|---|---|
| `스킬 ID` + 최종일 | 🔕 90일 무호출 | 상시 편성이 실제 업무와 어긋났다 |
| `보완 횟수` | 🔁 평균 2회 이상 | **그 스킬이 한 번에 안 나온다** — `inputs`·브리핑이 부실하다 |
| `게이트` + `상태` | ⛔ 차단률 30% 이상 | 그 스킬 프롬프트가 규제를 계속 건드린다 |
| `데이터 모드` | 📄 샘플률 80% 이상 | 실데이터가 안 붙어 있다 — 프로필·MCP 가 비었다 |
| `상태` | 💾 저장실패 | 착지 규칙이 안 지켜지는 자리 |
| `요청` | 🗣 같은 말이 다른 스킬로 | **부를 말이 겹친다** — 트리거를 갈라야 한다.<br>⛔ **체인은 오탐이라 뺀다** — `ROUTING.md` 의 체인 순서와 대조한다 |
| `산출물 경로` ↔ 실물 | 📁 착지실패 | **원장엔 있는데 파일이 없다** — 화면에만 뜨고 끝난 것 |
| `게이트` ↔ `gate.md` | 🚪 게이트기록 | 게이트는 탔는데 **근거가 안 남았다** |
| `산출물 경로` ↔ `writes_to` | 📊 형식위반 | **스킬이 정한 형식과 다르게 냈다** — 다음 스킬이 경로를 못 찾는다 |

**위 아홉은 전부 「이상」이다.** 잘 쓰는 사람에겐 평생 안 뜬다 — 그것만 있으면
**시스템이 먼저 말을 걸 일이 없다.** 아래 셋은 이상이 아니라 **때가 된 것**이다.

| 무엇으로 재나 | 재방문 신호 | 무슨 뜻인가 |
|---|---|---|
| 완료 행 간격의 **중앙값** | ⏰ 주기도래 | 평소 간격의 **1.5배**를 넘겼다 |
| `상태` 중단·차단 ↔ 이후 완료 | 📌 미완 | 막힌 채 남았고 **그 뒤 완료된 적이 없다** |
| 완료 건수 ↔ `my-playbook` | 📎 플레이북 | 5건 넘게 했는데 **빈 템플릿 그대로**다 |

⛔ **주기를 선언하지 않는다. 원장에서 잰다.** 「주간 스킬」 같은 필드를 붙이면
안 쓰는 사람에게도 뜬다. **실제로 반복한 것만** 주기가 있다.

**부르지 않아도 본다.** `hooks/hooks.json` 의 SessionStart 훅이 세션이 열릴 때 조용히 재고,
**말할 것이 있을 때만** 한 화면으로 알린다. 사람이 「점검해줘」를 잊어도 신호가 묻히지 않는다.

⛔ **둘을 섞지 않는다.** **이상**은 물을 때만 답하고, **재방문**은 **먼저 꺼낸다.**
전부 「먼저 꺼내지 말 것」으로 두면 재방문은 영영 안 일어난다 (실측 · 실효 0).
다만 꺼내되 **가로채지 않는다** — 사용자가 말한 일을 먼저 하고 끝에 한 줄로 붙이며,
**멋대로 실행하지 않고** 「돌릴까요?」로 묻는다.

| | |
|---|---|
| 어디서 도나 | `logs/build-log.md` 가 있는 폴더에서만 — 마케팅 작업 공간이 아니면 아무 일도 없다 |
| 얼마나 자주 | **7일에 한 번.** `logs/.ledger-check` 에 본 날짜를 남긴다 |
| 흔적 | `logs/.ledger-check` 한 줄뿐. 작업 폴더를 git 으로 관리하면 `.gitignore` 에 넣는다 |
| 언제 말하나 | 롤오버가 필요하거나 진단 신호가 있을 때. **이상 없으면 조용하다** |
| 무엇을 하나 | **원장은 읽기만 한다.** 옮기지도 고치지도 않는다 — 처방은 사람이 승인한다 |
| 무엇을 쓰나 | `.ledger-check` 와 `build-log-summary.md` 둘뿐. **둘 다 파생물**이라 지워도 다시 생긴다 |

- 훅이 말한 뒤 「점검해줘」로 들어가면 전체 진단과 처방까지 간다.
- ⛔ **완주 조건 셋(파일 착지 · 규제 게이트 · 원장 1행)은 이제 기계가 뒤늦게 잰다.**
  원장 1행은 행이 있다는 것 자체가 증거고, 나머지 둘은 **원장과 실물을 대조**한다 (최근 8주).
  ⛔ 문서에서 33번 강조해도 재지 않으면 안 지켜진다 — 그래서 재는 자리를 만들었다.
- ⛔ **원장은 보관용이 아니라 진단 데이터다.** 적기만 하고 안 읽으면 적는 비용만 남는다.
- 🗣 라우팅 신호는 `100-skills/ROUTING.md` 를 고칠 근거가 된다 — **실제 사용자가 뭐라고 부르는지**는 원장에만 있다.
- 고칠 지점은 **한 번에 3개 이내**로 돌려준다. 열 개를 적으면 하나도 안 고쳐진다.
| `market_analysis_report.md` | 파일 이름은 `writes_to` 가 정한다. **지어내지 않는다** |
| 날짜 폴더 없이 바로 저장 | 다음 주에 무엇이 언제 것인지 알 수 없다 |
