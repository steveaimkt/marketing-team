# 데이터 가져오기 · 어디서 어떻게 내보내나

> **이 문서가 왜 있나** · 100개 중 **64개**가 외부 데이터를 쓴다 (폴백 보유 48 + 폴백 없이 필요 16).
> 「CSV 주세요」로 끝내면 사용자가 움직이지 못한다. 규약 §G 는 **「어디서 구하는지까지 말한다」**
> 인데, 그 정보가 어디에도 없어서 AI 마케터가 매번 지어냈다. **여기가 정본이다.**
>
> G1 에서 데이터를 요청할 때 이 표의 **「어디서」 열을 그대로 인용한다.** 지어내지 않는다.

---

## 0. 크롤링은 기본이 아니다 · 붙여넣기가 기본이다

⛔ **URL 을 받았다고 크롤링부터 시도하지 않는다.**

```
스마트스토어 · 쿠팡 · 인스타그램 · 카카오        로그인 뒤에 있다 · 봇 차단 · 대부분 실패
네이버 검색결과 · 경쟁사 자사몰                  되기도 하고 안 되기도 한다
공개 블로그 · 뉴스 · 공식 문서                   대체로 된다
```

**순서는 이렇다.**

| | 무엇을 | 언제 |
|---|---|---|
| **①** | `inputs/` 에 **이미 있는 파일**을 먼저 훑는다 | 항상 먼저 |
| **②** | 없으면 **내보내는 법을 알려 주고** `inputs/` 에 넣게 한다 | 로그인 뒤 데이터 |
| ③ | 공개 페이지면 가져와 본다 | 막히면 즉시 ②로 |
| ④ | 그래도 없으면 **샘플로 완주**하고 `[샘플]` | 멈추지 않는다 |

**③에서 막혔을 때 「크롤링에 실패했습니다」로 끝내지 않는다.** 반드시 ②의 안내를 낸다.

> 스크린샷·복사 붙여넣기도 정상 입력이다. CSV 가 아니어도 받는다.
> 리뷰는 **화면 캡처 여러 장**으로 들어오는 경우가 가장 흔하다.

## 1. 리뷰 · 후기

관련 스킬 — `소비자 리뷰 분석(006)` · `리뷰 관리(054)` · `VoC 취합·분류(078)` ·
`상세페이지 24섹션(051)` 의 06 페인포인트 섹션

| 어디 | 어떻게 내보내나 | 넣을 곳 |
|---|---|---|
| **스마트스토어** | 스마트스토어센터 → 문의/리뷰관리 → **리뷰 관리** → 기간 선택 → **엑셀 다운로드** | `inputs/reviews-smartstore.xlsx` |
| **쿠팡** | 쿠팡 윙 → 상품관리 → **상품평 관리** → 기간 → 다운로드<br>⚠️ 판매자 화면에 다운로드가 없으면 **화면 캡처 여러 장**으로 받는다 | `inputs/reviews-coupang.*` |
| **자사몰(카페24·아임웹 등)** | 관리자 → 게시판/리뷰 → 엑셀 내보내기 | `inputs/reviews-{몰이름}.csv` |
| **네이버 플레이스** | 다운로드 기능 없음 → **캡처** 또는 본문 복사 | `inputs/reviews-place.md` |
| **인스타 댓글** | API 없이는 못 긁는다 → **캡처** 또는 복사 | `inputs/comments-ig.md` |
| **CS 문의** | 채널톡·카카오 상담 → 대화 내보내기 · 메일 검색 결과 복사 | `inputs/cs-{기간}.csv` |

**최소 몇 건이면 되나** — 20건이면 경향이 보이고, **50건 이상이면 판정이 선다.**
그 아래면 산출물에 「표본 {N}건 기준이라 흔들릴 수 있습니다」를 적는다.

**어떤 열이 있으면 좋나** — `별점 · 리뷰 원문 · 작성일 · (옵션명)`.
**없어도 된다.** 원문만 있으면 돈다.

⚠️ **주문자명·전화번호·주소는 마스킹하고 받는다.** 산출물에 남기지 않는다.

## 1-b. 키워드 · 검색량

⚠️ **6개 스킬(001·004·005·042·053)이 이 절을 가리키는데 여기가 비어 있었다** (실측 2026-08-26).
그래서 「데이터-가져오기.md 참조」가 **깨진 참조**였다.

| 무엇 | 어디서 | 어떻게 |
|---|---|---|
| **검색량 · 연관어** | 네이버 검색광고 → 도구 → **키워드 도구** | 키워드 입력 → 조회 → **다운로드**(엑셀) · 광고주 계정 필요(무료 가입) |
| **검색 추이 · 성비/연령** | **네이버 데이터랩** → 검색어트렌드 | 주제어 최대 5개 → 기간·기기·성별·연령 → **다운로드** · 로그인 불필요 |
| **쇼핑 카테고리 인기어** | 네이버 데이터랩 → **쇼핑인사이트** | 분야 선택 → 인기 검색어 20개 · **상대지수라 절대 검색량이 아니다** |
| **구글 검색량** | Google Ads → 도구 → **키워드 플래너** | 광고 집행 이력이 없으면 **범위값(1천~1만)만** 나온다 |
| **자동완성·연관검색어** | 네이버·구글 검색창 | 화면 캡처로 충분하다 · 크롤링하지 않는다 |
| **내 유입 검색어** | 스마트스토어 → 통계 → **마케팅분석 → 검색채널** | 기간 선택 → 다운로드 · 이미 우리에게 들어온 말이라 **가장 값지다** |

⚠️ **데이터랩은 상대지수(0~100)다.** 절대 검색량이 아니므로 **키워드 도구와 섞어 쓰지 않는다.**
둘을 함께 쓸 때는 어느 쪽 수치인지 표에 밝힌다.

⚠️ **광고주 계정이 없으면** 키워드 도구를 못 연다. 그때는 데이터랩(로그인 불필요)으로 **추이만**
보고 `[추정]` 을 붙인다 — 없다고 멈추지 않는다 (`공통규약 §0-c D2`).

## 6-b. 숫자·문서 · 파일이 아니라 사람에게서 온다

**여기 있는 것들은 플랫폼에서 내려받는 게 아니다.** 그래서 「어디서」가 더 중요하다 —
어디를 뒤져야 하는지 모르면 사용자도 못 가져온다.

| 무엇 | 어디서 | 쓰는 스킬 |
|---|---|---|
| **원가 · 공급가 · 수수료율** | 공급사 **거래명세서·견적서** · 자사 원가표(엑셀) · ERP·회계 프로그램 | 014 016 017 057 059 |
| **재고 · 회전율** | 스마트스토어 → 상품관리 → 재고 · 쿠팡 WING → 재고 | 016 057 |
| **플랫폼 수수료** | 각 플랫폼 **판매자 요금 안내** 페이지 (카테고리별로 다르다) | 016 017 057 |
| **회의·상담 녹취** | 클로바노트 · Otter · 줌 자동 전사 → **텍스트 붙여넣기** | 080 086 093 |
| **견적서** | 업체 메일 · PDF → **본문 붙여넣기도 된다** (표로 안 와도 정규화한다) | 096 |
| **RFP · 제안 요청** | 고객 메일 · 나라장터 · 기업마당 공고문 | 084 |
| **지원사업 공고문** | K-스타트업 · 기업마당 · 각 지자체 공고 페이지 (**배점표가 핵심**) | 090 |
| **SNS 계정 인사이트** | 인스타 프로페셔널 대시보드 · 유튜브 스튜디오 → 분석 → **내보내기** | 031 033 039 |

⚠️ **원가는 「대략 얼마」로 받지 않는다.** 마진 계산이 판정을 뒤집는다 —
받을 수 없으면 프로필 §4 마진율로 **잠정 판정**을 내고 「실마진이 들어오면 뒤집힐 수 있다」를 적는다.

⚠️ **녹취는 요약본이 아니라 전사본을 받는다.** 요약에는 이미 사람의 판단이 섞여 있어
「누가 무엇을 약속했는지」가 사라진다.

## 6. G1 에서 이렇게 낸다

```
「이번 달 광고 어땠어」 → 광고 주간 리포트(045)

이 일에 있으면 좋은 자료
  ✅ 있음    브랜드 프로필 (공헌이익률 50% → 손익분기 ROAS 2.0)
  ⬜ 없음    매체별 지출·성과 CSV        ← 있으면 실제 숫자로 판정합니다

             네이버 검색광고  광고시스템 → 보고서 → 맞춤 보고서 → 기간 → 다운로드
             메타            광고 관리자 → 보고서 → 열 선택 → 내보내기 → CSV
             inputs/ 에 넣어 주시면 됩니다

             필요한 열: 노출 · 클릭 · 비용 · 전환수 · 전환매출

없으면 샘플(가상의 A브랜드)로 완주하고 [샘플] 이 붙습니다. 그대로 진행할까요?
```

**「어디서」를 지어내지 않는다.** 이 문서에 없는 경로는 **모른다고 말하고** 사용자에게 묻는다.
플랫폼이 화면을 바꾸면 이 문서를 고친다 — 100개 스킬을 고치지 않는다.
