# 데이터 가져오기 · 어디서 어떻게 내보내나

> **이 문서가 왜 있나** · 100개 중 **32개**가 외부 데이터를 요구한다.
> 「CSV 주세요」로 끝내면 사용자가 움직이지 못한다. 규약 §G 는 **「어디서 구하는지까지 말한다」**
> 인데, 그 정보가 어디에도 없어서 AI 마케터가 매번 지어냈다. **여기가 정본이다.**
>
> G1 에서 데이터를 요청할 때 이 표의 **「어디서」 열을 그대로 인용한다.** 지어내지 않는다.

---

## 0. 크롤링은 기본이 아니다 · 붙여넣기가 기본이다

⛔ **URL 을 받았다고 크롤링부터 시도하지 않는다.**

```
스마트스토어 · 쿠팡 · 인스타그램 · 카카오        로그인 뒤에 있다 · 봇 차단 · 대부분 실패
네이버 검색결과 · 경쟁사 자사몰                  되기도 하고 안 되기도 한다
공개 블로그 · 뉴스 · 공식 문서                   대체로 된다
```

**순서는 이렇다.**

| | 무엇을 | 언제 |
|---|---|---|
| **①** | `inputs/` 에 **이미 있는 파일**을 먼저 훑는다 | 항상 먼저 |
| **②** | 없으면 **내보내는 법을 알려 주고** `inputs/` 에 넣게 한다 | 로그인 뒤 데이터 |
| ③ | 공개 페이지면 가져와 본다 | 막히면 즉시 ②로 |
| ④ | 그래도 없으면 **샘플로 완주**하고 `[샘플]` | 멈추지 않는다 |

**③에서 막혔을 때 「크롤링에 실패했습니다」로 끝내지 않는다.** 반드시 ②의 안내를 낸다.

> 스크린샷·복사 붙여넣기도 정상 입력이다. CSV 가 아니어도 받는다.
> 리뷰는 **화면 캡처 여러 장**으로 들어오는 경우가 가장 흔하다.

## 1. 리뷰 · 후기

관련 스킬 — `소비자 리뷰 마이닝(006)` · `리뷰 관리 시스템(054)` · `VoC 취합·분류(078)` ·
`상세페이지 24섹션(051)` 의 06 페인포인트 섹션

| 어디 | 어떻게 내보내나 | 넣을 곳 |
|---|---|---|
| **스마트스토어** | 스마트스토어센터 → 문의/리뷰관리 → **리뷰 관리** → 기간 선택 → **엑셀 다운로드** | `inputs/reviews-smartstore.xlsx` |
| **쿠팡** | 쿠팡 윙 → 상품관리 → **상품평 관리** → 기간 → 다운로드<br>⚠️ 판매자 화면에 다운로드가 없으면 **화면 캡처 여러 장**으로 받는다 | `inputs/reviews-coupang.*` |
| **자사몰(카페24·아임웹 등)** | 관리자 → 게시판/리뷰 → 엑셀 내보내기 | `inputs/reviews-{몰이름}.csv` |
| **네이버 플레이스** | 다운로드 기능 없음 → **캡처** 또는 본문 복사 | `inputs/reviews-place.md` |
| **인스타 댓글** | API 없이는 못 긁는다 → **캡처** 또는 복사 | `inputs/comments-ig.md` |
| **CS 문의** | 채널톡·카카오 상담 → 대화 내보내기 · 메일 검색 결과 복사 | `inputs/cs-{기간}.csv` |

**최소 몇 건이면 되나** — 20건이면 경향이 보이고, **50건 이상이면 판정이 선다.**
그 아래면 산출물에 「표본 {N}건 기준이라 흔들릴 수 있습니다」를 적는다.

**어떤 열이 있으면 좋나** — `별점 · 리뷰 원문 · 작성일 · (옵션명)`.
**없어도 된다.** 원문만 있으면 돈다.

⚠️ **주문자명·전화번호·주소는 마스킹하고 받는다.** 산출물에 남기지 않는다.

## 2. 광고

관련 스킬 — `광고 주간 리포트(045)` · `ROAS 진단·예산 재배분(046)` · `쿠팡 광고(041)` ·
`네이버 쇼핑검색광고(042)` · `메타 광고(043)` · `구글 광고(044)` · `어트리뷰션 정리(050)`

| 어디 | 어떻게 | 넣을 곳 |
|---|---|---|
| **네이버 검색광고** | 광고시스템 → 보고서 → **맞춤 보고서** → 기간 → 다운로드 | `inputs/ads-naver-{기간}.csv` |
| **메타** | 광고 관리자 → 보고서 → 열 선택 → **내보내기 → CSV** | `inputs/ads-meta-{기간}.csv` |
| **구글** | Google Ads → 캠페인 → 우측 상단 **다운로드 → CSV** | `inputs/ads-google-{기간}.csv` |
| **쿠팡** | 쿠팡 윙 → 광고 관리 → 보고서 → 다운로드 | `inputs/ads-coupang-{기간}.csv` |
| **카카오** | 카카오모먼트 → 보고서 → 다운로드 | `inputs/ads-kakao-{기간}.csv` |

**꼭 있어야 하는 열** — `노출 · 클릭 · 비용 · 전환수 · 전환매출`.
전환매출이 없으면 **ROAS 를 계산하지 않는다.** 「전환매출 미포함이라 ROAS 는 못 냅니다」라고 적는다.

## 3. 매출 · 트래픽

관련 스킬 — `판매 데이터 분석(061)` · `GA4 분석 리포트(063)` · `마케팅 월간 리포트(067)` ·
`코호트 분석(064)` · `KPI 트리(066)`

| 어디 | 어떻게 | 넣을 곳 |
|---|---|---|
| **스마트스토어** | 스토어센터 → 통계 → **판매분석** → 기간 → 엑셀 | `inputs/sales-smartstore-{기간}.xlsx` |
| **쿠팡** | 쿠팡 윙 → 정산 → 매출내역 → 다운로드 | `inputs/sales-coupang-{기간}.csv` |
| **GA4** | 보고서 → 우측 상단 **공유 → 파일 다운로드 → CSV**<br>탐색 보고서면 **탐색 → 내보내기** | `inputs/ga4-{보고서명}.csv` |
| **자사몰** | 관리자 → 주문/매출 통계 → 엑셀 | `inputs/sales-{몰이름}.csv` |

**꼭 있어야 하는 열** — `날짜 · 상품 · 수량 · 매출`. 마진을 보려면 `원가` 도.
원가가 없으면 `brand/profile.md §4` 의 마진율로 추정하고 **`[추정]`** 을 붙인다.

## 4. 고객 · CRM

관련 스킬 — `고객 여정 맵핑(073)` · `이탈 방지 윈백(077)` · `설문·NPS 분석(070)`

| 어디 | 어떻게 | 넣을 곳 |
|---|---|---|
| **주문 이력** | 각 몰 관리자 → 주문 내역 → 기간 전체 엑셀 | `inputs/orders-{기간}.csv` |
| **설문** | 구글폼 → 응답 → **스프레드시트로 보기 → CSV 다운로드** | `inputs/survey-{이름}.csv` |
| **이메일** | 스티비·메일침프 → 캠페인 → 리포트 → 내보내기 | `inputs/email-{캠페인}.csv` |

⛔ **개인정보는 받지 않는다.** 이름·전화·주소·이메일 원문은 **마스킹해서** 넣게 안내한다.
필요한 것은 `고객ID · 첫구매일 · 최근구매일 · 구매횟수 · 누적금액` 뿐이다.

## 5. 경쟁사

관련 스킬 — `경쟁사 분석(002)` · `경쟁사 상시 모니터링(003)` · `가격 포지셔닝 맵(009)`

**여기는 내보내기가 없다.** 남의 데이터라 전부 손으로 모은다.

| 무엇 | 어떻게 |
|---|---|
| 상세페이지 | **캡처 여러 장** 또는 URL (공개 페이지라 열리기도 한다) |
| 가격·옵션 | 화면 보고 표로 적어 넣는다 — `inputs/competitors.md` |
| 리뷰 | 캡처 · 복사 (다운로드 안 된다) |
| 검색 순위 | 검색 결과 화면 캡처 |

**경쟁사 3곳이면 충분하다.** 5곳을 넘으면 비교가 흐려진다.

## 6. G1 에서 이렇게 낸다

```
「이번 달 광고 어땠어」 → 광고 주간 리포트(045)

이 일에 있으면 좋은 자료
  ✅ 있음    브랜드 프로필 (마진율 30% → 손익분기 ROAS 3.3)
  ⬜ 없음    매체별 지출·성과 CSV        ← 있으면 실제 숫자로 판정합니다

             네이버 검색광고  광고시스템 → 보고서 → 맞춤 보고서 → 기간 → 다운로드
             메타            광고 관리자 → 보고서 → 열 선택 → 내보내기 → CSV
             inputs/ 에 넣어 주시면 됩니다

             필요한 열: 노출 · 클릭 · 비용 · 전환수 · 전환매출

없으면 샘플(가상의 A브랜드)로 완주하고 [샘플] 이 붙습니다. 그대로 진행할까요?
```

**「어디서」를 지어내지 않는다.** 이 문서에 없는 경로는 **모른다고 말하고** 사용자에게 묻는다.
플랫폼이 화면을 바꾸면 이 문서를 고친다 — 100개 스킬을 고치지 않는다.
