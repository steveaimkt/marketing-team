# 자문 프레임워크 · 답이 하나로 안 떨어질 때

> 전략·가격·포지셔닝·론칭 여부처럼 **정답이 없는 결정**을 여러 프레임워크로 압박한다.
> CMO가 메인 대화에서 직접 진행한다 (별도 담당을 두지 않는다).
> 트리거 — 「자문단 소집」·「이거 어떻게 볼까」·「고딘이라면」

## ⛔ 최우선 원칙

1. **이것은 프레임워크 적용이지 인물 시뮬레이션이 아니다.** 산출물 첫 줄에 이 고지를 넣는다.
2. **인용문을 지어내지 않는다.** "○○는 이렇게 말했다" 형식 금지. **"○○의 △△ 프레임워크로 보면"** 형식만 쓴다.
3. **가치는 합의가 아니라 불일치에 있다.** 전원이 같은 결론이면 배석을 잘못 짠 것이다. **반대자를 최소 1명 반드시 배석**한다.
4. **일반론 금지.** 각 자문은 자기 프레임워크를 **사용자의 숫자와 상황에** 적용해야 한다.
5. **판정하지 않는다.** 선택지와 각각의 대가까지가 경계다. 고르는 것은 사용자다.

## 배석 가능한 프레임워크

| 출처 | 프레임워크 | 강한 질문 |
|---|---|---|
| 세스 고딘 | 퍼미션 마케팅 · 보랏빛 소 · 트라이브 | 커뮤니티 · 구독 · 차별화 |
| 데이비드 오길비 | 리서치 기반 카피 · 헤드라인 원칙 | 카피 · 광고 |
| 유진 슈워츠 | 시장 인지 5단계 · "욕망은 만들 수 없고 채널링만 된다" | 카피 · 수요 |
| 에이프릴 던포드 | 포지셔닝 10단계 · 경쟁 대안 정의 | 포지셔닝 · 카테고리 |
| 로리 서덜랜드 | 행동경제학 · 가격의 신호 기능 | 가격 · 비합리 |
| 알렉스 호모지 | 가치 방정식 · 굶주린 군중 · 그랜드슬램 오퍼 | 오퍼 · 가격 · 전환 |
| 바이런 샤프 | 물리적·정신적 가용성 · 라이트 바이어 · 독특함 | 브랜드 성장 · 도달 |

**3~5명만 배석한다.** 질문 성격에 맞는 사람 + **반드시 반대자 1명**.

> ⚠️ 바이런 샤프와 세스 고딘은 근본적으로 충돌한다 (대중 도달 vs 트라이브).
> 호모지와 서덜랜드도 가격에서 충돌한다 (가치 극대화 vs 신호).
> **이 충돌이 자산이다.** 매끄럽게 봉합하지 마라.
