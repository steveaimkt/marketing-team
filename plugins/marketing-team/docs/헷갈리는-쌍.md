# 헷갈리는 쌍 · 가르는 말

> 스킬을 고를 때 **후보가 갈리면 여기부터 본다.** 스킬 본문을 열기 전이다.
> 겹치는 쌍은 두 갈래로 찾았다 — **계산** (이름·트리거·설명의 낱말 자카드 ≥ 0.13) 과
> **실측** (`scripts/eval-routing.mjs --live-cc` 가 모델이 실제로 헷갈린 자리를 찾아낸다). 지금 12묶음.
>
> **원칙 하나** — 사용자의 문장에 **관찰 가능한 단서**로 가른다.
> 「더 적절해 보인다」로 고르지 않는다. 단서가 없으면 **묻는다.**

---

## 리뷰 셋 · 가장 자주 갈린다

| | 무엇을 하나 | 가르는 말 |
|---|---|---|
| **006** 소비자 리뷰 마이닝 | 리뷰에서 **인사이트를 뽑는다** (분석) | 「분석·마이닝·페인포인트·뽑아」 |
| **054** 리뷰 관리 시스템 | 리뷰에 **답변을 단다** (운영) | 「답변·응대·달아줘·악평」 |
| **078** VoC 취합·분류 | 여러 채널 VoC를 **모아 분류한다** (체계) | 「모아·분류·체계·파이프라인」 |

```
"리뷰 분석해줘"          → 006
"악평에 답변 달아줘"      → 054
"CS·리뷰·설문 다 모아줘"  → 078
```

⚠️ 「리뷰 분석해줘」 하나만 오면 **006 이 기본**이다. 답변까지 원하면 006 → 054 로 잇는다.

## 리포트 셋 · 기간과 범위로 가른다

| | 범위 | 주기 | 가르는 말 |
|---|---|---|---|
| **045** 광고 주간 리포트 | **광고만** | 주 | 「주간·이번 주·광고 리포트」 |
| **067** 월간 마케팅 리포트 | **마케팅 전체** | 월 | 「월간·이번 달·종합」 |
| **062** 마케팅 대시보드 | 전체 | **상시** | 「대시보드·화면·매일 본다」 |

```
"이번 주 광고 어땠어"   → 045
"월간 리포트 만들어줘"  → 067
"매일 볼 화면 만들어줘"  → 062
```

기간도 범위도 안 나오면 **묻는다.** 「주간 광고인가요, 월간 종합인가요?」

## 광고 · 매체 이름이 나오는지로 가른다

| | | 가르는 말 |
|---|---|---|
| **041 · 042 · 044** | 한 매체를 **깊게** | 매체 이름이 나온다 — 쿠팡·네이버·구글 |
| **045** | 여러 매체를 **취합** | 매체 이름이 없다 |
| **046** | 예산을 **옮긴다** | 「예산·재배분·어디에 더」 |

```
"쿠팡 광고 분석해줘"   → 041
"광고 성과 봐줘"       → 045
"예산 다시 짜줘"       → 046
```

## A/B · 실험 전인가 후인가

| | | 가르는 말 |
|---|---|---|
| **019** A/B 테스트 설계 | **돌리기 전** — 표본·기간을 정한다 | 「설계·어떻게 하지·며칠」 |
| **047** 광고 소재 A/B 판독 | **돌린 뒤** — 승패를 가르고 **다음 변형까지 제안한다** | 「결과·판독·이겼나·유의미」 |

⚠️ **「다음에 뭘 테스트할지」는 019 가 아니다.** 앞뒤로만 가르면 여기서 무너진다 (실측에서 틀렸다).
**손에 결과가 있으면 047 이다** — 「이긴 소재 기준으로 다음 테스트 제안해줘」는 이긴 소재가 이미 있다.
019 는 **앞선 결과가 없을 때**다.

```
"이긴 소재 기준으로 다음에 뭘 테스트할지"  → 047 (결과가 근거다)
"이 가설 A/B 로 어떻게 검증하지"           → 019 (결과가 없다)
```

## 댓글 둘 · 데이터가 손에 있나

> 실측으로 찾았다 (`eval-routing.mjs --live-cc`). 낱말이 안 겹쳐서 계산으로는 안 잡혔다.

| | | 가르는 말 |
|---|---|---|
| **006** 소비자 리뷰 마이닝 | **가진** 리뷰·댓글을 분석한다 | 파일이 손에 있다 · 「분석·마이닝·페인포인트」 |
| **038** 소셜 리스닝 | 브랜드 언급을 **긁어와** 추이를 본다 | 키워드만 있다 · 「언급·여론·추이·주간」 |

```
"댓글 감정별로 나눠줘"  → 데이터가 있으면 006 · 없으면 038. 없으면 묻는다
```

⚠️ 「감정·감성」 이라는 말만 보고 038 로 가지 않는다. **006 도 감정을 가른다.**
갈리는 것은 감정이 아니라 **수집을 우리가 하느냐**다.

## 심의 둘 · 광고 카피인가 아닌가

> 실측으로 찾았다. 등재돼 있지 않아 실제로 틀렸다.

| | | 가르는 말 |
|---|---|---|
| **049** 광고 정책·심의 체커 | **광고 소재·카피**를 매체에 올리기 전 | 「카피·소재·광고 문구·심의·반려」 |
| **099** 법무 기초 체커 | 광고가 **아닌** 공개물 — 이벤트 요강·수집 양식·약관 | 「이벤트·개인정보·약관·수집·동의」 |

```
"상세페이지 카피에서 과장 광고 걸릴 부분 고쳐줘"  → 049 (대상이 카피다)
"경품 이벤트 세금이랑 고지문구 뭐 챙겨야 해?"     → 099 (대상이 이벤트 요강이다)
```

⚠️ **「과장광고·표시광고법」이라는 말만 보고 099 로 가지 않는다.** 둘 다 표시광고법을 본다.
갈리는 것은 법이 아니라 **검사 대상**이다 — **광고 카피면 049**, 그 밖의 공개물이면 099.

## 협찬 둘 · 내가 보내나 받나

> 실측으로 찾았다. 둘 다 「협찬」 이 들어가 겹쳐 보이지만 **자리가 반대**다.

| | | 가르는 말 |
|---|---|---|
| **034** 인플루언서 계약·브리프 | 인플루언서에게 **보낼** 문서 (우리가 광고주) | 「브리프·계약·가이드·보낼」 |
| **088** 스폰서십 콘텐츠 기획 | 광고주 브리프를 **받아** 만드는 기획안 (우리가 크리에이터) | 「기획안·구성안·받았는데」 |

```
"협찬 광고 표기 어떻게 안내해?"  → 남에게 안내 = 034
"광고주 브리프 왔는데 짜줘"      → 내가 받음  = 088
```

## 그래도 갈리면

**임의로 고르지 않는다.** 두 후보를 나란히 내밀고 사용자가 고르게 한다.

```
둘 중 어느 쪽일까요?
  006 리뷰 마이닝 — 리뷰에서 개선 포인트를 뽑습니다
  054 리뷰 관리   — 리뷰에 달 답변을 씁니다
```

**한 번 물어보는 것이, 엉뚱한 걸 돌리고 다시 하는 것보다 싸다.**
