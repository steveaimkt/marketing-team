# 차트 규격 · 어떤 차트를 언제, 어떤 기하로

> `.html` 을 착지시키는 스킬이 따른다 — 061 · 062 · 067 · 그 밖의 대시보드 스킬.

## ⛔ 이 문서가 정하지 않는 것

**색 · 서체 · 여백 · 어두운 화면 · 인쇄는 여기서 정하지 않는다.**
전부 `brand-templates/디자인시스템/` 이 정본이다 (`tokens.css` + `산출물.css`).

```
tokens.css   색 · 서체 · 크기 · 여백
산출물.css   .chart · .bar · .axis · .card · .tw · 어두운 화면 · 인쇄
```

⛔ **토큰에 없는 색값을 새로 만들지 않는다.** `#2563eb` 같은 값을 차트에 쓰지 않는다 —
디자인 시스템 README 의 「여기 없는 값은 만들지 않는다」가 차트에도 그대로 걸린다.
계열을 더 갈라야 하면 **색을 늘리지 말고 모양을 바꾼다** (아래 §2).

두 css 파일은 산출물 `.html` 의 `<style>` 안에 **그대로 박아 넣는다.** 링크로 걸지 않는다.

## 1. 골격 · 이미 있는 클래스를 쓴다

```html
<figure class="chart">
  <p class="cap">전월 대비 매출 분해</p>
  <p class="sub">2026-06 · [실데이터] · 출처 판매 원장</p>
  <svg viewBox="0 0 720 260" role="img"
       aria-label="전월 대비 +1,240만원. 수량 +1,800, 단가 -300, 믹스 -260.">
    …
  </svg>
  <p class="sub">읽기 — 늘어난 것은 전부 수량이다. 단가는 오히려 깎였다.</p>
</figure>
```

| | |
|---|---|
| `viewBox` 로만 그린다 | 폭을 %로 두면 360px 화면에서 알아서 줄어든다. `width` 를 px 로 박지 않는다 |
| `aria-label` 에 **결론**을 쓴다 | 「차트」라고만 쓰지 않는다. 화면을 못 보는 사람이 읽는 문장이다 |
| **해석 한 줄**을 붙인다 | 「그래서 뭐」가 없는 그림은 자리만 먹는다. `.sub` 로 아래에 단다 |
| `[실데이터]`/`[샘플]` | 차트 옆에 붙인다. 표에만 붙이고 그림에 안 붙이면 샘플이 실적처럼 보인다 |

## 2. 계열을 가르는 법 · 색을 늘리지 않는다

`산출물.css` 가 주는 것은 `.bar`(올리브) 와 `.bar.dim`(모래) **둘**이다.
셋 이상을 갈라야 하면 **잉크 농담과 모양**으로 간다 — `tokens.css` 가 판정 색을 만들 때 쓴 방법과 같다.

| 갈래 | 쓰는 것 |
|---|---|
| 주 계열 | `.bar` · 선은 `stroke:var(--olive)` 실선 2px |
| 보조 계열 | `.bar.dim` · 선은 `stroke:var(--ink-faint)` **점선** `stroke-dasharray="4 3"` |
| 셋째 이상 | `fill-opacity` 를 .35 / .6 / 1 로 나눈다. **색상을 바꾸지 않는다** |
| 좋아짐 / 나빠짐 | `var(--up)` / `var(--down)` · 반드시 **▲▼ 기호도 함께** 붙인다 |
| 사람이 판단할 자리 | `var(--mark)` — 아껴 쓴다 |
| 축 · 격자 | `class="axis"` · 격자선 `stroke:var(--line)` |

⛔ **색만으로 의미를 싣지 않는다.** 흑백 인쇄와 색각 이상에서 무너진다.

## 3. 차트 일곱 · 무엇을 물을 때 무엇을

| 차트 | 답하는 질문 | 쓰는 스킬 |
|---|---|---|
| ① **추이 라인** | 지금 올라가고 있나 | 061 · 062 · 067 |
| ② **가로 막대** | 어디가 큰가 (이름이 길 때) | 061 · 062 · 067 |
| ③ **파레토** | 상위 몇 개가 전체의 몇 %인가 | 061 · 067 |
| ④ **워터폴** | **늘고 준 것을 원인별로 쪼갠다** | 061 · 067 |
| ⑤ **100% 스택** | 구성비가 바뀌고 있나 | 062 · 067 |
| ⑥ **요일×주차 히트맵** | 반복 패턴인가 사고인가 | 061 · 062 |
| ⑦ **산점도** | 두 지표의 관계 (광고비↔매출) | 062 · 067 |

### ① 추이 라인 — 원계열만 그리지 않는다

들쭉날쭉한 선 하나는 판단을 못 만든다. **원계열(실선) + 이동평균(점선) + 이상치 점**이 한 벌이다.

```html
<polyline fill="none" stroke="var(--olive)" stroke-width="2" points="56,180 88,164 …"/>
<polyline fill="none" stroke="var(--ink-faint)" stroke-width="1.5"
          stroke-dasharray="4 3" points="…"/>
<circle cx="312" cy="206" r="4" fill="var(--down)"/>
<text x="312" y="196" class="axis" text-anchor="middle">▼ 6/12</text>
```

### ④ 워터폴 — 061·067 의 대표 차트

Δ매출을 **수량 + 단가 + 믹스** 로 쪼갠 그림. 표로만 내던 성장 동인 분해를 눈에 보이게 하는 자리다.
시작·끝 막대는 `.bar.dim`, 늘어난 칸은 `var(--up)`, 줄어든 칸은 `var(--down)`,
칸 사이는 `stroke:var(--line)` 점선으로 잇는다.

```html
<rect class="bar dim" x="56"  y="120" width="80" height="100"/>
<rect x="176" y="60" width="80" height="60" fill="var(--up)"/>
<rect x="296" y="60" width="80" height="20" fill="var(--down)"/>
<rect class="bar dim" x="536" y="98" width="80" height="122"/>
<line x1="136" y1="120" x2="176" y2="120" stroke="var(--line)" stroke-dasharray="3 3"/>
```

### ③ 파레토 — 80% 선이 결론이다

막대는 상품별 매출(`.bar`), 선은 누적 비중(`--ink-faint` 점선).
**80% 가로 점선을 긋고 거기서 몇 번째 상품인지 숫자를 박는다.** 그 숫자를 보려고 그리는 차트다.

### ⑥ 히트맵 — 반복과 사고를 가른다

행 = 주차, 열 = 요일. `fill="var(--olive)"` 에 `fill-opacity` 를 .1~1 로 걸어 **단색 농담**으로 낸다.
매주 같은 열이 진하면 반복 패턴이고, 한 칸만 튀면 이상치다.
⛔ 무지개 색상표를 쓰지 않는다.

## 3-2. 도식 여섯 · 수가 아니라 **구조**를 보일 때

차트는 「얼마나」를 그리고, 도식은 「어떻게 이어지나」를 그린다.
도식도 §1 골격과 §2 색 규칙을 그대로 따른다 — `figure.chart` 안에 인라인 SVG, 해석 한 줄, `aria-label`.

| 도식 | 무엇을 보이나 | 쓰는 스킬 |
|---|---|---|
| ⑧ **퍼널** | 단계마다 얼마나 빠지나 · **어디가 제일 새나** | 073 |
| ⑨ **감정 곡선** | 여정을 따라 기분이 어떻게 움직이나 | 073 |
| ⑩ **등급 피라미드** | 등급이 몇 층이고 각 층이 얼마나 되나 | 076 |
| ⑪ **4분면 매트릭스** | 무엇을 먼저 할까 (효과 × 난이도) | 091 |
| ⑫ **플로우·분기도** | 이 경우엔 이리로, 저 경우엔 저리로 | 072 · 093 |
| ⑬ **타임라인** | 언제까지 누가 | 093 · 057 |

### ⑧ 퍼널 — 사다리꼴로 줄어드는 폭이 이탈이다

⛔ **막대 네 개를 세워 놓고 퍼널이라 부르지 않는다.** 폭이 줄어드는 것이 보여야 퍼널이다.
각 단 옆에 **잔존수와 이탈률**을 함께 적고, **가장 큰 낙폭 한 단만** `--down` 으로 칠한다.

```html
<svg viewBox="0 0 720 300" role="img"
     aria-label="인지 10000 → 탐색 3200 → 구매 1200 → 재구매 180. 최대 이탈은 구매에서 재구매, 85%.">
  <polygon class="bar" points="120,20  600,20  540,80  180,80"/>
  <polygon class="bar" points="180,84  540,84  480,144 240,144"/>
  <polygon class="bar" points="240,148 480,148 420,208 300,208"/>
  <polygon points="300,212 420,212 380,272 340,272" fill="var(--down)"/>
  <text x="620" y="55"  class="axis">10,000</text>
  <text x="620" y="119" class="axis">3,200 · −68%</text>
  <text x="620" y="183" class="axis">1,200 · −63%</text>
  <text x="620" y="247" class="axis" fill="var(--down)">180 · ▼ −85%</text>
</svg>
```

### ⑨ 감정 곡선 — 퍼널 바로 아래에 같은 x축으로

퍼널과 **단 폭을 맞춘다.** 어긋나면 어느 단의 감정인지 못 읽는다.
0선을 `--line` 으로 긋고, 음수 구간만 `--down` 점으로 찍는다.

### ⑩ 등급 피라미드 — 위가 좁고 아래가 넓다

층마다 **인원과 매출 기여를 함께** 적는다. 인원이 적은데 매출이 큰 층이 보여야 설계가 읽힌다.
층 색은 `--olive` 에 `fill-opacity` 를 위 1.0 → 아래 0.35 로 내린다. **색상을 바꾸지 않는다.**

```html
<svg viewBox="0 0 720 280" role="img" aria-label="VIP 3% 인원이 매출 31%. 일반 68%가 매출 24%.">
  <polygon fill="var(--olive)" fill-opacity="1"   points="330,20 390,20 410,80 310,80"/>
  <polygon fill="var(--olive)" fill-opacity="0.7" points="310,84 410,84 440,144 280,144"/>
  <polygon fill="var(--olive)" fill-opacity="0.5" points="280,148 440,148 470,208 250,208"/>
  <polygon fill="var(--olive)" fill-opacity="0.35" points="250,212 470,212 500,272 220,272"/>
  <text x="490" y="55"  class="axis">VIP · 3% · 매출 31%</text>
</svg>
```

### ⑪ 4분면 매트릭스 — 사분면 이름을 적는다

축만 긋고 점만 찍으면 못 읽는다. **네 칸에 이름을 박는다** (먼저 한다 / 계획한다 / 자투리에 / 버린다).
「먼저 한다」 칸만 `--acc-band` 로 옅게 깔고, 그 칸의 점에만 라벨을 단다.

### ⑫ 플로우·분기도 — 마름모가 판단, 사각형이 행동

가로로 흐르게 그린다. 화살표는 `--ink-faint`, 판단 마름모는 테두리만, 행동 사각형은 `.bar.dim`.
**되돌아오는 선은 그리지 않는다** — 얽히면 아무도 안 읽는다. 「①로 돌아간다」라고 글자로 적는다.
⛔ 분기는 **한 화면에 일곱 개까지.** 넘으면 도식을 둘로 가른다.

### ⑬ 타임라인 — 가로선 하나에 점을 찍는다

점마다 **날짜·담당·할 일**을 붙인다. 지난 것은 `--ink-fade`, 다가올 것은 `--ink`,
기한이 지난 것은 `--down` 에 ▼ 를 붙인다.

## 3-3. 워드·PPT 에서 그리는 도식 · **SVG 를 쓸 수 없는 자리**

`.docx` · `.pptx` 는 `python-docx` · `python-pptx` 로 만든다 (`docs/공통규약.md`).
**인라인 SVG 가 안 들어간다.** 이미지로 변환해 넣는 길은 변환기가 없으면 통째로 실패하므로 쓰지 않는다.

⛔ **그래서 도식을 포기하지 않는다. 워드가 원래 잘 그리는 것으로 그린다 — 표다.**

| 도식 | 워드에서 | 규칙 |
|---|---|---|
| **분기도** | 3열 표 · `조건 → 판단 → 그러면` | 한 행이 한 갈래. 되돌아오는 화살표 대신 「①로」라고 적는다 |
| **단계 흐름** | 1열 표에 `▼` 를 사이 행에 둔다 | 세로로 읽힌다. 가로 화살표(→)는 줄바꿈에서 깨진다 |
| **타임라인** | 표 · `시점 │ 담당 │ 할 일 │ 상태` | 지난 것은 회색, 기한 넘긴 것은 ▼ |
| **4분면** | 2×2 표 · 칸마다 이름과 항목 | 칸 이름을 굵게. 빈 칸도 남긴다 (비어 있다는 것이 정보다) |
| **등급·계층** | 위에서 아래로 행 · 들여쓰기로 폭 | 층마다 인원·비중을 같은 행에 |

**색은 셀 배경으로만 준다.** `tokens.css` 값을 그대로 쓴다 —
강조 `#E0CCBE`(sand) · 사람이 판단할 자리 `#EBFF2C`(mark) · 머리 행 `#EBEBEB` · 글자 `#2A2A28`.
⛔ 새 색을 만들지 않는다. ⛔ 색만으로 의미를 싣지 않는다 — **기호(▼ ★ ⛔)를 함께 쓴다.**

```
분기도 예 · 워드 3열 표

| 들어온 것이            | 판단                    | 그러면              |
|------------------------|-------------------------|---------------------|
| 욕설·법적 언급         | 감정점수 1~2            | ⛔ 즉시 상담원 연결 |
| 환불 요구 · 금액 초과  | {금액}원 넘나           | 부분 응대 후 이관   |
| 단순 문의              | FAQ 에 있나             | 스크립트 A 로 답    |
| 위 어디에도 안 걸림    | —                       | 문의로 분류 · ①로   |
```

⚠️ **PPT 는 다르다.** `python-pptx` 는 도형을 직접 그린다 (`add_shape`).
분기도·퍼널·타임라인을 **도형과 연결선으로** 그린다. 표로 대신하지 않는다.
도형 채움도 위 색값만 쓴다.
