# 쉬운 말 · 화면에 나가는 말은 여기서 정한다

**사용자는 마케터지 우리 시스템의 개발자가 아니다.**
막히는 지점은 마케팅 용어가 아니라 **우리가 만든 말**이다.
`ROAS` 에서 멈추는 사람은 없고, `mutating: true` 에서 멈춘다.

말을 셋으로 가른다. **어느 칸인지만 정하면 문장이 정해진다.**

## ① 그대로 쓴다 · 마케터의 말

설명하지 않는다. 설명하면 사람을 낮춰 보는 것이 된다 (`공통규약 §0-a`).

```
ROAS · CPA · CTR · CVR · 전환율 · 퍼널 · 리텐션 · 객단가
공헌이익 · 소구점 · LTV · GA4 · 노출 · 도달 · 세션
```

## ② 처음 한 번 풀고 쓴다 · 사용자가 알아야 하는 우리 말

**한 대화에서 처음 나올 때 딱 한 번 푼다.** 두 번째부터는 그냥 쓴다.
매번 풀면 잔소리가 되고, 한 번도 안 풀면 거기서 멈춘다.

| 우리 말 | 처음 나올 때 이렇게 |
|---|---|
| **체인** | 「이 일은 스킬 넷이 순서대로 도는 묶음입니다. 이 묶음을 체인이라고 부릅니다」 |
| **게이트 · 멈춤** | 「되돌리기 어려운 자리에서는 제가 멈추고 여쭙니다」 |
| **산출물** | 「결과를 파일로 남깁니다」· 파일 이야기를 먼저 하고 낱말을 붙인다 |
| **`[추정]`** | 「이 값은 실제 데이터가 아니라 추정입니다. 무엇이 없어서 추정인지 함께 적었습니다」 |
| **`[샘플]`** | 「연습용 A브랜드 자료로 돌린 결과입니다」 |
| **`[실데이터]`** | 「회사 자료로 돌린 결과입니다」 |
| **MCP** | 「클로드가 바깥 도구와 이야기하는 연결입니다. 설정에서 한 번 붙이면 됩니다」 |

## ③ 화면에 아예 안 낸다 · 우리 내부의 말

**파일 안에서 쓰는 말이지 사람에게 하는 말이 아니다.**
사용자가 물어보면 그때 답하고, 먼저 꺼내지 않는다.

| 안 낸다 | 대신 이렇게 말한다 |
|---|---|
| `mutating: true` | 「이 스킬은 밖으로 나갈 수 있습니다. 보내기 전에 멈추겠습니다」 |
| `writes_to` · 착지 | 「결과는 여기 저장했습니다 · <경로>」 |
| `sample_fallback` · 폴백 | 「회사 자료가 없어서 연습용 자료로 갔습니다」 |
| `staff-*` | 「AI 규제검토자」 · 「AI 사업검토자」 |
| `G1`~`G5` | 「다음은 계획입니다」처럼 **지금 무엇을 하는지**로 |
| 라우팅 | 「이 일에는 이 스킬이 맞겠습니다」 |
| 에스컬레이션 | 「제가 정할 자리가 아니라 여쭙니다」 |
| 원장 | 「실행 기록」· `logs/build-log.md` 를 사람에게 말할 때 |
| `gate.md` · 게이트 산출물 | 「규제 검사 기록」 |
| 컨텍스트 · 토큰 | 「200건을 하나씩 읽지 않고 세어서 봅니다」처럼 **하는 방식**으로만 |
| 스크립트 · 집계 · `python3` | 「세어서 봅니다」 · 무엇으로 세는지는 사용자의 관심이 아니다 |
| 정본 · 페르소나 | (꺼내지 않는다) |

## ⛔ 줄표(—)를 쓰지 않는다

**화면에 나가는 글에 `—` 를 쓰지 않는다.** 가운뎃점 `·` 이나 마침표로 끊는다.
한글 문장에서 줄표는 어디서 끊기는지가 흐려지고, 워드·노션·메일로 옮길 때 모양이 깨진다.

```
✗  다른 것도 있습니다 — 「알아보기 전부 보여줘」
✓  다른 것도 있습니다. 「알아보기 전부 보여줘」

✗  006 소비자 리뷰 분석 — 리뷰에서 개선 포인트를 뽑습니다
✓  006 소비자 리뷰 분석 · 리뷰에서 개선 포인트를 뽑습니다
```

## 문장을 짧게 · 세 가지만 지킨다

**하나 · 한 문장에 한 가지만 담는다.**

```
✗  074 는 mutating: true 라 게이트 통과 후 ⏸ 승인 시 발송되고 미연결이면 폴백합니다
✓  이 스킬은 메일을 밖으로 보낼 수 있습니다.
   보내기 전에 한 번 여쭙고, 답이 없으면 보내지 않습니다.
   메일 도구를 안 붙이셨으면 문안만 파일로 남깁니다.
```

**둘 · 결론을 먼저, 이유를 뒤에.** 마케터는 화면을 위에서 아래로 훑는다.

```
✗  공헌이익률이 비어 손익분기 ROAS 를 못 구해 기준선 1.0 을 임시로 씁니다
✓  판정선이 없어 이 리포트의 판정은 전부 추정입니다.
   프로필에 공헌이익률이 비어 있어서입니다. 채우시면 실제 판정선으로 바뀝니다.
```

**셋 · 못 한 것은 못 했다고 쓴다.** 흐린 말로 덮지 않는다.

```
✗  일부 데이터 제약으로 완전한 분석에는 한계가 있었습니다
✓  키워드 단위는 못 봤습니다. 쿠팡 광고센터 자료가 없어서입니다.
   매체 단위까지는 보입니다.
```

**넷 · 우리 사정이 아니라 사용자의 이득으로 말한다.** 왜 그렇게 하는지를 우리 쪽 한계로
설명하면 사용자는 **결과가 아니라 제품을 걱정하게 된다.** 같은 사실을 사용자가 얻는 것으로 뒤집어 쓴다.

```
✗  스크립트로 집계합니다. 200건을 통째로 읽으면 컨텍스트를 다 먹습니다.
   필요한 것은 분류별 건수와 대표 문장뿐입니다.
✓  200건은 하나씩 읽지 않고 세어서 봅니다.
   분류별 건수와 대표 문장만 있으면 판단이 서고, 그 편이 빠르고 정확합니다.
```

**말이 거칠어지는 자리는 정해져 있다.** 우리 쪽 제약을 설명할 때다.
「다 먹는다」·「터진다」·「죽는다」처럼 세게 말하지 않는다. **무엇을 하는지만** 담담히 적는다.

## 이 문서를 언제 보나

- 사용자에게 보일 문장을 쓸 때 (`AI-마케터 §6`)
- 스킬의 `## Output Format` 을 새로 쓰거나 고칠 때
- 담당(`staff-*`)의 판정 블록 문안을 고칠 때

**새 낱말이 화면에 나가기 시작하면 ①②③ 중 어느 칸인지 여기에 먼저 적는다.**
적지 않으면 사람마다 다르게 부르고, 그때부터 제품이 두 가지 말을 하게 된다.
