# 기억 운영 · 스키마 · 자리 · 인용 · 점검

> `docs/공통규약.md §I` 에서 갈라져 나왔다. **매 업무에 필요한 것은 「G1 에서 찾고 G5 에서 남긴다」뿐**이고,
> 아래는 **자리를 정할 때와 점검할 때만** 쓴다.
>
> ⛔ **기억을 손대기 전에 해당 절을 통째로 읽는다. 기억으로 하지 않는다.**
> 자리를 한 번 잘못 정하면 같은 앎이 두 곳에 쌓이고, 다음 사람은 둘 다 못 믿는다.

| 언제 | 무엇을 읽나 |
|---|---|
| 어느 페이지에 남길지 헷갈릴 때 | §1 주제 여섯 · 자리 결정 |
| 남기기 직전 · 형식이 궁금할 때 | §2 스키마 · §3 인용 · §4 역링크 |
| 「이것도 남길까」 싶을 때 | §5 주목가치 게이트 · §6 남기지 않는 것 |
| 「점검해줘」 · 기억이 지저분할 때 | §7 점검 |

---

## 0. 회상과 기억은 다른 것이다

**둘 다 있어야 한다. 하나로 다른 하나를 대신하지 않는다.**

| | 무엇을 답하나 | 어디에 | 무엇으로 찾나 |
|---|---|---|---|
| **회상** `recall.mjs` | **무엇을 했나** | `outputs/` 의 md 와 영수증 | 날짜 · 스킬 번호 · 요청문 |
| **기억** `memory.mjs` | **무엇을 아나** | `brand/memory/{주제}/{이름}.md` | 주제 — 경쟁사 이름 · 채널 이름 |

회상만 있으면 경쟁사를 다섯 번 분석해도 **「그 경쟁사에 대해 우리가 아는 것」이 어디에도 없다.**
날짜와 스킬 번호를 기억하는 사람만 되찾을 수 있고, 그것은 기억이 아니라 검색이다.

**셋이 이어져야 백지에서 시작하지 않는다.**

```
brand/profile.md      고정 사실     온보딩 1회 · 바뀌면 고친다
brand/memory/         쌓이는 사실   실행마다 늘어난다 · 이 문서
brand/my-playbook.md  승격된 규칙   「다음에도 이렇게」 라고 정한 것
```

## 1. 주제 여섯 · 자리는 **무엇에 대한 앎인가**가 정한다

**형식도, 스킬 번호도, 날짜도 아니다.** 스킬 046 으로 알아낸 경쟁사 가격은 `경쟁사/` 로 간다.

| 주제 | 무엇이 오나 | 예 |
|---|---|---|
| `경쟁사/` | 경쟁 브랜드에 대해 알게 된 것 | `경쟁사/올리브영` |
| `고객/` | 세그먼트·페르소나의 행동과 이유 | `고객/30대-민감성` |
| `채널/` | 매체·플랫폼에서 우리에게만 참인 것 | `채널/메타` · `채널/쿠팡` |
| `제품/` | 우리 제품·라인에 대해 알게 된 것 | `제품/앰플` |
| `캠페인/` | 한 번의 캠페인이 남긴 것 | `캠페인/2026-08-여름` |
| `교훈/` | **다시 쓸 판단** — 재사용 가능한 규칙 | `교훈/가격인하-대응` |

⛔ **주제를 늘리지 않는다.** 늘리면 같은 앎이 두 곳에 쌓이고 검색이 둘 다 놓친다.
정본은 `scripts/memory.mjs` 의 `TYPES` 다 — 문서와 코드가 갈리면 코드가 이긴다.

### ⛔ 이렇게 넣지 않는다

| 잘못 | 맞게 | 왜 |
|---|---|---|
| 경쟁사 분석 → `캠페인/` | → `경쟁사/{이름}` | 주어가 경쟁사다. 어느 캠페인 중에 알았는지는 타임라인이 담는다 |
| 메타 광고로 알게 된 고객 반응 → `채널/메타` | → `고객/{세그먼트}` | 주어가 고객이다. 채널은 알게 된 경로일 뿐이다 |
| 산출물 전문을 복사 | → 한 줄 + 원본 링크 | 정본이 둘이 되면 다음 달에 어느 쪽이 맞는지 아무도 모른다 |
| 원자료 CSV·캡처 | → `inputs/` 에 둔다 | 기억은 **앎**이지 자료가 아니다 |
| 이번 실행에서만 쓴 수치 | → 남기지 않는다 | §5 주목가치 게이트 |

**헷갈리면 이렇게 묻는다 — 「석 달 뒤에 이걸 찾을 때 무슨 말로 찾을까?」**
그 말이 경쟁사 이름이면 `경쟁사/`, 판단이면 `교훈/` 이다.

## 2. 페이지 스키마 · 세 칸이다

정본 예시 — `brand-templates/memory/_페이지-템플릿.md`.

```markdown
---
type: 경쟁사
slug: 경쟁사/올리브영
title: 올리브영
created: 2026-09-01
updated: 2026-09-01
runs: [20260830-046-aaa]
---

# 올리브영

## 아는 것
- 8월 초 주력 라인 가격을 12% 내렸다 [출처: ROAS 진단(046) · 2026-08-30 · 샘플]

## 타임라인
- **2026-08-30** · [ROAS 진단(046)](../../../outputs/…/046-….md) — 경쟁 가격 인하가 ROAS 하락의 주원인

## 연결
- [[교훈/가격인하-대응]]
```

| 칸 | 무엇이 | 규칙 |
|---|---|---|
| **아는 것** | 지금도 참인 사실 | 한 줄에 한 사실 · 인용 필수 · 바뀌면 **고친다** |
| **타임라인** | 언제 무엇을 하다 알았나 | 산출물 원본을 가리키는 링크 필수 · **지우지 않는다** |
| **연결** | 함께 봐야 할 페이지 | `[[주제/이름]]` · 양방향 (§4) |

- 슬러그 문법 `{주제}/{이름}` — 소문자·한글·숫자·`.` `_` `-` 만. 대문자·공백·`..`·`.md` 는 거부된다.
- ⛔ **파일을 손으로 만들지 않는다.** `memory.mjs capture` 가 만든다 — 손으로 쓰면 인용과 역링크가 빠진다.
- `아는 것` 이 40줄을 넘으면 점검이 「비대」로 잡는다. 묶어 줄이고 옛 줄은 타임라인이 이미 들고 있다.

## 3. 인용 · **AI가 쓰지 않는다. 기계가 붙인다**

⛔ **초안에 `[출처: …]` 를 직접 쓰면 거부된다.** 이것이 이 구조의 핵심이다.

```
초안이 쓰는 것   "8월 초 주력 라인 가격을 12% 내렸다"
기계가 붙이는 것  [출처: ROAS 진단(046) · 2026-08-30 · 샘플]
                        ↑ 영수증(run.json)의 skills · completed_at · data_mode 에서 읽는다
```

- **영수증이 없으면 기억을 남기지 않는다.** 실행 없이 「그냥 아는 것」은 여기 들어오지 않는다.
- **데이터 모드가 인용에 남는다** (`실데이터` · `샘플` · `추정` · `혼합`).
  ⚠️ **샘플로 돈 실행에서 나온 앎을 실데이터인 것처럼 쓰지 않기 위해서다.**
  석 달 뒤 이 줄을 읽는 사람은 그 실행을 기억하지 못한다. **인용만 남는다.**
- 사실이 뒤집히면 **줄을 고치고** 새 인용으로 바꾼다. 옛 판단은 타임라인에 이미 남아 있다.

---

## 4. 역링크 · 한쪽만 걸린 링크는 끊긴 것이다

`links` 에 `교훈/가격인하-대응` 을 걸면, **그 페이지의 「연결」에도 돌아오는 링크가 들어간다.**
`capture` 가 자동으로 한다 — 상대 페이지가 **있을 때만**.

없으면 링크만 남고 점검이 「끊긴링크」로 잡는다. 그건 고장이 아니라 **아직 안 쓴 페이지**라는 표시다.
다음에 그 주제를 남길 때 채워진다.

---

## 5. 주목가치 게이트 ⏸ · 다시 쓸 것만 남긴다

**한 실행에 3건까지다.** 4건을 넘기면 `capture` 가 거부한다.

⛔ **묻지 않고 적지 않는다.** G5 에서 「이번에 남길 것」을 보여주고 ⏸ 로 받는다 —
`brand/` 의 파일은 사용자 것이고, 무엇을 아는 것으로 칠지는 사용자가 정한다.

**남길 것인지 판단하는 한 문장 — 「다음에 같은 일을 할 때 이걸 몰라서 다시 찾게 될까?」**

| 남긴다 | 남기지 않는다 |
|---|---|
| 경쟁사가 8월에 가격을 내렸다 | 이번 표의 3행 값이 12,400원이다 |
| 이 고객군은 성분보다 가격에 먼저 반응한다 | 이번 카피 20안 중 7안을 골랐다 |
| 메타는 우리 계정에서 주말 CPC 가 40% 뛴다 | 스킬 046 을 돌렸다 (← 원장이 이미 안다) |
| 경쟁 인하에는 예산보다 소재를 먼저 본다 | 사용자가 「좋아요」라고 했다 |

**0건도 정상이다.** 새로 안 것이 없는 실행이 대부분이다. 억지로 채우면 검색이 나빠진다.

## 6. 남기지 않는 것 · 여기 없는 것이 어디 있나

| 무엇 | 어디에 |
|---|---|
| 무엇을 했나 · 언제 · 어느 스킬 | `logs/build-log.md` (원장) |
| 산출물 전문 | `outputs/{날짜}/{번호}-{슬러그}/` |
| 입력 원자료 | `inputs/` |
| 「다음에도 이렇게 하자」 라고 **정한 방식** | `brand/my-playbook.md §3` |
| 브랜드 고정 정보 | `brand/profile.md` |
| 스킬 하나에 대한 우리 보완 | `brand/skill-notes/{번호}.md` |

⚠️ **`교훈/` 과 `my-playbook §3` 이 헷갈린다.**
`교훈/` 은 **우리가 알게 된 것**(「경쟁 인하에는 소재가 먼저다」)이고,
`my-playbook §3` 은 **사용자가 정한 절차**(「리뷰는 별점 3점짜리만 본다」)다.
앎은 기억으로, 지시는 플레이북으로 간다.

## 7. 점검 · 재는 자리가 있어야 지켜진다

```bash
node "${CLAUDE_PLUGIN_ROOT}/scripts/memory.mjs" doctor          # 사람이 읽는 3건
node "${CLAUDE_PLUGIN_ROOT}/scripts/memory.mjs" doctor --json   # 전부
```

| 신호 | 무슨 뜻 | 무엇을 한다 |
|---|---|---|
| `인용없음` | 손으로 쓴 줄이다 | 어느 실행에서 나왔는지 찾아 붙이거나 지운다 |
| `끊긴링크` | 상대 페이지가 아직 없다 | 급하지 않다. 그 주제를 다음에 남길 때 채워진다 |
| `형식` | frontmatter·자리가 어긋났다 | 슬러그와 파일 위치를 맞춘다 |
| `비대` | `아는 것` 40줄 초과 | 묶어 줄인다. 옛 줄은 타임라인이 들고 있다 |
| `낡음` | 180일 갱신 없음 | 아직 참인지 본다. 참이면 그대로 둔다 |
| `고아` | 90일 넘게 아무도 안 부르고 아는 것 1줄 이하 | **지울 후보다** ⏸ 로 묻고 지운다 |

- **한 번에 3건 이내로 돌려준다.** 열 개를 적으면 하나도 안 고쳐진다 (원장 진단과 같은 규칙).
- ⛔ **점검이 페이지를 지우지 않는다.** 지우는 것은 사람이 정한다 (`§J 정원제`).

## 8. gbrain 에서 가져온 것 · 무엇을 안 가져왔나

github.com/garrytan/gbrain 의 기억 구조에서 다섯을 가져왔다.
회상(`recall.mjs`)이 가져온 넷과 짝이다 — 정본은 `docs/원장-운영.md` 「회상」 절이다.

| 원칙 | 여기서는 |
|---|---|
| 주제가 자리를 정한다 (filing rules) | 주제 여섯 · 형식·스킬 번호·날짜로 나누지 않는다 (§1) |
| 인용 없는 사실은 없다 (citation) | 영수증에서 기계가 붙인다 · 초안이 쓰면 거부 (§3) |
| 역링크 철칙 (back-linking) | `capture` 가 상대 페이지에도 넣는다 (§4) |
| 주목가치 게이트 (notability) | 한 실행 3건 · ⏸ 승인 · 0건도 정상 (§5) |
| 재는 자리 (doctor · orphans) | `memory.mjs doctor` 여섯 신호 (§7) |

**안 가져온 것 셋** — 이 팀에는 과하다.

| gbrain | 왜 안 쓰나 |
|---|---|
| 벡터 DB · 임베딩 검색 | 마케터 한 사람의 기억은 수백 쪽이다. 토큰 매칭으로 충분하고 **설치가 0단계**여야 한다 |
| dream cycle (모델이 밤에 종합) | 승격은 사람이 ⏸ 로 한다. 모델이 몰래 쌓으면 **틀린 앎이 조용히 굳는다** |
| 사실의 확신도 가중치 (takes) | 대신 **데이터 모드**를 인용에 박았다 — 마케터에게는 「샘플이냐 실데이터냐」가 전부다 |
